User-authorized scope: performance review and real before/after measurements; rapid repeated region capture; screenshot capture during recording and cancellation/close edge cases; one-click update; Korean/English preference; optional date/time including seconds and milliseconds in recording with a movable/resizable floating clock; visible video text and direct timeline duration/position manipulation; shape/image video layers; commercial video-editor UX research; GitHub push, verified PR integration and release.

Baseline source: main21c12cbf5b791e9cde8e6833db0587044d1d59a3 (v1.7.0). Workbranch agent/performance-editor-v1.8.0. The earlier v1.7.0 completion does not prove this new goal.

## Stable behavior and acceptance boundary

- Preserve existing capture, pin gestures, export compatibility, offline capture/OCR, private user captures, settings and annotations. Updating contacts GitHub only as part of the requested update flow; no telemetry.
- Support screenshot capture during recording without polluting the video with capture controls, corrupting files or losing recording state. Avoid replacing the requested concurrent scenario with blanket feature blocking. Busy editor/selection requests must be rejected or coalesced before expensive pixel work.
- Measure production call paths, not a toy substitute: pin move latency/CPU/allocations, idle with/without visible windows, repeated capture/persistence, OCR text/blank input, recording frame time/CPU/allocations/dropped frames, concurrent capture/recording and cancellation. Record environment, workload, process CPU normalization, sample count, medians/tails and limitations. Do not promise a speedup until measured.
- Optional clock is an explicit visible recording element with date/time/seconds/milliseconds, adjustable position/size, stable capture-coordinate mapping and bounded refresh rate. UI control overlays remain excluded from capture. Clock rendering must not restart continuous idle work when disabled.
- Video text, shapes and images must be visible in preview and exported MP4/GIF; selection/drag/resize and timeline move/trim share the persisted model, respect clip boundaries, and support keyboard/undo where existing architecture permits. Benchmark mainstream editor behavior using official sources.
- Update button checks the canonical repository stable release, downloads/validates exact expected artifacts, reports progress/errors/cancel, waits for safe application state, invokes the existing per-user transactional installer and restarts. Never discard active work or silently trust an arbitrary download URL.
- English option covers ordinary capture/pin/library/settings/recording/editor/update flows, persists selection, retains Korean default compatibility and avoids clipped or untranslated primary UI. No OS language changes.
