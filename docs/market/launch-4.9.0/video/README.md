# 핀 중심 영상과 블로그 그림 안내

이번 작업은 문서와 초안 작성입니다. 새 영상·표지·블로그 이미지를 만들거나 내려받지 않았습니다. 아래 파일은 저장소에서 존재를 확인한 기존 사용법 자료이며, 게시자는 실제로 재생하여 현재 배포 화면과 맞는 장면을 고릅니다. 4.4.0의 가리기 중심 영상과 표지를 새 버전의 대표 자료로 그대로 사용하지 않습니다.

## 사용할 기존 파일

기준 폴더는 저장소 루트의 `src/MyCapture.App/Assets/Tutorials/`입니다. 한국어는 `.ko`, 영어는 `.en` 파일을 사용합니다. 아래의 `.jpg`는 같은 이름으로 존재하는 미리보기 후보입니다. 핀·복사·클릭 허용·글자 복사·GIF의 한국어 미리보기 5장을 확인했습니다. 핀 클립보드 미리보기는 텍스트 선택 예시이고 핀 복사는 코드 예시입니다. 엑셀 표 화면으로 잘못 설명하지 않습니다. 클릭 허용 미리보기는 오른쪽 클릭 단계이므로 4.9.0 손잡이가 보이는 자료라고 단정하지 않습니다. 영상의 후속 장면은 게시자가 재생해 고릅니다.

| 용도 | 한국어 영상 | 영어 영상 | 한국어 미리보기 후보 |
| --- | --- | --- | --- |
| 표·코드·이미지 핀 | `pin-clipboard.ko.mp4` | `pin-clipboard.en.mp4` | `pin-clipboard.ko.jpg` |
| 핀 복사 | `pin-copy.ko.mp4` | `pin-copy.en.mp4` | `pin-copy.ko.jpg` |
| 클릭 허용·손잡이 | `pin-click-through.ko.mp4` | `pin-click-through.en.mp4` | `pin-click-through.ko.jpg` |
| 화면 글자 복사 | `text-copy.ko.mp4` | `text-copy.en.mp4` | `text-copy.ko.jpg` |
| 영역 녹화 | `record-region.ko.mp4` | `record-region.en.mp4` | `record-region.ko.jpg` |
| 녹화 일시정지 | `record-pause.ko.mp4` | `record-pause.en.mp4` | `record-pause.ko.jpg` |
| 영상 구간 정리 | `video-trim.ko.mp4` | `video-trim.en.mp4` | `video-trim.ko.jpg` |
| GIF 내보내기 | `video-gif-export.ko.mp4` | `video-gif-export.en.mp4` | `video-gif-export.ko.jpg` |
| 라이브러리 열기 | `library-open.ko.mp4` | `library-open.en.mp4` | `library-open.ko.jpg` |

네이버 1편에는 핀·복사·손잡이, 2편에는 텍스트 복사, 3편에는 녹화·일시정지·자르기·GIF 내보내기 장면을 배치합니다. 각 글에 적힌 그림 위치는 실제로 사용할 장면의 선택 지시이며 이미지 삽입 완료를 뜻하지 않습니다. 해당 영상에 원하는 장면이 충분히 담기지 않았으면 잘못된 장면을 붙이지 말고 실제 앱에서 별도로 준비합니다.

## 짧은 영상 구성안

완성 길이는 약 20~30초를 목표로 하는 편집안입니다. 아래 초 단위 구간은 새 영상의 목표 배치이며 원본에서 확인한 타임코드가 아닙니다. 원본을 확인한 뒤 실제 컷 지점을 정합니다.

| 목표 구간 | 보여 줄 행동 | 한국어 자막 | English caption |
| --- | --- | --- | --- |
| 0~5초 | 엑셀 표 또는 코드 복사 | 표·코드 복사 | Copy a table or code |
| 5~12초 | F3으로 다른 창 위에 핀 | F3으로 핀 | Press F3 to pin |
| 12~19초 | 원문이 있는 핀에 포커스 후 복사 | Ctrl+C로 원문 복사 | Copy source text with Ctrl+C |
| 19~24초 | 클릭 허용 손잡이 또는 첫 안내 | 클릭 허용 손잡이 | Click-through handle |
| 24~30초 | 이름과 받는 곳 | MyCapture · 무료 Windows 도구 | MyCapture · Free Windows tool |

핀 소개는 F3 한 가지로 시작합니다. 첫 화면부터 여러 핀 단축키나 가리기 기능을 나열하지 않습니다. 캡처·OCR·녹화는 각각의 블로그와 후속 설명에서 다룹니다. 기존 사용법 영상에 원문 복사나 새 손잡이 장면이 없으면 필요한 장면을 준비한 후 구성을 완성합니다.

## 게시 전 확인

1. 표의 글자, F3 입력, 핀의 원문 복사 결과가 읽히는지 확인합니다. 앱 화면과 다른 설명을 덧씌우지 않습니다.
2. 한글·영어 파일과 자막 언어를 맞추고 실제 배포 버전과 안내를 대조합니다. 실제 고객 정보·비밀 키가 화면에 없는지 확인합니다.
3. 세로 영상으로 편집할 경우 핀과 글자가 잘리지 않고 플랫폼 버튼에 가려지지 않는지 실제 미리보기에서 확인합니다.
4. 음성을 추가하는 별도 편집을 한다면 앱 자체 녹음 기능으로 오해하게 설명하지 않습니다. MyCapture의 녹화에는 마이크·시스템 소리가 포함되지 않습니다.
5. 게시 문안은 [영상 설명](../posts/video-descriptions.md)을 사용하고 Store 링크의 `cid=video`를 확인합니다. 블로그에서는 `cid=naver-blog`를 사용합니다.

## 기존 자료와의 차이

4.4.0의 영상은 개인정보 가리기를 앞세우며 F3을 사용자가 지정한 키로 설명했습니다. 4.9.0 초안은 복사 → F3 핀 → 원문 Ctrl+C를 먼저 설명하고 새 설치 기본값을 반영합니다. 과거 영상의 렌더·음량·프레임 검사 수치는 새 영상의 검증 결과로 옮기지 않았습니다. 문서만 요청된 이번 작업에서는 편집 스크립트를 복사하거나 실행하지 않았습니다.
