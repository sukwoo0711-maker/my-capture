## 제품 설명

```text
제가 직접 만든 MyCapture는 표·코드를 다른 창 위에 띄우는 무료 Windows 프로그램입니다. 엑셀 표나 코드를 복사하고 F3을 누르면 핀으로 뜨며, 원문이 있는 핀에 포커스를 두고 Ctrl+C로 원문을 다시 복사할 수 있습니다.

4.9.0은 처음 사용 안내와 라이브러리·편집기를 다듬은 버전입니다. 클릭 허용 상태인 핀은 오른쪽 위 손잡이로 클릭 허용을 끌 수 있습니다. 캡처·화면 글자 복사·영역 녹화와 GIF·개인정보 가리기도 제공합니다. 녹화에는 소리가 포함되지 않습니다.
```

## 연결 글 본문

```text
제가 직접 만든 MyCapture는 표·코드를 다른 창 위에 띄우는 무료 Windows 프로그램입니다. 표를 보며 문서를 작성하거나 예제 코드를 참고하는 상황에서 사용할 수 있습니다.

복사한 내용을 F3으로 띄우고, 원문이 있는 핀에 포커스를 두고 Ctrl+C로 다시 복사하는 흐름입니다. 핀의 확대와 투명도를 조절하고, 뒤 창 클릭 허용을 켜 둘 수 있습니다. 4.9.0에서는 클릭 허용 상태인 핀의 오른쪽 위 손잡이로 해당 상태를 바로 끄도록 했습니다.

이번 버전의 처음 사용 안내에서는 직접 캡처하고 핀을 띄우고 라이브러리에서 다시 찾습니다. 라이브러리는 3열 카드와 필요할 때 여는 상세 정보를 중심으로 정리했습니다. 편집기에는 파일로 저장과 복사하고 닫기를 배치했습니다. 시작 표시와 단축키 반응·메모리 반환도 개선했습니다.

처음 사용 안내에서 막힌 단계, 표·코드 원문을 다시 붙여 넣는 과정, 핀 손잡이의 위치에 대한 의견을 받고 싶습니다. 캡처·OCR·영역 녹화와 GIF도 사용할 수 있으며 녹화에는 소리가 포함되지 않습니다.

소개: https://mimiloaf.com/mycapture/
설치: https://apps.microsoft.com/detail/9PB33MC095VR?cid=community-ko
```
