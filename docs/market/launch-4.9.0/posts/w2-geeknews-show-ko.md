## 본문

```text
제가 직접 만든 MyCapture는 표·코드를 다른 창 위에 띄우는 무료 Windows 프로그램입니다. 참고 코드를 보며 다른 파일을 수정하거나 엑셀 표를 보며 문서를 작성하는 흐름으로 소개합니다.

표나 코드를 복사하고 F3을 누르면 핀으로 뜹니다. 원문이 있는 핀에 포커스를 두고 Ctrl+C를 누르면 원문 텍스트와 이미지를 함께 복사합니다. 지원하는 VS Code HTML은 코드 색상과 들여쓰기를 유지합니다. 이미지로 캡처한 내용과 복사한 원문을 구분해 다룹니다.

핀은 확대·투명도·뒤 창 클릭 허용을 지원합니다. 4.9.0에서는 클릭 허용 상태에서 오른쪽 위 손잡이로 해당 상태를 끌 수 있도록 했습니다. 처음 사용 안내에서 캡처·핀·라이브러리를 따라 할 수 있고 트레이 메뉴와 설정에서 다시 볼 수 있습니다.

라이브러리는 3열 카드와 필요할 때 여는 상세 정보를 중심으로 다듬었습니다. 편집기에는 파일로 저장과 복사하고 닫기를 배치했습니다. 편집 중 영역 캡처 단축키를 눌러도 현재 편집 내용은 유지하며 새 캡처를 라이브러리와 클립보드에 보냅니다.

캡처·OCR·영역 녹화·GIF·개인정보 가리기도 제공합니다. 녹화에는 소리가 없습니다. OCR 결과와 개인정보 가리기는 공유 전에 확인해야 합니다. F3은 새 설치 기본키이며 이전에 저장한 키는 유지됩니다.

소개: https://mimiloaf.com/mycapture/
설치: https://apps.microsoft.com/detail/9PB33MC095VR?cid=community-ko
저장소: https://github.com/sukwoo0711-maker/my-capture
```
