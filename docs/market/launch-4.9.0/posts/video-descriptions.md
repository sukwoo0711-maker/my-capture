# 짧은 영상 · YouTube Shorts / Instagram Reels

- 제안 일정: 한국어 D+6, 영어 D+18, 각 12:00 KST.
- 기본 장면: 복사한 표·코드 → F3 핀 → 원문 Ctrl+C. [기존 소스와 구성안](../video/README.md)을 사용합니다.
- 이 작업에서 새 영상·표지를 렌더하지 않았습니다. 준비한 파일의 실제 내용과 언어를 확인한 뒤 아래 문안을 사용합니다.
- Store ID는 `video`입니다. 플랫폼에서 설명 링크를 클릭할 수 없는 경우 사용자가 프로필 링크를 직접 설정하고 같은 주소를 사용합니다.

## 한국어 설명

```text
제가 직접 만든 무료 Windows 프로그램 MyCapture의 핀 사용 방법입니다. 표·코드를 복사하고 F3을 누르면 다른 창 위에 뜹니다. 원문이 있는 핀에 포커스를 두고 Ctrl+C로 원문을 다시 복사할 수 있습니다.

F3은 새 설치 기본키이며 이전에 변경한 단축키는 유지됩니다. 4.9.0에는 처음 사용 안내와 클릭 허용 핀의 손잡이가 추가됐습니다.

소개: https://mimiloaf.com/mycapture/
설치: https://apps.microsoft.com/detail/9PB33MC095VR?cid=video
```

I built MyCapture, a free Windows tool for pinning copied tables and code. Copy the content and press F3 to keep it above other windows. Focus a pin with source text and press Ctrl+C to copy the original text again.

F3 is the new-install default; existing saved shortcuts are preserved. Version 4.9.0 adds a first-use walkthrough and a handle for turning click-through off.

Overview: https://mimiloaf.com/en/mycapture/
