## 본문

```text
제가 직접 만든 MyCapture는 표·코드를 다른 창 위에 띄우는 무료 Windows 프로그램입니다. 보고서를 작성하면서 엑셀 수치를 확인할 때 필요한 표를 작업 창 가까이에 두는 방식으로 사용할 수 있습니다.

배경과 해결하는 문제

표를 보며 문장을 작성하거나 여러 자료를 비교하면 원래 창을 반복해서 열게 됩니다. 클립보드에 복사한 내용을 핀으로 띄우면 필요한 부분을 보며 작업하고, 원문이 필요할 때 핀에서 다시 복사할 수 있습니다.

동작 방식

복사한 텍스트·표를 읽기 좋은 이미지로 표시하면서 원문을 보존하는 Windows 데스크톱 도구입니다. 캡처와 인식 결과는 기본적으로 사용자 PC 안에서 처리합니다. 원문이 있는 핀에 포커스를 두고 Ctrl+C를 누르면 원문 텍스트와 이미지를 함께 복사합니다.

사용 방법

1. MyCapture를 실행하고 엑셀에서 참고할 표를 Ctrl+C로 복사합니다.
2. F3을 눌러 표를 다른 창 위에 핀으로 띄웁니다.
3. 보고서 창에서 표를 참고하며 작성합니다. 필요한 원문은 핀에 포커스를 둔 뒤 Ctrl+C로 다시 복사합니다.
4. 클릭 허용 상태인 핀은 오른쪽 위 손잡이로 클릭 허용을 끄고 조작할 수 있습니다.

4.9.0에는 처음 사용 안내가 추가됐으며 라이브러리와 편집기도 다듬었습니다. 캡처, 이미지 속 글자 복사, 영역 녹화·GIF, 개인정보 가리기를 함께 사용할 수 있습니다. 녹화에는 소리가 포함되지 않으며, 개인정보 가리기 결과는 공유 전 확인해야 합니다.

로그인·데이터·외부 서비스

캡처와 인식 결과는 기본적으로 PC 안에서 처리합니다. 선택 기능인 영어→한국어 번역은 처음 켤 때 약 247MB의 모델을 받습니다. GitHub 이미지 첨부는 설정한 이슈 페이지를 사용하는 별도 기능입니다.
앱 로그인 여부: 없습니다. 계정 없이 설치해 바로 씁니다.
데이터 수집·자동 업로드 여부: 개발자는 개인정보, 캡처 내용, 사용 기록을 받지 않습니다. 원격 측정, 분석, 광고, 충돌 보고 기능이 없고 캡처를 자동으로 올리지 않습니다.
그 밖의 외부 연결: 글자 인식 품질을 "정확"으로 고르면 ModelScope에서 공개 PP-OCRv5 모델(약 102MB)을 받습니다. 새 버전 확인은 하루 한 번이며 설정에서 끌 수 있습니다. 모델 내려받기와 새 버전 확인 요청에는 캡처 내용이 들어가지 않습니다. 자세한 내용은 https://mimiloaf.com/mycapture/privacy/ 에 있습니다.
```
