## 제목

엑셀 표 화면에 고정하는 방법: F3으로 표·코드를 다른 창 위에 띄우기

## 본문

```text
제가 직접 만든 무료 Windows 프로그램 MyCapture로 엑셀 표를 화면에 고정하는 방법을 소개합니다. 표나 코드를 복사하고 F3을 누르면 다른 창 위에 핀으로 뜨며, 필요한 원문을 핀에서 다시 복사할 수 있습니다.

엑셀의 숫자를 보며 보고서를 쓰거나 예제 코드를 참고하며 다른 파일을 수정할 때, 창을 계속 오가면 보고 있던 행을 다시 찾아야 합니다. 큰 창 전체를 옆에 두기보다 지금 필요한 표나 코드 일부를 작업 창 위에 두는 방식입니다. 여기서는 엑셀의 작은 표를 먼저 띄우고 코드에도 같은 방법을 적용합니다.

1. 필요한 표 복사

MyCapture를 실행한 뒤 엑셀에서 참고할 셀 범위를 선택하고 Ctrl+C를 누르십시오. 처음에는 머리글과 몇 행만 선택하면 결과를 비교하기 쉽습니다. 화면을 이미지로 캡처하는 대신 표 자체를 복사하면 핀에 원문을 함께 보존할 수 있습니다.

[그림 1: pin-clipboard.ko.mp4의 텍스트 복사·핀 표시 예시, 표에도 같은 F3 사용]

2. F3으로 다른 창 위에 고정

F3을 누르면 클립보드의 표가 핀으로 나타납니다. 문서 작성 창으로 돌아가도 참고 내용을 다른 창 위에 두고 볼 수 있습니다. 핀은 확대와 투명도 조절을 지원하므로 글자를 읽으면서 작업 영역을 확보하는 데 사용할 수 있습니다. 코드는 편집기에서 필요한 부분을 복사한 뒤 같은 방식으로 띄웁니다. 지원하는 VS Code HTML에서는 코드 색상과 들여쓰기를 유지합니다.

3. 핀에서 원문 다시 복사

원문이 있는 핀에 포커스를 두고 Ctrl+C를 누르십시오. 원문 텍스트와 이미지를 함께 복사하므로 붙여 넣을 문서에서 결과를 확인할 수 있습니다. 표 전체를 다시 찾아가거나 코드 내용을 손으로 옮겨 적을 필요가 줄어듭니다. 붙여 넣기 결과는 대상 프로그램이 선택하는 클립보드 형식에 따라 확인하십시오.

[그림 2: pin-copy.ko.mp4의 핀 복사 장면]

주의할 점

핀으로 띄운 이미지를 보는 것과 엑셀 파일을 편집하는 것은 다릅니다. 셀 내용을 고치는 작업은 원래 문서에서 진행합니다. 이미지로만 만든 핀에는 복사했던 표·코드의 원문이 없을 수 있습니다. 원문을 다시 쓸 목적이면 표나 코드 자체를 복사한 뒤 F3을 누르십시오.

F3은 새 설치의 기본 단축키입니다. 이전에 바꾼 키는 유지되며, 다른 프로그램이 먼저 F3을 사용하는 경우 시작 안내와 설정의 단축키 항목을 확인합니다. 뒤 창 클릭 허용이 켜져 조작이 어려우면 4.9.0의 핀 오른쪽 위 손잡이로 클릭 허용을 끌 수 있습니다.

[그림 3: pin-click-through.ko.mp4의 뒤 창 클릭 허용 전환 예시]

처음 사용하는 경우 앱의 처음 사용 안내에서 캡처·핀·라이브러리를 차례로 익힐 수 있습니다. 안내는 트레이 메뉴와 설정에서 다시 볼 수 있습니다. 캡처, 화면 글자 복사, 영역 녹화와 GIF 내보내기도 필요에 따라 이어서 사용할 수 있습니다.

```
