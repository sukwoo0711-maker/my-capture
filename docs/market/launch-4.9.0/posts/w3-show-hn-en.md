I built MyCapture, a free Windows tool for keeping copied tables and code above other windows. The workflow is copying the small part you need, pressing F3 to pin it, and continuing work with that reference visible.

A pin with source text keeps the original text alongside its rendered image. Focus the pin and press Ctrl+C to copy the source text and image again. Supported VS Code HTML preserves code colors and indentation. This is useful when comparing code or writing a document with an Excel table in view; an image-only pin doesn't necessarily contain that source text.

Pins support zoom, opacity and click-through. In 4.9.0, a handle at the top right of a click-through pin lets you turn click-through off. A first-use walkthrough takes you through capture, pinning and finding an item in the library. It can be reopened from the tray menu or settings.

The update also reorganizes library cards and the editor's save and copy-and-close actions. It improves startup feedback, the response after invoking capture and the release of memory used by capture effects.

Region capture, screen-text copying, region recording, GIF export and editable redaction are also available. Recordings have no microphone or system audio. OCR output and redacted screenshots still need checking before use or sharing. F3 is the default on new installations; existing shortcut settings are preserved.

Overview: https://mimiloaf.com/en/mycapture/
Store: https://apps.microsoft.com/detail/9PB33MC095VR?cid=community-en
Project: https://github.com/sukwoo0711-maker/my-capture

I'd appreciate concrete feedback on the table/code pin workflow, source-text pasting, or a confusing step in the walkthrough.
