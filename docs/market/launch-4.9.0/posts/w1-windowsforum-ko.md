## 본문

```text
제가 직접 만든 MyCapture는 표·코드를 다른 창 위에 띄우는 무료 Windows 프로그램입니다. 엑셀 표를 보며 문서를 작성하거나 예제 코드를 참고할 때 필요한 부분만 핀으로 두는 방식입니다.

엑셀에서 표나 편집기에서 코드를 복사하고 F3을 누르면 핀으로 나타납니다. 원문이 있는 핀에 포커스를 두고 Ctrl+C를 누르면 원문 텍스트와 이미지를 함께 복사합니다. 이미지로만 만든 핀과 표·코드 원문을 가진 핀은 복사할 수 있는 내용이 다릅니다. 지원하는 VS Code HTML의 코드 색상과 들여쓰기도 유지합니다.

핀의 확대와 투명도, 뒤 창 클릭 허용을 조절할 수 있습니다. 4.9.0에서는 클릭 허용 상태인 핀 오른쪽 위에 손잡이를 두어 다시 끌 수 있게 했습니다. 처음 사용 안내에서는 캡처·핀·라이브러리를 순서대로 익힐 수 있고, 트레이 메뉴와 설정에서 다시 안내를 볼 수 있습니다.

이번 버전은 라이브러리 카드를 3열로 정리하고 상세 정보를 필요할 때 열도록 다듬었습니다. 편집기 오른쪽 위에는 파일로 저장과 복사하고 닫기를 배치했습니다. 앱 시작이 늦으면 시작 중을 표시하며, 단축키 뒤 선택 화면이 뜨는 반응과 캡처 효과를 닫은 뒤 메모리를 돌려주는 과정도 개선했습니다.

영역 캡처는 Ctrl+Shift+C, 영역 녹화 시작·종료는 Ctrl+Shift+X입니다. 화면 글자 복사와 GIF 내보내기, 개인정보 가리기도 제공합니다. 녹화에는 소리가 포함되지 않습니다. 개인정보 가리기를 적용한 화면도 공유 전에 전체를 확인해야 합니다.

F3은 새 설치의 기본키입니다. 기존에 바꾼 단축키는 유지되며 다른 앱과 충돌하면 설정에서 확인할 수 있습니다.

소개: https://mimiloaf.com/mycapture/
설치: https://apps.microsoft.com/detail/9PB33MC095VR?cid=community-ko
```
