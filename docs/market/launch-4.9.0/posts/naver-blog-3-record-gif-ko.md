- 그림은 `src/MyCapture.App/Assets/Tutorials/`의 아래 파일에서 고릅니다. 그림 표시를 실제 장면으로 교체한 뒤 게시합니다.
- 기능 근거: [기능 문서](../../../features.md), [4.9.0 릴리스 노트](../../../releases/4.9.0-release-notes.md).

## 제목

윈도우 화면 녹화 GIF 만들기: 화면 일부만 녹화하고 필요한 구간 내보내기

## 본문

```text
제가 직접 만든 무료 Windows 프로그램 MyCapture로 화면 일부를 녹화하고 GIF로 만드는 방법을 소개합니다. 버튼을 누르는 순서나 오류가 생기는 순간을 짧은 움직임으로 보여 줄 때 사용할 수 있습니다.

설정 방법을 설명하면서 화면을 여러 장 붙이면 어느 순서로 눌렀는지 다시 적어야 합니다. 화면 전체를 녹화하면 관계없는 창까지 들어갈 수 있으므로, 설명할 부분만 골라 녹화한 뒤 필요한 구간을 GIF로 내보내는 방식입니다. 이 글에서는 영역 선택, 녹화 종료, 구간 정리, 파일 크기 확인 순서로 진행합니다.

1. 녹화할 영역 선택

MyCapture를 실행하고 설명할 창을 준비한 뒤 Ctrl+Shift+X를 누르십시오. 필요한 영역을 선택해 녹화를 시작합니다. 개인 알림이나 다른 문서가 들어오지 않도록 녹화 범위를 먼저 확인합니다. 버튼을 누르는 짧은 예시부터 만들면 구간을 고르고 결과를 점검하기 쉽습니다.

[그림 1: record-region.ko.mp4의 영역 선택·녹화 시작 장면]

2. 필요한 동작 녹화와 종료

영역 안에서 설명할 동작을 수행한 뒤 같은 Ctrl+Shift+X로 녹화를 종료합니다. 중간에 기다리는 시간이 있으면 녹화 컨트롤 창에서 일시정지·재개를 사용할 수 있습니다. 일시정지한 구간은 영상에서 제외됩니다. 녹화 결과는 MP4이며 라이브러리에서 동영상을 열어 재생하고 편집할 수 있습니다.

[그림 2: record-pause.ko.mp4의 일시정지·재개 장면]

3. 시작과 끝 정리

동영상 편집기에서 자르기로 보여 줄 구간을 정리합니다. 녹화를 시작하며 마우스를 옮긴 부분이나 마지막 대기 화면을 덜어 내면 전달하려는 동작을 찾기 쉽습니다. 자세히를 펼치면 프레임 이동과 시작·끝 시간을 확인할 수 있습니다. 필요한 경우 텍스트를 넣고 표시 시간을 조절할 수도 있습니다.

[그림 3: video-trim.ko.mp4의 구간 자르기 장면]

4. GIF 내보내기

내보내기에서 GIF 형식과 품질을 선택하고 저장 위치를 지정하십시오. 짧은 실제 GIF 샘플을 미리 보며 원본과 비교할 수 있습니다. 공유할 곳의 크기 제한에 맞춰 목표 크기를 선택하고 예상 크기와 권장 설정을 확인합니다. 저장한 뒤에는 파일을 열어 글자가 읽히는지, 시작과 끝이 의도한 구간인지 확인하십시오.

[그림 4: video-gif-export.ko.mp4의 미리보기·내보내기 장면]

주의할 점

MyCapture 녹화에는 마이크와 시스템 소리가 포함되지 않습니다. 음성 설명이나 회의 소리를 함께 담는 용도로 선택하지 마십시오. GIF에는 화면 움직임으로 설명할 수 있는 짧은 과정을 담습니다. 예상 크기만 보고 게시하지 말고 실제 저장 파일의 크기도 확인해야 합니다.

글자가 작아졌다면 품질을 낮추기 전에 필요 없는 구간이나 녹화 범위를 줄일 수 있는지 살펴보십시오. 결과가 불분명하면 편집기로 돌아가 구간과 품질을 다시 조정합니다. 4.9.0에서는 처음 사용 안내와 라이브러리를 다듬어 캡처·핀·저장한 항목을 찾는 과정을 안내합니다.
```
