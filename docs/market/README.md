## 핵심 요약

- **지금 팔 수 있나?** 기능·오프라인·정리(큐/갤러리)는 유료급이나, **코드 서명·JP/KR 현지화·녹화 오디오·라이선스 모델·문서/지원**이 갖춰지기 전엔 유료 출시 부적합. → "필수 수정 후 판매 가능".
- **압도적 해자:** 오프라인 OCR + 영속 큐 + 전문 검색, 레이어 보존 재편집, 녹화 프레임→주석 브리지, 무계정·완전 오프라인 포지셔닝, 풍부한 핀-투-스크린.
- **다음 단계(v0.6, P0):** 코드 서명 → JP/KR/EN 현지화 → 녹화 오디오 → 라이프타임 라이선스 → 캡처 OCR 전문 검색.

## 근거·검증 주의

- MyCapture 기능/패키징: 저장소 코드·스크립트 직접 확인(검증됨).
- 경쟁 가격/기능·VOC: 웹 조사 기반, 시점 변동 가능. 출시 직전 재확인 권장.
- 성능 목표·온보딩·일부 KR/JP 로컬 앱 세부·OCR 정확도: **미검증(잠정)** 으로 각 문서에 명시.
