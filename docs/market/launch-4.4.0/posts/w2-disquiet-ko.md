## 게시물 본문

```text
제가 만든 MyCapture는 개발자를 위한 무료 Windows 캡처·핀 도구입니다. 고객 문의를 이슈로 옮길 때 연락처를 가리고, 수정 중에는 원래 화면을 참고할 수 있도록 만들었습니다. 지난 문의 화면은 라이브러리에서 다시 찾을 수 있습니다.

개인정보 가리기는 로컬 OCR로 이메일·한국 전화번호 등의 형식을 찾아 편집 가능한 가림막을 붙입니다. 이미지·텍스트·표는 핀으로 다른 창 위에 두고, 라이브러리는 창 제목과 이미지 속 글자로 검색합니다. 이름·주소와 OCR이 놓친 부분은 직접 확인해야 합니다.

4.4.0부터 캡처 후에는 편집기 대신 작은 카드가 기본으로 나타납니다. 이미지는 이미 클립보드에 복사되어 있고 E로 편집, P로 핀, T로 텍스트 복사를 실행합니다. 4.4.0부터 테마는 시스템 따르기·밝게·어둡게·고대비이며, 새 설치의 이미지 보관 기간은 무기한입니다. 기존 사용자의 보관 설정은 유지합니다.

캡처한 이미지를 바로 붙여 넣는 상황에서 카드가 거슬리는지, 편집이 필요한 상황에서 E를 찾기 쉬운지 의견을 받고 싶습니다. 가림막을 수정하는 과정에서 막힌 부분도 확인하려고 합니다.

무료이며 계정·광고가 없습니다. 처리는 로컬에서 하지만 모델 파일은 내려받습니다. Windows용이고 녹화에는 소리가 없습니다. Store는 Microsoft 서명·업데이트를 제공하며 GitHub 배포본은 서명·앱 안 업데이트가 없습니다.

Store: https://apps.microsoft.com/detail/9PB33MC095VR?cid=community-ko
소스(MIT): https://github.com/sukwoo0711-maker/my-capture
```
