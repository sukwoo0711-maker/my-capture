## 본문

```text
MyCapture는 제가 만든 무료 Windows 캡처 앱입니다. 고객 문의 화면으로 이슈를 만들 때 이메일과 전화번호를 매번 손으로 가렸습니다. 코드를 수정할 때 그 화면을 옆에 두고, 나중에 같은 문의 화면을 다시 찾는 과정까지 묶어 보려고 만들었습니다.

개인정보 가리기(Ctrl+Shift+R)는 PC에서 OCR로 읽은 글자 중 이메일, 한국 전화번호, 주민번호 형태, 카드번호, IPv4 주소와 주요 비밀 키를 찾아 가림막을 붙입니다. 탐지 결과에는 종류와 위치만 유지하며, 가림막은 저장 전에 이동·삭제·실행 취소할 수 있습니다. 이름이나 주소는 탐지하지 않으며 OCR이 놓친 글자는 직접 확인해야 합니다.

F3으로 클립보드의 이미지, 텍스트, Excel 표를 다른 창 위에 핀으로 띄울 수 있습니다. 지원하는 VS Code HTML의 색상과 들여쓰기를 유지하며 확대·투명도를 조절할 수 있습니다. 라이브러리에서는 캡처 당시 창 제목과 이미지 속 글자로 검색합니다. 파일·프로젝트 이름 검색은 원래 앱이 제목 표시줄에 넣은 내용에 한합니다.

4.4.0부터는 캡처 후 편집기를 여는 대신 작은 카드가 기본으로 나타납니다. 이미지는 클립보드에 복사되어 있고 E는 편집, P는 핀, S는 저장, T는 텍스트 복사입니다. 4.4.0부터 새 설치의 이미지 보관 기간은 무기한이며 기존 사용자의 설정은 유지합니다.

.NET/WPF로 만들었고 소스는 MIT 라이선스입니다. 무료이며 계정·광고·캡처 횟수 제한·워터마크가 없습니다. 캡처·편집·녹화·OCR은 로컬에서 처리합니다. 캡처 자동 업로드와 분석 텔레메트리는 없지만 없는 OCR 모델은 시작 시 ModelScope에서, 선택 이미지 확대 모델은 첫 사용 시 Amazon S3에서 내려받습니다. GitHub 첨부는 직접 실행할 때만 연결합니다.

Windows 11 또는 Windows 10 22H2 x64에서 동작하며 ARM64 PC는 Windows 11이 필요합니다. 녹화에는 마이크·시스템 소리가 없습니다. Store는 Microsoft 서명과 업데이트를 제공하고, GitHub 설치 파일·ZIP은 서명과 앱 안 업데이트가 없습니다.

Store: https://apps.microsoft.com/detail/9PB33MC095VR?cid=community-ko
소스: https://github.com/sukwoo0711-maker/my-capture

다음 세 가지가 궁금합니다.
1. 개인정보 가리기가 놓치거나 잘못 가린 형식이 있습니까?
2. 문의 화면을 코드 옆에 둘 때 핀의 크기·투명도 조절이나 뒤 창 클릭 허용 중 실제 작업을 방해하는 부분은 무엇입니까?
3. 4.4.0부터 기본인 캡처 후 카드에서 원하는 동작을 찾기 어려웠던 상황과, 그때 기대한 동작을 알려 주시면 다음 조정을 판단하는 데 도움이 됩니다.
```

## 첫 댓글

```text
설치는 Microsoft가 서명하고 업데이트하는 Store 경로를 먼저 안내합니다. 포터블이 필요한 경우 https://github.com/sukwoo0711-maker/my-capture/releases 에서 ZIP과 SHA256SUMS.txt를 함께 받을 수 있습니다. GitHub ZIP은 서명이 없어 SmartScreen 경고가 나올 수 있습니다. SHA-256을 대조한 뒤 압축 전체를 풀어 실행하며, 앱 안 업데이트는 제공하지 않습니다. 재현 자료는 https://github.com/sukwoo0711-maker/mycapture-support/issues 에 남길 수 있습니다.
```
