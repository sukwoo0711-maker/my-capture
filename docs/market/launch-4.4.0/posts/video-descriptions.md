## YouTube Shorts English description

```text
I built MyCapture, a free Windows screenshot and pinning tool.
I kept covering contact details by hand when turning customer inquiries into issues.
This video shows local OCR redaction and annotations, followed by pinning the screenshot above a code window with F3.
No account or ads are required, and recordings have no audio.
OCR runs on the PC, with network access for model downloads.

Store: https://apps.microsoft.com/detail/9PB33MC095VR?cid=video
Source (MIT): https://github.com/sukwoo0711-maker/my-capture
Support: https://github.com/sukwoo0711-maker/mycapture-support/issues
```

## YouTube Shorts English first comment

Redaction can miss text that OCR fails to read; names and street addresses aren't detected. Requires Windows 11 or Windows 10 22H2 x64; ARM64 PCs need Windows 11. The Store build is signed by Microsoft and updated by the Store. GitHub setup and ZIP files are unsigned, may trigger SmartScreen, and have no in-app updates; compare them with SHA256SUMS.txt.
