# 세로 영상 만들기

`make_vertical.py`는 Store용 30초 트레일러 두 편(한국어 `artifacts\promo-2026-10-18\v2`, 영어 `v2-en`)을 잘라 1080×1920 세로 영상, 영상 표지, 가리기 전후 이미지를 만듭니다. 결과는 저장소 루트의 `artifacts\launch-4.4.0\`(git 무시 폴더)에 씁니다. 앱 소스는 건드리지 않고, 중간 파일은 `artifacts\launch-4.4.0\render-work\`에 남깁니다.

## 명령

홍보 영상 원본 폴더의 가상 환경(imageio-ffmpeg 7.1, NumPy, Pillow)을 씁니다. 저장소 루트에서 실행합니다.

```powershell
$py = 'C:\GitRepositories\my-capture\artifacts\promo-2026-10-18\source\video\venv\Scripts\python.exe'
& $py -I docs\market\launch-4.4.0\video\make_vertical.py --lang all
```

`--lang ko` 또는 `--lang en`으로 한 언어만 만들 수 있고, `--verify-only`는 다시 렌더하지 않고 검사만 합니다. 두 언어를 만드는 데 약 1분 걸립니다. 종료 코드 0은 아래 자동 검사가 모두 통과했다는 뜻입니다.

## 편집 기준

구간 경계는 트레일러 음악의 박자 지도(`source\video\film-v2\js\music.js`의 `beats`)에 맞췄습니다. 각 구간은 박 단위 길이이므로 이음매를 지나도 123.36BPM 박자가 이어집니다. 오디오는 같은 원본 구간을 12ms 교차 페이드로 잇고, 끝에서 0.3초 줄입니다. 음량은 올리지 않았습니다.

자르는 범위는 120px 격자를 그린 원본 프레임에서 쟀습니다. 패널은 폭 1000px로 가운데 두고, 세로 플랫폼의 오른쪽 버튼 열과 아래 설명 칸을 피하도록 중심을 y=900에 둡니다. 자막은 y=360에 고정합니다. 패널 가장자리는 36px에 걸쳐 배경색으로 흐려 잘린 선이 보이지 않게 합니다. 두 캡처 구간은 모드 막대와 크기 표시가 원본 맨 위에 붙어 있어 위쪽만 6px입니다.

| 구간 | 원본(초) | 박 | 자르는 범위 (x, y, w, h) | 자막(ko) |
|---|---|---|---|---|
| 창 전체 | 2.017–5.426 | 7 | 170, 0, 1580, 1070 | Ctrl+Shift+C 영역 캡처 |
| 선택 영역 | 5.426–8.751 | 7 | 120, 0, 1680, 1010 | Ctrl+Shift+C 영역 캡처 |
| 캡처 직후 카드 | 9.730–11.193 | 3 | 540, 270, 840, 760 | 캡처 직후 키 하나로 다음 동작 |
| 개인정보 가리기 | 13.150–15.584 | 5 | 420, 240, 1130, 800 | Ctrl+Shift+R 개인정보 가리기 |
| 주석 | 16.059–18.993 | 6 | 80, 0, 1720, 985 | 주석은 레이어로 남습니다 |
| 코드 위 핀 | 20.945–22.894 | 4 | 180, 40, 1570, 1000 | F3 다른 창 위에 핀 |
| 엔딩 | 25.805–29.657 | 8 | 530, 320, 860, 640 | 없음 |

창 전체 구간은 문의 창, 모드 막대, Ctrl·Shift·C 키캡이 모두 들어갑니다. 선택 영역 구간부터는 트레일러 카메라가 이미 문의 창 위쪽을 화면 밖으로 밀어내므로, 선택 사각형과 크기 표시, 오른쪽 아래로 들어가는 카드가 모두 보이게 잡았습니다. 개인정보 가리기 구간은 카메라 확대가 끝난 13.15초부터 쓰고, 가린 세 줄과 키캡이 모두 들어갑니다. 캔버스 오른쪽은 트레일러에서도 화면 밖입니다. 영상의 빠른 작업 카드는 4.2 화면이고, 4.4.0의 새 카드와 모양이 다릅니다.
