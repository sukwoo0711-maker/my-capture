# 사용자 VOC · 아이디어 마라톤 · 해자(Moat) 로드맵

근거: 멀티에이전트 VOC 마이닝(G2/Capterra/TrustRadius/Reddit/커뮤니티) + 경쟁 강점 흡수. 목적: 경쟁 유료 제품의 특장점을 흡수하여 MyCapture를 **압도적 해자**를 지닌 제품으로 만든다.

## 1. Voice of Customer — 반복되는 신호

### 사랑받는 기능 (Loved) — 흡수 대상
1. 스크롤/긴 페이지 캡처 (Snagit/알캡처) — MyCapture 보유 ✓
2. 완성 도형 재편집 (Snagit 요청 다수) — MyCapture 보유 ✓ (레이어 보존)
3. 단계 번호 배지·화살표로 튜토리얼 제작 (Snagit) — MyCapture 보유 ✓
4. 빠른 공유 링크 (Monosnap/Droplr/Loom) — **미보유**(오프라인 포지셔닝과 상충 → 로컬 대안 필요)
5. 클립보드 즉시 복사 + 자동 저장 동시 (다수) — MyCapture 보유 ✓
6. GIF 내보내기 (ShareX/ScreenToGif) — **미보유**
7. 녹화 중 주석/커서 강조 (Camtasia/ScreenPal) — **미보유**
8. OCR로 이미지의 텍스트 추출 (일부) — MyCapture 보유 ✓ (오프라인 KR+EN)
9. 캡처 자동 정리·검색 (거의 없음) — MyCapture 결정적 우위 ✓ (큐+갤러리)
10. 가벼움·즉각 반응 (Greenshot/PicPick) — MyCapture 목표 ✓ (실측 필요)

### 불만 (Pain points) — 회피/해결 대상
1. **구독 강제**에 대한 반감 (Snagit 유지보수·SaaS류) → 라이프타임 모델로 차별화
2. **광고/번들 설치** (무료 한국 앱) → "광고·번들 없음" 명시
3. 계정/로그인 강제·클라우드 종속 (Loom/Monosnap) → 무계정·오프라인
4. 무거움·느림·메모리 (일부 Electron/무거운 앱) → 네이티브 경량
5. 캡처 유실·이력 없음 (Snipaste 세션 한정) → 영속 큐
6. 업데이트 시 설정/데이터 손실 → 트랜잭션 설치·데이터 보존 ✓ (보유)
7. 미서명 실행 경고 → **코드 서명 필요**(현재 미해결)
8. 현지화 부실 → JP/KR 완전 현지화
9. 녹화 오디오 없음/싱크 문제 → 오디오 지원
10. 프라이버시 우려(클라우드 업로드) → 완전 로컬

## 3. 방어 가능한 해자 (복제 난이도 높은 것)

1. **오프라인 OCR + 영속 큐 + 전문 텍스트 검색의 결합** — "예전에 찍은 화면을 그 안의 글자로 검색". 클라우드 없이, 계정 없이. 경쟁 어디에도 통째로 없음.
2. **레이어 보존 재편집 + 큐 왕복 보장** — 3일 전 캡처의 화살표만 수정. 원본·레이어·평면화가 항상 일관.
3. **녹화 프레임 → 주석 편집기 브리지** — 영상 프레임을 정지 캡처와 100% 동일하게 편집→갤러리 승격.
4. **완전 오프라인·무계정 포지셔닝 쐐기** — 규제·보안·프라이버시 시장(KR 공공/금융, JP) 진입 장벽을 역이용.
5. **풍부한 핀-투-스크린** — 참조 이미지를 화면에 고정하는 워크플로 우위.
