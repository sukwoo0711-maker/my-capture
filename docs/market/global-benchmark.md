# 글로벌 경쟁 벤치마크 (US / UK / JP / KR)

근거: 멀티에이전트 병렬 웹 조사(공식 가격·기능 페이지, G2/Capterra/PCMag, Reddit, 일본/한국 소스). 시점 변동 가능한 수치는 대략값으로 표기하며 확정 시 재확인 대상.

## 1. 대상 선정 근거

- **US/UK 유료 선호**: Snagit(TechSmith), CleanShot X(mac), Monosnap, Droplr, Markup Hero, Zappy.
- **녹화/GIF**: ShareX, ScreenToGif, OBS Studio, Bandicam, Camtasia, ScreenPal, Loom, Ashampoo Snap.
- **한국 선호**: 알캡처, 픽픽(PicPick), oCam, 반디캠(Bandicam·녹화).
- **일본 선호**: Screenpresso, Rapture, WinShot, Windows 기본 Snipping Tool.

## 4. 지역별 기대치

### 미국/영국
- 유료 결제 저항 낮음, **코드 서명·문서·지원**이 신뢰의 기본 요건. G2/Capterra 리뷰 노출이 구매에 영향.
- 팀/공유·클라우드 협업 수요 존재(MyCapture는 오프라인 포지셔닝으로 다른 세그먼트 공략).

### 한국
- 무료 앱(알캡처 등)의 **광고/제휴 설치 번들**에 대한 반감이 큼 → "광고 없음·번들 없음"이 강력한 판매 논거.
- 한글 UI·**한글 OCR 품질** 기대. 인트라넷/공공기관의 오프라인 요구가 강함.
- 반디캠 등 국산 녹화 도구 인지도가 높아 녹화 성능은 비교 기준이다. 오디오는 MyCapture의 무음 제품 결정에 따라 직접 경쟁 범위에서 제외한다.

### 일본
- **현지화 완성도**(UI·문서·용어)에 민감. vector.co.jp/窓の杜(forest.watch.impress) 등 소개 매체 노출이 신뢰에 기여.
- Screenpresso/WinShot류의 가벼움·안정성 기대. 무계정·오프라인은 일본에서도 긍정 요인.

## 5. 종합 포지셔닝

MyCapture는 **"완전 오프라인·무계정 프라이버시 우선, 영속 큐·레이어 보존 재편집·오프라인 OCR로 지식노동 정리까지 아우르는 단일 Windows 유틸리티"**로 포지셔닝할 때 경쟁 우위가 가장 크다. 클라우드 협업(Loom/Monosnap)·본격 영상편집(Camtasia)과는 정면 경쟁하지 않고, Snagit/PicPick의 캡처+주석 세그먼트를 "오프라인·프라이버시·정리"라는 축으로 잠식하는 전략이 유효하다.

## 6. 검증 상태

- 가격/기능: 웹 조사 기반. 정확한 최신 가격·에디션은 출시 직전 재확인 필요(시점 변동).
- 한국/일본 로컬 앱 세부(광고 번들 정책, OCR 정확도)는 일부 커뮤니티 근거로 **부분 미검증**.
