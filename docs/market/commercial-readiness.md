# MyCapture 상용화 준비도 평가 (Commercial-Readiness Assessment)

버전 기준: v0.5.0 (main @ c1bc291) · 근거: 실제 코드베이스 인벤토리 + 멀티에이전트 경쟁 조사(US/UK/JP/KR) + 사용자 VOC
평가 성격: **객관적 판정**. 각 점수는 근거와 함께 제시하며, 검증 불가한 항목은 명시적으로 표시한다.

> 방법론 주의: MyCapture의 기능 목록은 저장소 코드에서 직접 확인했다(116개 소스 파일, 145개 테스트 통과, `build/package.ps1` 확인). 경쟁 제품의 가격·기능은 웹 조사로 수집했으며, 확인 불가 항목은 "미검증"으로 표기한다. 성능(메모리/응답성) 목표치와 온보딩/문서 수준은 실측·현물 부재로 잠정 평가다.

---

## 1. 한 줄 결론

**"필수 수정 후 판매 가능(Sellable with must-fixes)."** 기능의 폭과 깊이, 오프라인·프라이버시, 영속 큐/갤러리는 이미 유료 제품과 대등하거나 앞선다. 그러나 **코드 서명 부재**, **JP/KR 현지화 부재**, **녹화 오디오 부재**, **라이선스/가격 모델 미정**, **온보딩·문서·지원 부재**가 유료 출시를 막는 핵심 결함이다.

## 2. 점수표 (1–5, 근거 포함)

| 차원 | 점수 | 근거 (경쟁/VOC 대비) |
|---|---|---|
| 기능 폭(Feature breadth) | 5 | 영역/창/전체/스크롤/지연/고정 캡처 + 주석 + 핀 + OCR + 녹화까지 단일 앱. Snagit급 폭, ShareX급 기능 다양성. |
| 주석 깊이(Annotation depth) | 5 | 객체 기반 재선택·재편집 + **레이어 보존 재편집**은 Snipaste(공식 미구현)보다 앞섬. |
| 녹화 깊이(Recording depth) | 2 | 영역 녹화·트림·프레임 이동·프레임→이미지 편집은 있으나 **오디오(마이크/시스템) 없음**, 웹캠·커서 강조·주석-중-녹화 없음. Bandicam/Camtasia/ScreenPal 대비 열위. |
| 영속성·정리(Queue+Gallery) | 5 | 300장 영속 큐 + 갤러리(격자/날짜/검색)는 경쟁 대부분에 없는 결정적 차별점. |
| OCR | 4 | 오프라인 KR+EN OCR은 강점. 단 정확도 실측 미검증, 다국어 확장 여지. |
| 오프라인·프라이버시 | 5 | 무계정·무클라우드·무텔레메트리·완전 오프라인. 프라이버시 민감 시장(공공/금융/KR)에서 강력한 쐐기. |
| 성능(Performance) | 3 | 네이티브 WPF·경량 설계지만 80MB/100ms 목표가 **실측 미검증**(잠정). |
| 패키징/설치(Packaging) | 4 | 자체 완결 오프라인 IExpress 설치 + 포터블 ZIP + SHA-256 무결성 + 트랜잭션 설치/롤백. 상용 수준. |
| 코드 서명/신뢰(Trust) | 1 | **Authenticode 미서명** → SmartScreen "알 수 없는 게시자" 경고. 유료 배포의 최대 장벽. (`README-OFFLINE.txt`에 자체 명시) |
| 현지화(JP/KR/EN) | 2 | UI 기본 ko-KR. JP 현지화 없음, EN 부분. JP/KR 시장 판매엔 완전 현지화 필요. |
| 가격/라이선스 모델 | 3 | 코드상 유료 잠금·라이선스 체계 **부재**. 모델(라이프타임/구독) 미정. |
| 지원/문서 | 2 | 사용자용 문서·도움말·지원 채널 부재(개발 문서만 존재). |
| 온보딩(Onboarding) | 2 | 최초 실행 가이드/튜토리얼 부재(잠정). |

**합계: 43/65 (~66%).**

## 3. 판매를 막는 필수 수정(Top Must-Fix Gaps) — 심각도 순

1. **[치명] EV/OV 코드 서명 도입** — 미서명 시 Windows SmartScreen 경고로 유료 고객 이탈·환불·신뢰 붕괴. 상용 제품(Snagit 등)은 전부 서명됨. 저장소 `README-OFFLINE.txt`가 스스로 이 리스크를 명시. → 해결: EV 인증서 + 서명 파이프라인.
2. **[치명] JP+KR 완전 현지화** — 일본 시장은 UI/문서 현지화 기대치가 높고(예: Screenpresso/WinShot류), 한국은 한글 UI + 한글 OCR 품질을 기대. 다국어 리소스 체계 필요.
3. **[높음] 녹화 오디오 결핍** — 데모/튜토리얼 녹화 시장에서 마이크+시스템 오디오는 사실상 필수(Bandicam/Camtasia/ScreenPal/Loom 전부 지원). MF에 오디오 스트림 추가 필요.
4. **[높음] 라이선스·가격 모델 확정** — "구매 후 영구 사용(라이프타임) + 유료 메이저 업그레이드"를 권장. PicPick과 Snagit 사이 가격대. 구독 전용은 지양(VOC상 반감 큼).
5. **[중간] 온보딩·문서·지원** — 최초 실행 투어, 단축키 치트시트, 사용자 도움말, 최소 지원 채널(이메일/FAQ).

## 4. 이미 확보한 우위 (판매 논거)

- **결정적 차별점 5**: (1) 재시작 후 유지되는 300장 영속 큐, (2) 레이어 보존 재편집, (3) 완성 도형 직접 재선택, (4) 갤러리, (5) 오프라인 OCR — 이 조합은 경쟁 제품 어디에도 통째로 없다.
- **v0.5.0 추가 우위**: 완전 오프라인·제로 구성 녹화(ShareX의 FFmpeg 다운로드 약점 해소) + 프레임→주석 편집기 브리지 + 녹화 결과의 갤러리·영속·재편집 승계.
- **포지셔닝 쐐기**: 무계정·무클라우드·완전 오프라인 — 규제·보안 환경(공공기관, 금융, 병원, 한국 기업 인트라넷)에서 강력.

## 5. 검증 상태

- MyCapture 기능·패키징: 코드/스크립트 직접 확인(검증됨).
- 경쟁 가격·기능: 웹 조사(대부분 공식 페이지/리뷰). 세부 수치는 시점에 따라 변동 가능.
- 성능 목표·온보딩·Korean OCR 정확도·일부 KR/JP 로컬 앱 커뮤니티 평판: **미검증(잠정)** — 실측/현물 확인 권장.
