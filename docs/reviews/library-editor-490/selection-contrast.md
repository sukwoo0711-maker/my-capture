# 선택 배경 대비 재측정

제품 ThemeCatalog 및 ThemeContrast로 계산했습니다. 배경 ARGB를 검정/흰색 바탕에 먼저 합성하고 전경을 합성한 뒤 WCAG 상대 휘도 비율을 계산합니다. 기존 감사와 같은 합성 순서입니다. Windows 사용자 시스템색은 읽지 않았습니다.

선택/기본 3:1 목표보다 글자 가독성을 우선한 요청의 예외를 적용했습니다. 모든 본문·보조·설명 글자가 4.5:1 이상이며 기존 글자 계층 대비도 유지합니다. 같은 색상 방향으로 배경을 한 단계 더 강하게 하면 설명 글자가 4.5:1 미만이 되는 경계를 자동 검사합니다. 선택 신호는 카드·폴더·날짜 목록의 2 DIP 강조색 테두리와 채운 체크가 맡습니다. 앱 HighContrast의 체크는 노랑/검정 쌍이며, Windows 고대비에서는 기존 Highlight/HighlightText와 Window/WindowText 사용자 설정 매핑을 보존합니다.

Surface.Selected를 공유하는 설정 체크박스와 편집 도구 선택 컨트롤도 실제 제품 템플릿으로 전후 렌더링했습니다. AS-IS는 같은 fixture에서 이전 토큰 값만 적용한 비교 화면이며, 설치 앱의 실사용 스크린샷은 아닙니다.
