# 핀 중심 30초 트레일러·세로 영상 구성

2026-10-20 홍보 방향을 개인정보 가리기에서 핀으로 바꾸면서 만든 Store 트레일러와 세로 영상의 장면 구성입니다. 영상의 이야기는 Store 목록과 같습니다. 코딩하는 동안 엑셀 사양 표와 자주 쓰는 코드를 에디터 위에 띄워 두고, 보면서 입력하다가 원문 그대로 붙여 넣습니다. 핀을 띄우는 키는 처음부터 끝까지 `F3` 하나입니다. 캡처 카드의 `P`와 트레이 메뉴의 '클립보드를 핀으로 띄우기'는 영상에 넣지 않습니다.

기존 30초 2판(`artifacts/promo-2026-10-18/source/video/film-v2-440`, 영어 `film-v2-en-440`)의 곡, 마디 표기, 키캡, 카메라, 렌더 경로를 그대로 씁니다. 바뀌는 것은 장면의 이야기와 앱 레이어입니다. 2판의 '고객 문의 화면을 캡처해 가리고 주석을 넣는' 장면은 쓰지 않습니다.

## 지켜야 할 사실

이 구성은 4.5.0 핀 흐름 수정(`feat/pin-core-flow-450`)이 들어간 앱을 기준으로 합니다. 새 설치에서 `F3`이 클립보드를 핀으로 띄우고, `Shift+F3`이 핀을 모두 숨기거나 다시 보이며, `F3`으로 띄운 핀은 에디터 포커스를 가져가지 않습니다. 4.4.0에는 이 기본값이 없으므로 트레일러는 4.5.0이 Store에 나갈 때 함께 바꿉니다.

- 핀에서 원문을 복사하는 키캡은 `Ctrl`+더블클릭을 씁니다(4.4.0과 4.5.0 모두 같은 동작). 4.5.0의 `Ctrl+C` 원문 복사로 바꿀 때는 핀을 먼저 눌러 포커스를 준 뒤 `Ctrl+C`를 누르는 동작으로 그립니다.
- 에디터에 붙여 넣는 `Ctrl+V`는 에디터의 동작이라 그대로 씁니다.
- 뒤 창 클릭 허용은 핀의 오른쪽 클릭 메뉴에서 켜고, 4.5.0 새 설치에서는 `Shift+F3`을 두 번 눌러 끕니다. 핀이 보여 주는 안내 문구가 그 경로를 그대로 적습니다.
- 장면 문구는 넣지 않고 키캡만 둡니다(2판과 같음). 엔드 카드 문구는 `MyCapture`, `무료 · Microsoft Store`(영어 `Free · Microsoft Store`)입니다.

카메라는 2판처럼 장면마다 한 지점으로만 다가갑니다. 장면 1은 표 핀, 장면 2는 입력 줄과 핀이 겹치는 곳, 장면 3은 핀과 붙여 넣은 다섯 줄, 장면 4는 안내 문구, 장면 5는 새로 붙은 핀입니다. 장면 5에서 캡처 직후 화면 구석에 뜨는 캡처 카드는 실제 앱에도 뜨지만, 카메라를 핀 쪽에 두어 카드를 이야기의 중심에 두지 않습니다.

## 앱 레이어

모든 레이어는 `MyCapture.exe --selftest-store-layers <폴더> ko|en`(`src/MyCapture.App/Diagnostics/StoreScreenshotSelfTest.PinLayers.cs`)이 Store 스크린샷과 함께 만듭니다. 2026-10-20 렌더본은 4.5.0 핀 흐름 브랜치 위에서 뽑은 `artifacts/store/layers/4.5.0-pin/{ko,en}`이며, 트레이 메뉴와 핀 안내에 `F3`·`Shift+F3`이 보입니다. 핀·메뉴는 실제 제품 창을 3배로 렌더한 것이고, 표 핀과 코드 핀은 메모리 안의 클립보드 데이터(엑셀처럼 그림·탭 구분 텍스트·HTML 표, 에디터처럼 색을 담은 HTML)를 제품의 클립보드 읽기 경로에 넣어 만든 것입니다. 시스템 클립보드와 사용자 데이터는 건드리지 않습니다. `manifest.json`의 `windowOpacity`는 창 투명도라서 장면에서 레이어의 불투명도로 적용합니다.

영상용 레이어는 `film/` 아래에 있습니다. `film/sheet.png`의 A1:D6 칸은 표 핀 그림과 같은 DIP 크기로 그려서, 시트에서 핀으로 넘어가는 전환에 같은 표가 겹칩니다. 핀 오른쪽 클릭 메뉴는 `menus/pin-context.png`, 핀을 숨긴 상태의 트레이 메뉴는 `film/tray-pins-hidden.png`입니다.

## 세로 영상

출시 확산 자료의 세로 영상(1080×1920, 약 19초, `docs/market/launch-4.4.0/video/make_vertical.py`)은 이 트레일러에서 장면 1·3·5를 골라 핀 둘레로 세로 자릅니다. 세 장면 모두 키캡이 `Ctrl+C`·`F3` 또는 `Ctrl+Shift+C`·`F3`으로 끝나므로, 세로 영상만 보는 사람도 'F3으로 띄운다'를 세 번 봅니다. 2판의 자르기 범위는 쓰지 않습니다. 장면마다 핀과 바로 아래 코드 줄이 세로 화면의 가운데 3분의 1에 오도록 범위를 새로 재고, 키캡은 아래쪽 안전 영역(아래에서 260px 위) 안에 둡니다.

## 렌더 순서

1. 4.5.0 핀 흐름 수정이 main에 들어가면 그 빌드에서 앱 레이어를 다시 뽑습니다.
2. `film-v2-440`을 복사해 `film-v3-pin`(영어 `film-v3-pin-en`)을 만들고 장면 스크립트 다섯 개를 위 표대로 바꿉니다. 곡·박자 지도(`music.js`)와 엔드 카드는 그대로 둡니다.
3. 정지 화면으로 각 장면의 키 입력 시점을 확인한 뒤 4K 렌더, Store용 1080p 인코딩(10MB 이하), 썸네일(장면 2의 반투명 표 핀이 코드 위에 떠 있는 프레임) 순서로 만듭니다. 이 PC에서 다른 작업이 메모리를 많이 쓰면 `WORKERS=3`으로 렌더합니다.
4. Store 트레일러 교체는 4.5.0 목록 제출에 함께 넣습니다. Partner Center 저장과 제출은 사용자 승인을 받은 뒤에 합니다.
