# MyCapture 2.2.1

라이브러리에서 이미지 편집이 열리지 않던 문제를 고치고, 2.1.1 이후 접수된 편집·단축키·폴더 선택 개선을 함께 제공합니다.

- 라이브러리에서 편집을 누르면 “이 캡처를 편집할 수 없습니다”와 함께 창이 열리지 않던 문제를 수정했습니다. 편집기가 이미 창의 내용인데 보존 기간 배너 패널에 다시 붙이면서 발생한 WPF 오류였습니다.
- 설정과 내보내기의 찾아보기가 “예기치 않은 오류”로 바로 실패하던 문제를 수정했습니다. .NET에서 폴더 선택 대화상자의 표시 이름 필드를 넘기지 못하던 마샬링 오류입니다.
- GitHub 이미지 URL 단축키 기본값을 F4에서 F9로 바꿨습니다. 이전에 F4만 쓰던 설정은 F9로 옮기고, 직접 바꾼 단축키는 그대로 둡니다.
- GitHub 이슈 주소는 github.com뿐 아니라 사내 GitHub(GitHub Enterprise Server)의 `https://호스트/소유자/저장소/issues/번호` 형식도 받습니다. HTTP는 허용하지 않습니다.
- 이미지 편집에 왼쪽·오른쪽 90도 회전(Q/W)을 추가했습니다. 주석 좌표도 함께 돌아가며, 글자는 읽기 쉽게 수평을 유지합니다. 180·270도는 같은 동작을 반복하면 됩니다.
- 상자·화살표 도구는 한 개를 그린 뒤에도 도구를 유지합니다. 연속으로 그릴 수 있습니다.
- 텍스트 상자의 기본 폭을 넓히고, 한 줄이 길어지면 캔버스 오른쪽까지 따라 늘어난 뒤에만 줄바꿈합니다. 글자 크기 슬라이더를 인스펙터에 추가했습니다.

F9로 GitHub 첨부 URL을 가져오려면 브라우저에서 GitHub에 로그인되어 있어야 하며, 업로드 중 해당 탭과 클립보드를 유지해야 합니다. 실제 로그인된 브라우저에서 붙여넣기부터 URL 복사까지 이어지는 검증은 환경에 따라 접근성 지원이 필요합니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
