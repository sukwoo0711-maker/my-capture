## Implementation details and limits

New captures create an in-memory identity/provenance record only. Explicit Done, copy, quick save and accepted Save As commit paths may create the durable record; automatic region clipboard copying does not. Save As cancellation remains before persistence. Confirmed records survive a later clipboard failure and retry with the same ID and advanced revision.

The capture preparation reserves one operation and awaits 100 ms without requiring dispatcher idle before acquisition. This provides compositor settling time; it is not a guarantee or measurement of DWM completion.

Notifications are bounded to one nonactivating, five-second WPF window, excluded from capture where supported and dismissed before still capture. Help uses the common window theme. Language selection saves settings and immediately changes tray/newly generated UI strings; already open windows may need reopening/restart. Last drawing tool, stroke colour/thickness/style and fill transparency persist through a debounced settings save; drawing content and undo history are not preferences.

UI focus, popup dismissal, multi-monitor placement and high-DPI visuals were not exercised locally. No packaged execution tests were run. The four added regression tests cover lease/writer distinction, pending-publication retry accounting, first-commit clipboard retry revision and serialized preference preservation.
