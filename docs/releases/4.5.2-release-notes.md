# MyCapture 4.5.2

4.5.2는 핀을 닫는 방법과 첫 실행 안내를 정리하고 설치 안내·Store 목록 문서를 실제 동작에 맞춘 업데이트입니다. 4.5.1의 편집기 '응답 없음' 해결, 핀 글자 선택, 핀 저장 암호화는 그대로 들어 있습니다.

Microsoft Store 배포용 패키지 버전은 `4.5.2.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 핀

- 새로 설치해도 핀을 더블클릭하면 닫힙니다. 4.5.0에서는 새 설치에서 이 동작을 꺼 두었습니다.
- 4.5.0이나 4.5.1을 새로 설치해 쓰고 있다면 설정 파일에 꺼진 값이 남아 있습니다. 더블클릭으로 닫으려면 설정 → 편집 → 핀에서 '더블클릭으로 핀 닫기'를 켜십시오. Esc와 닫기 버튼은 계속 동작합니다.

## 처음 실행

- 4.5.1에서 환영 화면에 넣은 F3 안내 줄을 뺐습니다. 처음 실행할 때 나오는 핵심 단축키 질문이 F3을 안내합니다.

## 문서

- 설치 안내의 라이브러리 정리 기본값(새 설치는 기간 제한 없이 1,000개·5 GiB)과 OCR 모델을 받는 시점을 실제 동작에 맞췄습니다.
- Store 목록 초안을 핀 중심으로 다듬고, 4.5.2의 새로운 기능을 적었습니다.

## 데이터

- 설정, 캡처, 라이브러리, 색인, 열린 핀 저장 형식은 4.5.1과 같습니다.

편집기 '응답 없음' 해결과 핀 글자 선택 같은 이전 변경은 [4.5.1](4.5.1-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
