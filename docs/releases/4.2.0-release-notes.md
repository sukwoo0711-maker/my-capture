# MyCapture 4.2.0

4.2.0은 라이브러리 검색·정리·가져오기, 이미지 재편집과 내보내기, 녹화 구간 편집을 확장하고, 앱 아이콘과 포인트 색을 새로 정한 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.2.0.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 앱 아이콘과 화면

- 앱 아이콘을 새로 그렸습니다. 흑연색 타일 위의 흰 선택 프레임은 캡처 영역을, 프레임 중심을 향해 꽂힌 빨간 압정은 화면 위 고정(핀)을 나타냅니다. 작업 표시줄, 창 제목 표시줄, 시작 메뉴, Microsoft Store 아이콘에 같은 마크를 사용합니다.
- 트레이 아이콘이 16px 칸을 채우도록 다시 그려 밝은 작업 표시줄과 어두운 작업 표시줄에서 더 잘 보입니다. 캡처·녹화 중에는 초록 점, 처리 중에는 파란 모래시계, 오류가 있을 때는 노란 경고 표시가 압정 자리에 나타납니다.
- 설정의 테마 옆에 **포인트 색**을 추가했습니다. 기본값 **바이올렛**과 **레드** 중에서 고를 수 있으며, 모든 테마에 적용합니다. 고대비 테마에서는 시스템 색을 따릅니다. 캡처 안내선은 따로 색을 지정하지 않았다면 포인트 색을 따릅니다.
- 앱 전체에서 명령 버튼의 높이와 모양을 통일했습니다. 편집기 명령 막대의 버튼은 아이콘, 이름, 단축키를 함께 표시합니다.

## 라이브러리

- 검색할 필드를 지정할 수 있습니다. `app:`·`앱:`, `title:`·`제목:`, `tag:`·`태그:`, `text:`·`글자:`, `url:`·`주소:`, `folder:`·`폴더:`, `type:`·`종류:`, `pinned:`·`보관:`, `date:`·`날짜:`를 지원합니다. `앱:Edge 태그:회의 글자:"월 매출"`처럼 조건을 함께 쓰거나 `-태그:임시`로 제외할 수 있습니다. 날짜는 `2026-10` 또는 `2026-10-14` 형식으로 지정합니다.
- 입력한 검색 조건을 칩으로 표시하고 하나씩 지울 수 있습니다. 검색 결과가 없으면 “검색 조건 때문에 N개가 숨겨져 있습니다.”로 숨겨진 항목 수를 안내하며, 결과 카드에는 제목·태그·이미지 속 글자 등 어떤 필드가 일치했는지 표시합니다.
- 탐색 창의 **태그** 목록에서 태그별 캡처 수를 확인하고 해당 태그로 모아 볼 수 있습니다. 여러 캡처를 선택한 뒤 **태그 편집**에서 태그를 한 번에 추가하거나 제거할 수 있습니다.
- 파일 탐색기에서 PNG·JPEG·MP4 파일을 라이브러리로 끌어 놓거나 **가져오기…**로 선택해 가져올 수 있습니다. 원본 파일은 그대로 두고 복사하며, 파일 내용이 같은 중복 항목은 건너뜁니다.
- **PDF로 묶기**로 선택한 이미지를 한 페이지에 여러 장씩 배치한 PDF로 저장할 수 있습니다. 용지 크기, 배치와 캡션을 선택하고 미리보기를 확인할 수 있으며, 동영상은 제외합니다.
- 이미지 두 장을 선택한 뒤 **비교**로 열 수 있습니다. **나란히**와 **겹쳐 보기**를 지원하며, **확대·이동 함께**로 두 이미지의 확대와 이동을 맞출 수 있습니다. Ctrl+Shift+S로 좌우를 교환하고 Tab·Shift+Tab으로 화면의 조작 항목 사이를 이동합니다.
- 새 폴더를 만들어도 지금 보던 위치와 검색 조건을 유지하고, 탐색 창에서 새 폴더를 선택해 보여 줍니다.
- 폴더 안에서 Backspace, 마우스 뒤로 버튼, Alt+←로 상위 폴더로 이동합니다. 마우스 앞으로 버튼과 Alt+→로 다시 앞 위치로 돌아갑니다.
- 선택 명령 막대에는 **ZIP 내보내기**, **이동**, **삭제**를 바로 표시합니다. **비교**는 이미지 두 장을 선택했을 때만 나타나며, PDF·태그·파일 크기 줄이기·GIF는 더보기 메뉴에서 실행합니다.
- 자주 쓰는 검색 조건을 **저장된 검색**에 저장하고 이름을 바꾸거나 삭제할 수 있습니다.
- 캡처·폴더 이동, 태그 편집, 보관, 제목 변경을 Ctrl+Z로 되돌릴 수 있습니다. 앱을 실행하는 동안 최근 50단계까지 되돌립니다.
- 가져오기, ZIP·폴더 내보내기, PDF 만들기, 텍스트 인식 진행 상황을 상태 표시줄에 표시하고, 지원하는 작업은 취소할 수 있습니다.
- Office, 메모장, PDF 뷰어(Acrobat·Foxit·SumatraPDF), VS Code에서 캡처하면 **출처**에 문서 파일 경로를 표시하고 **파일 열기**와 **파일 위치 열기**를 제공합니다. 저장하지 않은 문서는 **저장되지 않은 문서**로 표시합니다. 문서 경로는 이 PC의 라이브러리에만 저장하며, 내보내는 파일에는 넣지 않습니다.

## 캡처

- Ctrl+Shift+C로 색을 복사하면 캡처를 바로 끝내고, 알림에 복사한 색의 견본과 값을 함께 표시합니다. 복사에 실패하면 캡처 화면을 그대로 둡니다.
- 라이브러리에서 캡처나 녹화를 시작하면 라이브러리 창이 화면에서 완전히 사라진 뒤에 시작해, 녹화 첫 화면에 창의 잔상이 남지 않습니다.

## 이미지 편집기

- 선택 도구로 드래그하면 범위에 걸친 주석을 함께 선택합니다. Shift·Ctrl 클릭으로 하나씩 추가하거나 빼고, Ctrl+A로 모두 선택하며, Esc로 선택을 해제합니다.
- 선택한 주석을 함께 이동·삭제하고 Ctrl+D로 복제할 수 있습니다. 방향키로 1px씩, Shift+방향키로 10px씩 옮기고, Ctrl+]·Ctrl+[로 앞뒤 순서를 바꿉니다. 색, 선 두께, 선 종류, 채우기는 선택한 주석에 함께 적용합니다.
- Shift를 누른 채 그리면 정사각형·원과 45° 단위의 화살표가 됩니다. Ctrl+Shift+Z로 다시 실행할 수 있습니다.
- 도구 막대는 아이콘과 단축키를 항상 함께 표시하고, 선택한 도구는 칸 전체를 채워 표시합니다. 회전 버튼은 명령 막대의 더보기(…) 메뉴로 옮겼습니다.
- 텍스트 외곽선을 글자 색과 관계없이 같은 얇은 선으로 그립니다. 아주 어두운 글자에만 밝은 외곽선을 사용하며, 이전에 만든 텍스트는 원래 모양을 유지합니다.
- 텍스트 속성에서 글꼴, 크기, 굵게, 배경 판, 외곽선을 지정할 수 있습니다. 텍스트를 선택하지 않고 텍스트 도구에서 고른 값은 다음 텍스트의 기본값이 됩니다. 글꼴 목록은 설치된 글꼴을 미리보기와 함께 보여 주므로, Maple Mono처럼 직접 설치한 글꼴도 고를 수 있습니다.
- 확정한 텍스트를 선택 도구에서 더블클릭하거나, 선택한 뒤 F2를 누르거나, 텍스트 도구로 클릭해 다시 수정할 수 있습니다.
- 선택한 텍스트의 **굵게**와 **배경 판**을 켜거나 끌 수 있습니다. 텍스트 입력은 Ctrl+Enter로 완료하고 Enter로 줄을 바꾸며 Esc로 취소합니다.

## 내보내기

- **이미지 내보내기**에서 **형식**을 **자동 · PNG/JPEG**, **PNG**, **JPEG** 중 선택하고 **이미지 긴 변**의 최대 길이를 지정할 수 있습니다. 작은 이미지는 확대하지 않습니다.
- **프리셋**에서 **마지막 설정**, **원본**, **메신저용 · 1280px · JPEG**, **문서용 · 1920px · PNG**를 선택할 수 있습니다.
- **꾸미기**에서 **여백**, **모서리 반경**, **배경**, **부드러운 그림자**를 조절해 내보낼 이미지를 꾸밀 수 있습니다. 라이브러리 원본에는 적용하지 않습니다.
- **출처 URL 포함**은 기본적으로 꺼져 있습니다. ZIP·폴더 내보내기, **다른 이름으로 저장…**, **이미지 내보내기**에 적용하며, 선택하지 않으면 내보내는 PNG에서 출처 URL 메타데이터를 제외합니다. ZIP·폴더 내보내기와 **다른 이름으로 저장…**에서도 **이미지 긴 변**을 지정할 수 있습니다.
- **ZIP 내보내기** 안내를 실제 내용에 맞게 수정했습니다. 편집한 PNG·현재 MP4와 폴더 구조를 포함하고 파일명에 캡처 제목을 사용하며, PNG의 출처 URL은 **출처 URL 포함**을 선택했을 때 포함합니다. 별도 원본 이미지·인식 텍스트·태그·설정 파일은 제외하며, 이미지에 보이는 내용은 유지합니다.

## 녹화 편집기

- 남길 구간은 진행 막대의 손잡이, I·O 키, 시작·끝 시간 입력으로 지정합니다. **여기서 시작**과 **여기서 끝** 버튼은 없앴습니다.
- 편집 버튼에 이름을 함께 표시하고, **자르기**와 **분할**을 서로 다른 아이콘으로 구분했습니다. 창이 좁으면 자주 쓰지 않는 도구는 더보기 메뉴로 옮깁니다.
- 라이브러리에 편집 내용을 저장할 때 진행 막대와 진행률, 예상 남은 시간, 취소 버튼을 표시합니다. 인코딩이 끝난 뒤 저장을 마무리하는 단계도 구분해 표시합니다.
- 타임라인에 마우스를 올리면 해당 위치의 시간을 표시합니다. 레이어 행은 확대된 타임라인과 같은 시간축으로 정렬합니다.
- 레이어를 이동하거나 길이를 조절할 때 재생 위치, 남길 구간의 시작·끝, 다른 레이어의 경계에 자동으로 맞춥니다. Alt를 누르면 자동 맞춤을 잠시 해제합니다.
- **분할** 또는 Ctrl+K로 재생 위치에서 구간을 나눈 뒤, 구간을 클릭하거나 재생 위치에서 Enter로 선택하고 Delete로 제거할 수 있습니다. 잘린 구간을 선택해 **되돌리기 구간**으로 복원하거나 Ctrl+Z로 편집을 되돌릴 수 있습니다.
- 미리보기 재생은 잘린 구간을 건너뛰며, MP4·GIF 내보내기에도 남긴 구간만 이어서 반영합니다. 원본 녹화는 보존합니다.

## 데이터

- 기존 라이브러리와 녹화 편집 내용은 별도 작업 없이 그대로 열립니다. 가져온 파일의 원래 이름과 중복 확인 정보는 라이브러리 목록에 함께 저장합니다. 기존 캡처의 중복 확인 정보는 앱을 시작할 때 한꺼번에 만들지 않고, 크기가 같은 파일을 가져올 때만 계산합니다.
- 4.1.5로 되돌려도 4.2.0에서 저장한 라이브러리 목록과 폴더·태그·보관 상태를 그대로 읽습니다. 다만 4.1.5에서 라이브러리를 다시 저장하면 가져온 파일의 원래 이름과 중복 확인 정보, 저장된 검색이 빠지고, 4.2.0으로 다시 올리면 해당 항목은 일반 캡처처럼 표시됩니다.
- 4.2.0에서 분할하거나 구간을 삭제한 녹화의 편집 정보는 4.1.5에서 열 수 없습니다.

이전 업데이트의 패키지 검사 수정과 캡처 선택 화면 개선은 [4.1.5](4.1.5-release-notes.md), [4.1.4](4.1.4-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
