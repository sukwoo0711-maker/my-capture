# MyCapture 4.2.0

4.2.0은 라이브러리 검색·정리·가져오기, 이미지 재편집과 내보내기, 녹화 구간 편집을 확장한 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.2.0.0`입니다. GitHub 릴리스의 포터블 zip은 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오.

## 라이브러리

- 검색할 필드를 지정할 수 있습니다. `app:`·`앱:`, `title:`·`제목:`, `tag:`·`태그:`, `text:`·`글자:`, `url:`·`주소:`, `folder:`·`폴더:`, `type:`·`종류:`, `pinned:`·`보관:`, `date:`·`날짜:`를 지원합니다. `앱:Edge 태그:회의 글자:"월 매출"`처럼 조건을 함께 쓰거나 `-태그:임시`로 제외할 수 있습니다. 날짜는 `2026-10` 또는 `2026-10-14` 형식으로 지정합니다.
- 입력한 검색 조건을 칩으로 표시하고 하나씩 지울 수 있습니다. 검색 결과가 없으면 “검색 조건 때문에 N개가 숨겨져 있습니다.”로 숨겨진 항목 수를 안내하며, 결과 카드에는 제목·태그·이미지 속 글자 등 어떤 필드가 일치했는지 표시합니다.
- 탐색 창의 **태그** 목록에서 태그별 캡처 수를 확인하고 해당 태그로 모아 볼 수 있습니다. 여러 캡처를 선택한 뒤 **태그 편집**에서 태그를 한 번에 추가하거나 제거할 수 있습니다.
- 파일 탐색기에서 PNG·JPEG·MP4 파일을 라이브러리로 끌어 놓거나 **가져오기…**로 선택해 가져올 수 있습니다. 원본 파일은 그대로 두고 복사하며, 파일 내용이 같은 중복 항목은 건너뜁니다.
- **PDF로 묶기**로 선택한 이미지를 한 페이지에 여러 장씩 배치한 PDF로 저장할 수 있습니다. 용지 크기, 배치와 캡션을 선택하고 미리보기를 확인할 수 있으며, 동영상은 제외합니다.
- 이미지 두 장을 선택한 뒤 **비교**로 열 수 있습니다. **나란히**와 **겹쳐 보기**를 지원하며, **확대·이동 함께**로 두 이미지의 확대와 이동을 맞출 수 있습니다. Ctrl+Shift+S로 좌우를 교환하고 Tab·Shift+Tab으로 화면의 조작 항목 사이를 이동합니다.

## 이미지 편집기

- 확정한 텍스트를 선택 도구에서 더블클릭하거나, 선택한 뒤 F2를 누르거나, 텍스트 도구로 클릭해 다시 수정할 수 있습니다.
- 선택한 텍스트의 **굵게**와 **배경 판**을 켜거나 끌 수 있습니다. 텍스트 입력은 Ctrl+Enter로 완료하고 Enter로 줄을 바꾸며 Esc로 취소합니다.

## 내보내기

- **이미지 내보내기**에서 **형식**을 **자동 · PNG/JPEG**, **PNG**, **JPEG** 중 선택하고 **이미지 긴 변**의 최대 길이를 지정할 수 있습니다. 작은 이미지는 확대하지 않습니다.
- **프리셋**에서 **마지막 설정**, **원본**, **메신저용 · 1280px · JPEG**, **문서용 · 1920px · PNG**를 선택할 수 있습니다.
- **꾸미기**에서 **여백**, **모서리 반경**, **배경**, **부드러운 그림자**를 조절해 내보낼 이미지를 꾸밀 수 있습니다. 라이브러리 원본에는 적용하지 않습니다.
- **출처 URL 포함**은 기본적으로 꺼져 있습니다. ZIP·폴더 내보내기, **다른 이름으로 저장…**, **이미지 내보내기**에 적용하며, 선택하지 않으면 내보내는 PNG에서 출처 URL 메타데이터를 제외합니다. ZIP·폴더 내보내기와 **다른 이름으로 저장…**에서도 **이미지 긴 변**을 지정할 수 있습니다.
- **ZIP 내보내기** 안내를 실제 내용에 맞게 수정했습니다. 편집한 PNG·현재 MP4와 폴더 구조를 포함하고 파일명에 캡처 제목을 사용하며, PNG의 출처 URL은 **출처 URL 포함**을 선택했을 때 포함합니다. 별도 원본 이미지·인식 텍스트·태그·설정 파일은 제외하며, 이미지에 보이는 내용은 유지합니다.

## 녹화 편집기

- 라이브러리에 편집 내용을 저장할 때 진행 막대와 진행률, 예상 남은 시간, 취소 버튼을 표시합니다. 인코딩이 끝난 뒤 저장을 마무리하는 단계도 구분해 표시합니다.
- 타임라인에 마우스를 올리면 해당 위치의 시간을 표시합니다. 레이어 행은 확대된 타임라인과 같은 시간축으로 정렬합니다.
- 레이어를 이동하거나 길이를 조절할 때 재생 위치, 남길 구간의 시작·끝, 다른 레이어의 경계에 자동으로 맞춥니다. Alt를 누르면 자동 맞춤을 잠시 해제합니다.
- **분할** 또는 Ctrl+K로 재생 위치에서 구간을 나눈 뒤, 구간을 클릭하거나 재생 위치에서 Enter로 선택하고 Delete로 제거할 수 있습니다. 잘린 구간을 선택해 **되돌리기 구간**으로 복원하거나 Ctrl+Z로 편집을 되돌릴 수 있습니다.
- 미리보기 재생은 잘린 구간을 건너뛰며, MP4·GIF 내보내기에도 남긴 구간만 이어서 반영합니다. 원본 녹화는 보존합니다.

## 데이터

- 기존 라이브러리와 녹화 편집 내용은 별도 작업 없이 그대로 열립니다. 가져온 파일의 원래 이름과 중복 확인 정보는 라이브러리 목록에 함께 저장합니다. 기존 캡처의 중복 확인 정보는 앱을 시작할 때 한꺼번에 만들지 않고, 크기가 같은 파일을 가져올 때만 계산합니다.
- 4.1.5로 되돌려도 4.2.0에서 저장한 라이브러리 목록과 폴더·태그·보관 상태를 그대로 읽습니다. 다만 4.1.5에서 라이브러리를 다시 저장하면 가져온 파일의 원래 이름과 중복 확인 정보가 빠지고, 4.2.0으로 다시 올리면 해당 항목은 일반 캡처처럼 표시됩니다.
- 4.2.0에서 분할하거나 구간을 삭제한 녹화의 편집 정보는 4.1.5에서 열 수 없습니다.

이전 업데이트의 패키지 검사 수정과 캡처 선택 화면 개선은 [4.1.5](4.1.5-release-notes.md), [4.1.4](4.1.4-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
