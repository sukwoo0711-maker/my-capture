# MyCapture 3.1.0

캡처를 편집하기 전에 라이브러리에 보관하고, 캡처한 문서의 창 제목을 함께 기록합니다.

- **캡처 즉시 라이브러리 저장**: Ctrl+Shift+C로 영역을 선택하면 원본 저장을 마친 뒤 편집창을 엽니다. Esc로 편집창을 닫아도 캡처는 라이브러리에 남습니다. 편집을 저장하면 같은 항목의 편집 결과를 갱신합니다.
- **문서와 창 제목 기록**: 캡처 선택창이 뜨기 전에 대상 창 제목을 확보해 라이브러리 표시와 검색에 사용합니다. Excel 문서나 VS Code 파일·프로젝트는 해당 앱이 제공하는 창 제목으로 기록됩니다.
- **제목을 활용한 파일명**: 빠른 저장 파일명에 `{title}`을 사용할 수 있습니다. 새 설정의 기본값은 `{title}_{yyyyMMdd}_{HHmmss}`이며 기존 사용자 지정 패턴은 유지됩니다. 파일명 금지 문자, 긴 제목과 이름 충돌을 처리합니다.
- **큰 녹화 영역의 조작 막대**: 녹화 조작 막대를 실제 모니터의 작업 영역 안에 배치합니다. 큰 영역이나 여러 모니터를 걸친 영역에서도 버튼을 한곳에서 찾을 수 있습니다.
- **영상 편집창의 모니터 크기 대응**: 넓은 주 모니터에서 계산한 편집창이 좁은 보조 모니터를 벗어나던 문제를 수정했습니다. 큰 영상을 열어도 편집창을 표시할 모니터의 작업 영역에 맞춰 저장·재생 버튼에 접근할 수 있습니다.
- **라이브러리 정리**: 캡처 제목·태그를 편집하고, 폴더·태그·선택 항목으로 모아 보며 미디어 파일을 ZIP으로 내보낼 수 있습니다. 제목·태그·창 제목·인식된 텍스트를 검색합니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
