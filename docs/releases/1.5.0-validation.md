# MyCapture 1.5.0 검증 기록

검증 기준일: 2026-09-03 (Asia/Seoul)

대상: Windows 11 21H2(build 22000) 이상, x64

배포 계약: self-contained, offline, unsigned, MIT

## 릴리스 경계

- 영역 캡처는 `Ctrl+Shift+C`, 화면 영역 녹화 시작·중지는 `Ctrl+Shift+X`, 라이브러리는 `Ctrl+Shift+Z`를 기본값으로 사용합니다.
- 이전 스키마의 정확한 기본 녹화 키 `Ctrl+X`만 `Ctrl+Shift+X`로 마이그레이션하고 사용자 지정 단축키는 보존합니다.
- 앱·트레이 아이콘은 16·20·24·32·40·48·64·128·256px 엔트리를 모두 포함합니다.
- 유휴·캡처·작업 중·오류 트레이 상태는 서로 다른 아이콘 자산을 사용합니다.
- Graphite/Focus Blue 디자인 토큰, 네이티브 창 크롬, 라이브러리와 편집기 컨트롤이 동일한 시각 체계를 사용합니다.
- 영상 편집 타임라인은 자르기 삭제 영역, 재생 헤드, 텍스트 레이어와 프레임 레이어를 의미 색상으로 구별합니다.

## 패키지 무결성 및 출처

`build/package.ps1 -Version 1.5.0`은 깨끗한 Git 작업 트리에서만 실행되며 다음을 보장합니다.

- `win-x64` CoreCLR/WPF를 포함한 완전한 self-contained publish
- 설치 payload와 portable ZIP의 경로·크기·SHA-256 inventory 검증
- ZIP traversal, 중복 경로, reparse point 및 symlink 방어
- 설치·업데이트 실패 시 rollback과 사용자 데이터 보존
- 패키지 시작과 종료 때 동일한 정확한 Git 커밋인지 재검증
- `release-manifest.json`에 source commit과 clean-tree 상태 기록
- 게시 파일 SHA-256을 `SHA256SUMS.txt`에 기록

## 알려진 제한

- Authenticode 서명이 없어 Windows가 알 수 없는 게시자 경고를 표시할 수 있습니다.
- Windows 10은 지원하지 않습니다.
- 라이브러리 내 동영상 재생은 의도적으로 무음이며 녹음·음악 편집 기능을 포함하지 않습니다.
- 조직 보안 정책이 IExpress 또는 PowerShell 설치 경로를 막는 경우 portable ZIP을 사용해야 합니다.
