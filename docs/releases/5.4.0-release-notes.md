# MyCapture 5.4.0

5.4.0은 그림 핀의 글자 선택과 핀 정리, 핀 번역의 품질과 안내, 선택 화면의 창 안 요소 선택과 자유형 영역을 더하고, 출처 열기와 PDF 순서, 워터마크를 고치고, 설치 파일 크기를 줄인 업데이트입니다.

5.3.1 이후의 변경을 담았습니다. 5.3.1의 변경은 [5.3.1 릴리스 노트](5.3.1-release-notes.md)에서 확인할 수 있습니다.

## 캡처 선택 화면

- 창 위에서 휠을 앞으로 굴리면(또는 `PgDn`) 포인터 아래 가장 작은 UI 요소가 강조되고, 클릭하면 그 요소만 캡처합니다. 휠을 뒤로 굴리면(`PgUp`) 한 단계씩 넓어집니다. 휠을 굴리기 전에는 기존처럼 창 단위로 동작합니다.
- 선택 영역이 없을 때 `Enter`를 누르면 강조 중인 창, 모니터, 요소를 캡처합니다. 전에는 아무 일도 없었습니다.
- `F`나 모드 막대의 `자유형`으로 자유형 영역을 캡처합니다. 누른 채 끌고 놓으면 시작점까지 닫아 캡처하며, 윤곽 바깥은 투명한 PNG로 저장됩니다. JPEG, PDF, 클립보드의 옛 Bitmap 형식에서는 투명한 곳을 흰 바탕으로 채웁니다. 텍스트 복사와 녹화 영역 선택에서는 쓸 수 없습니다.
- 녹화 영역 선택 화면이 전경으로 올라오지 못했을 때도 영역을 고르기 전에 `Esc`로 취소됩니다.
- 배율이 다른 모니터 사이를 넘을 때 단축키 안내판이 튕기고 크기가 두 번 보정되던 문제를 고쳤습니다. 보조 창이 요청한 자리에 닿지 못해도 선택이 끝나지 않습니다.

## 핀

- 그림 핀에서 `F2`(또는 오른쪽 클릭 메뉴의 `글자 선택`)를 누르면 글자를 인식하고, 텍스트 핀처럼 끌어서 고른 부분만 `Ctrl+C`로 복사합니다. 인식은 `F2`를 누를 때만 하고 결과는 핀을 닫으면 버립니다.
- `Shift+더블클릭`이나 오른쪽 클릭 메뉴의 `접기`로 핀을 작은 미리 보기로 접고, 더블클릭이나 `펼치기`로 되돌립니다. 접힌 상태는 다음 실행의 핀 복원에도 남습니다.
- 핀을 끌 때 작업 영역 가장자리나 다른 핀에 가까워지면 붙습니다. `Shift`를 누른 동안은 붙지 않고, `설정` → `핀` → `끌 때 가장자리와 다른 핀에 붙이기`로 끌 수 있습니다. 기본값은 켜짐입니다.
- 휠이나 `+`·`-`로 확대·축소할 때 크기가 부드럽게 바뀌고 100%에서 한 번 멈춥니다. Windows의 애니메이션 설정이 꺼져 있으면 즉시 바뀝니다.
- 새로 설치하거나 `기본값으로 재설정`하면 닫은 핀 다시 열기의 기본 키가 `Ctrl+Shift+F3`입니다. 기존 설정 파일의 지정 키는 그대로입니다.
- 클립보드에서 만든 그림 핀은 모니터 작업 영역에 들어가면 100% 크기로 띄웁니다. 전에는 80%를 넘으면 줄였습니다. 코드 핀은 복사한 편집기의 글자 크기를 따릅니다.
- 복사가 무엇을 넣는지 알림, 메뉴, 툴팁에 `텍스트와 이미지 복사됨`, `이미지 복사됨`으로 표시하고, 글자가 함께 들어가는 핀의 메뉴에 `이미지만 복사`를 더했습니다. 클립보드에 넣는 내용은 그대로입니다.
- `설정` → `핀` → `그림 핀을 적은 메모리로 띄우기`를 켜면 그림 핀을 가벼운 창으로 띄웁니다. 기본값은 꺼짐입니다. 글자 선택, 번역, 접기를 시작하면 그 핀은 일반 핀으로 바뀝니다. 개발 PC에서 설정만 바꿔 핀 10개를 띄우고 늘어난 메모리를 핀 수로 나눈 값은 1600×1000 그림이 41.3 MB에서 27.5 MB, 3840×2160 그림이 235.4 MB에서 95.5 MB입니다.

## 문자 인식과 번역

- 글자를 인식하는 모든 경로에서 그림 속 QR 코드와 바코드(QR, Data Matrix, Aztec, PDF417, EAN-13, EAN-8, UPC-A, Code 128)의 내용을 인식 결과의 한 줄로 넣습니다. 판독은 이 PC 안에서 하고 내용을 열거나 실행하지 않습니다.
- 핀 번역을 누르면 빛 띠가 한 번 지나가고, 번역이 끝난 블록부터 글자가 제자리에서 바뀝니다. Windows의 애니메이션 설정이 꺼져 있으면 즉시 바뀝니다.
- 번역문 글자 크기가 원문과 같아지고, 필요 이상으로 넓어지거나 바탕색이 다른 곳에 색 조각이 남던 문제를 고쳤습니다.
- 맞게 번역한 문장을 숫자·날짜 확인 단계에서 버리던 문제를 고쳤습니다. nine를 9시로, November를 11월로 옮긴 것을 같은 값으로 봅니다. 짧은 문단은 통째로 번역합니다. 쉬운 영어 60문장의 제품 출력은 맞음 38개에서 45개로, 틀림 9개에서 1개로 바뀌었습니다.
- 한국어 인식 팩만 있는 PC에서 영어 그림의 `alSO`, `t0` 같은 오인식을 원본 픽셀로 바로잡습니다. 합성 그림 360쪽의 낱말 정확도는 배율 100%에서 78.0%에서 81.5%로 올랐습니다.
- 번역 모델을 처음 받을 때 받은 양을 보여 주고, 번역 명령을 다시 누르면 `번역 취소`로 멈출 수 있습니다. 실패하면 이유를 알려 주고, 그림 핀은 `글자 읽는 중`을 보여 줍니다.

## 라이브러리와 출처

- `출처 열기`가 캡처한 문서와 주소를 그대로 엽니다. 문서는 캡처한 앱으로, 웹 주소는 캡처한 브라우저로 엽니다. 제목에 파일 이름만 있는 문서의 경로는 Windows 최근 항목과 VS Code의 선택 탭에서 찾아 이 PC의 라이브러리에만 기록합니다.
- 카드와 상세에 출처 앱의 아이콘을 보여 줍니다.
- 항목 메뉴와 결과 카드의 오른쪽 클릭 메뉴에 `연결 프로그램`을 더했습니다. Windows가 권하는 프로그램으로 캡처의 복사본을 열고 원본은 건드리지 않습니다. 결과 카드의 오른쪽 클릭 메뉴는 새로 생겼습니다.
- `PDF로 만들기`에서 이미지 순서를 끌어서, `Alt+↑/↓`로 바꾸고, 이번 내보내기에서 뺄 이미지를 고를 수 있습니다. 촬영 시각과 제목순 정렬도 됩니다.
- 출처 아이콘 캐시가 한도를 넘으면 오래된 아이콘을 휴지통으로 보냅니다. 전에는 바로 지웠습니다.

## 이미지 편집기

- 워터마크를 바탕에 스미게 그리는 `바탕에 스밈`을 더하고 기본값으로 했습니다. 기본 세기는 20%이고, 이미 만든 워터마크도 바뀝니다. 이 방식에서는 로고가 단색으로 그려집니다. 색을 살리려면 워터마크 단추의 오른쪽 클릭 메뉴 `표시 방식`에서 `위에 겹침`을 고릅니다.

## 설치

- 쓰지 않는 파일을 빼고 Windows 프로젝션 DLL을 줄였습니다. 5.3.1과 견주어 x64 포터블 ZIP은 141 MB에서 118 MB로, x64 설치 파일은 137 MB에서 116 MB로, 설치 뒤 x64 폴더는 311 MB에서 246 MB로 줄었습니다.

## 그 밖의 수정

- 캡처 카드, 알림 창, 녹화 워터마크 창이 요청한 위치에 닿지 못해도 오류 창으로 이어지지 않고 Windows가 둔 자리에 남습니다.
- Windows 10 배율 125%에서 영어 저장 탭의 안내 단추가 한 픽셀 위에 서던 것을 고쳤습니다.
