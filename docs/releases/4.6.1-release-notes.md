# MyCapture 4.6.1

4.6.1은 설치와 업데이트를 다듬고, 4.6.0 편집기와 글자 인식(OCR)에서 받은 지적을 고친 업데이트입니다. 새 버전이 나오면 앱이 알려 주고, 버튼 하나로 설치할 수 있습니다.

Microsoft Store 배포용 패키지 버전은 `4.6.1.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 설치와 업데이트

- 설치 파일을 실행하면 명령 창 대신 진행 막대가 있는 작은 창이 뜹니다. 파일 확인, 파일 복사, 시작 메뉴 등록 같은 실제 단계를 보여 주고, 끝나면 'MyCapture 실행'을 고른 채 [마침]을 누르면 바로 시작합니다.
- 설치하지 못하면 이유를 한 문장으로 알려 주고 [로그 열기]를 둡니다. 예를 들어 다른 MyCapture가 실행 중이면 트레이 메뉴에서 종료한 뒤 다시 실행하라고 안내합니다.
- 제거도 같은 창으로 진행합니다. 저장한 캡처와 설정은 지우지 않습니다.
- 새 버전을 자동으로 확인합니다. 앱을 켜고 약 2분 뒤 처음 확인하고, 그 뒤로는 하루에 한 번 확인합니다. 캡처, 녹화, 편집 중에는 끝날 때까지 미룹니다.
- 새 버전이 있으면 라이브러리와 설정 창에 새 버전을 설치할 수 있다는 카드가 나오고, 트레이 메뉴에 '업데이트 설치'가 생깁니다. GitHub 설치본은 카드에 버전 번호를 함께 보여 줍니다. Microsoft Store는 새 버전 번호를 알려 주지 않으므로 Store 설치본은 번호 없이 보여 줍니다. 카드를 닫으면 같은 새 버전은 다시 알리지 않습니다.
- [업데이트]를 누르면 설치 방식에 따라 다음처럼 진행합니다.
  - Microsoft Store 설치본은 Store 설치 화면으로 업데이트합니다.
  - GitHub 설치 파일로 설치했다면 앱이 새 설치 파일을 내려받아 SHA-256으로 확인합니다. 저장하지 않은 편집이나 진행 중인 녹화가 있으면 먼저 어떻게 할지 묻습니다. 앱이 닫히면 'MyCapture 업데이트 중' 창이 업데이트를 마치고 앱을 다시 엽니다. 실패하면 이전 버전으로 되돌리고 [MyCapture 열기]를 보여 줍니다.
  - 포터블 zip은 브라우저로 GitHub 릴리스 페이지를 엽니다.
- 업데이트한 뒤 처음 창을 열면 'X 버전으로 업데이트됨'을 한 번 보여 줍니다. GitHub 설치본도 이제 이 안내를 받습니다.
- 자동 확인을 끄려면 설정 → 정보에서 '새 버전 자동 확인'을 끄십시오. 같은 화면의 '업데이트 확인'으로 직접 확인할 수 있습니다.
- 4.6.0 이전 GitHub 설치본에는 업데이트 확인 기능이 없습니다. 4.6.1은 한 번 직접 설치하십시오. 그다음 버전부터 앱이 알려 줍니다.
- Microsoft Store 평가 요청은 캡처를 5번 성공하고 하루가 지난 뒤 한 번만 묻습니다. 지금까지는 10번, 3일이었습니다.

## 편집기

- 명령과 도구 단추는 평소에 아이콘을 가운데에 크게 보여 줍니다. Alt를 누르는 동안에는 아이콘이 작아지며 올라가고 단축키가 나타납니다. Alt를 누른 창에만 적용합니다.
- Alt만 눌렀다 뗀 뒤 다음 키가 무시되던 문제를 고쳤습니다. Alt+Space와 Alt+F4는 그대로 동작합니다.
- 도구나 선택을 바꿀 때 이미지 크기가 흔들리지 않습니다. 속성 막대 높이가 창 폭에 따라서만 정해지고, 1000 DIP 너비 창부터 한 줄에 들어갑니다.
- 속성 막대를 정리했습니다. 숫자 칸은 −·값·+를 한 테두리로 묶고, 색 추가는 점선 원으로, 묶음 사이에는 구분선을 둡니다. 삭제는 휴지통 단추로, 텍스트 서식은 아이콘 토글로 바꿨습니다.
- 회전은 '…' 메뉴 대신 자르기 옆의 회전 단추 두 개(Q·W)로 바로 합니다.
- 툴팁이 열려 있는 동안 동영상 재생 위치 표시나 자동 저장 같은 예약 작업이 멈추던 문제를 고쳤습니다. 지금까지는 마우스를 움직여 툴팁이 닫혀야 다시 동작했습니다.

## 캡처 출처

- 페이지나 앱을 알 수 있는 캡처에는 출처를 표시합니다. 편집기 상태 줄의 출처 칩, 핀 막대의 '원본 열기', 라이브러리 썸네일의 출처 배지, 캡처 직후 알림에서 볼 수 있습니다.
- 라이브러리에서 '같은 출처 캡처 보기'로 같은 사이트나 앱에서 찍은 캡처만 모아 봅니다.
- 화면에 보이는 주소에서는 질의 문자열과 조각(`?`, `#` 뒤)을 뺍니다. 열기와 주소 복사는 전체 주소를 씁니다.

## 글자 인식(OCR)

- 똑바로 선 짧은 한국어 줄을 뒤집힌 줄로 잘못 판단해 빠뜨리던 문제를 고쳤습니다.
- 인식 품질이 '정확'이면 Windows 인식기와 PP-OCR을 함께 돌려 줄마다 더 나은 결과를 고릅니다. 시험 시료 세 벌에서 한국어 화면 글자의 오류율이 PP-OCR만 쓸 때보다 줄었습니다(7.0% → 1.4%, 5.7% → 1.3%, 7.2% → 2.9%).
- 새로 설치하면 환영 화면에 '정확한 한국어 글자 인식'이 있습니다. 사양이 충분한 PC(4코어 이상, 메모리 8GB 이상)에서 데이터 요금제나 배터리 절약 모드가 아니면 미리 선택되어 있습니다. 켜 둔 채 닫으면 모델 파일(약 102MB)을 백그라운드에서 한 번 내려받습니다.
- 인식 품질은 빠름, 보통, 정확 세 단계입니다. '가장 정확'은 화면 캡처에서 나아지는 점이 없고 한 장에 약 1.5초가 걸려 없앴습니다. 저장된 '가장 정확' 설정은 '정확'으로 바뀌고, 남은 이미지 확대 모델 파일(약 70MB)은 한 번 정리합니다.
- 모델 파일은 zip 하나로 받아 크기와 SHA-256을 확인하고, 실제 크기를 표시합니다. 데이터 요금제나 로밍 연결, 배터리 절약 모드에서는 자동 내려받기를 미룹니다.

## 속도

- 편집기 열기가 빨라졌습니다(처음 열기 6%, 두 번째부터 17%).
- 모자이크 계산 시간이 92%, 선택 범위 계산이 86%, 점·영역 찾기가 49% 줄었습니다.

## 사용법 영상

- 앱 안 사용법 영상 66개를 새 편집기 화면으로 다시 만들었습니다.

## 개인정보와 네트워크

- '새 버전 자동 확인'이 켜져 있으면 하루에 한 번 새 버전을 확인합니다. Store 설치본은 Microsoft Store를 통해, GitHub 설치본과 포터블은 `api.github.com`을 통해 확인하고, GitHub 설치본에서 [업데이트]를 누르면 GitHub에서 설치 파일과 해시 목록을 내려받습니다. 캡처 내용이나 개인정보는 보내지 않습니다.
- 개인정보처리방침에 새 버전 확인과 바뀐 OCR 모델 내려받기를 반영했습니다.

## 데이터

- 설정 파일에 `updates` 항목(자동 확인 여부, 마지막 확인 시각, 닫은 버전)을 더했습니다.
- 이전 버전의 설정, 캡처, 라이브러리, 색인, 열린 핀 저장 형식은 그대로 읽습니다. 저장된 OCR 품질 '가장 정확'은 '정확'으로 읽습니다.

이전 변경은 [4.6.0](4.6.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
