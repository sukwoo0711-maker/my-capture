# MyCapture 5.0.0

5.0.0은 캡처 직후의 클립보드, 그림 핀 번역의 진행 표시, 형광펜 직선과 커서를 바꾸고, 오래 켜 두고 반복해 써도 메모리를 붙잡거나 느려지지 않는지 점검한 업데이트입니다. 4.13.1의 변경은 [4.13.1 릴리스 노트](4.13.1-release-notes.md)에서 확인할 수 있습니다.

- 캡처하면 왼쪽 아래 카드가 뜨기 전에 클립보드 복사를 마칩니다. 카드가 보일 때 바로 붙여 넣으면 방금 캡처한 그림이 들어갑니다. 복사가 1초를 넘는 아주 큰 캡처는 지금처럼 카드를 먼저 띄우고 `복사 중…`으로 알립니다.
- 그림 핀과 텍스트 핀을 번역하는 동안 안내에 끝난 문장 수를 `번역 중 · 3/12`처럼 보이고, 두 문장 이상 끝나면 `번역 중 · 4/12 · 약 8초 남음`처럼 남은 시간도 보입니다. 안내 아래의 얇은 막대가 끝난 만큼 차오르고, 모델 설치나 문자 인식처럼 아직 개수를 모르는 동안에는 막대 위로 밝은 띠가 오갑니다. Windows 애니메이션을 끄면 움직이지 않는 문구와 막대만 보입니다.
- 형광펜과 펜에서 Shift를 누른 채 그리면 누른 점에서 직선으로 그립니다. 화살표처럼 45° 단위로 맞춰 밑줄은 수평으로 그어집니다. 그리는 중에 Shift를 떼면 그때까지 그린 자유 곡선으로 돌아가고, 마우스 버튼을 놓을 때의 Shift 상태로 확정합니다.
- 형광펜 커서가 편집 아이콘의 연필 모양으로 바뀌었습니다. 획은 연필 끝에서 시작합니다. 고대비 테마에서는 Windows 펜 커서를 그대로 씁니다.
- 캡처한 그림이 카드로 날아갈 창을 더 빨리 띄웁니다. 실행 뒤 첫 캡처는 확인용 숨긴 창을 따로 만들지 않고, 그 뒤의 캡처는 미리 만들어 둔 창을 씁니다. 그래서 클립보드 복사를 마친 뒤에 카드를 띄우면서도 카드가 뜨기까지의 시간이 늘지 않습니다. 미리 만든 창은 마지막 캡처 뒤 1분이 지나면 닫아 메모리를 돌려줍니다.
- 캡처, 편집기, 핀, 문자 인식, 라이브러리를 40번 되풀이한 시험에서 메모리와 핸들, 스레드가 늘지 않았고 단계별 시간도 길어지지 않았습니다.
