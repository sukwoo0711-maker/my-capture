# MyCapture 2.1.0 UI/UX direction brief

Status: user approved the recommended direction 02 gallery + direction 03 video editor with a unified teal brand. Native implementation is in progress. Twelve proposal pairs remain under artifacts/ux-2.1.0 as design references.

The owner rejected the earlier palette-only proposals. The next comparison must change the product's workflow and visual hierarchy, not merely recolor the same gallery and editor.

## Shared product behavior

- Capture review is temporary until confirmation. Confirmation adds the capture to the library; cancelled/replaced captures do not appear as completed library items.
- Date headings communicate group selection and deselection. Selection feedback and the resulting actions appear near the selected items.
- Image and video actions are explicit. Copy, save edits and export are separate outcomes with clear labels.
- Video trim and timed text expose the relevant source-time domain. A selected layer reveals its controls; unrelated controls do not compete with the preview.
- Automatic deletion communicates both its purpose and remaining time. Errors say what happened and how to recover; success messages remain brief.
- Native desktop constraints remain: keyboard access, compact windows, mixed DPI, existing local data and no implied cloud collaboration, multivideo compositing or audio editing.

## Comparison directions

| ID | Product emphasis | Library architecture | Editor architecture | Brand voice | Tradeoff |
|---|---|---|---|---|---|
| 01 Quick Desk | Capture, check, copy | Recent captures with one dominant capture action | Compact canvas with immediate output actions | Fast, direct: “확인하고 복사” | Fewer controls visible at once |
| 02 Library Workspace | Find and continue work | Filter rail, content grid, selected-item details | Persistent workspace with contextual inspector | Calm, dependable: “선택한 항목 편집” | Three panes consume width |
| 03 Precision Studio | Precise editing | Dense production asset browser | Preview, properties, prominent timeline and numeric controls | Exact, restrained: “선택 구간 내보내기” | Higher initial learning effort |
| 04 Guided Edit | Complete an edit without uncertainty | Select one item, then start editing | Progressive trim → text → export steps | Helpful: “남길 구간을 정하세요” | Slower for frequent expert switching |
| 05 Canvas First | Judge the content | Visual thumbnails with minimal navigation | Large canvas, floating tool dock, contextual inspector | Quiet: “필요한 부분만 남기세요” | More controls require selection |
| 06 Contact Sheet | Compare many captures | Dense contact sheet with visible selection | Filmstrip context beside the active edit | Practical: “비교하고 고르기” | Smaller thumbnails and less whitespace |
| 07 Review Desk | Inspect before acting | Item list and large preview side by side | Preview-led workspace with compact edit controls | Clear: “내용 확인 후 편집” | Less room for a large timeline |
| 08 Timeline First | Understand recorded time | Chronological groups and recording metadata | Large timeline below compact preview and inspector | Measured: “시작과 끝을 정확하게” | Static image workflow gets less prominence |
| 09 Focus Light | One clear task | Large, sparse cards | Single canvas with task-specific side sheet | Simple: “지금 편집할 항목” | More scrolling for large libraries |
| 10 Command Desk | Repetitive expert use | Compact table and command/search bar | Shortcut-led controls and numeric inspector | Concise: “구간 적용” | Discoverability must be supported by labels |
| 11 Friendly Notebook | Capture as personal notes | Warm editorial rows with readable captions | Annotated work area and friendly instructions | Warm, plain: “필요한 장면을 남겨보세요” | Less technical density |
| 12 Utility Panel | Stay close to the current task | Narrow quick-access recent list | Compact grouped panes | Modest: “복사 준비 완료” | Limited space for long editing sessions |

Colors, type scale, control density and microcopy should reinforce these differences. Color alone does not establish a different direction. Use the same sample media so the content does not disguise structural similarity.

## Visual and interaction distinctions

| ID | Color roles and visual rhythm | Defining interaction |
|---|---|---|
| 01 | White/slate surfaces, cobalt for the one next action; medium density, strong action labels | Full-window capture/review/output task board |
| 02 | Cool neutral background, teal selection, quiet separators; consistent medium type hierarchy | Keep filter, grid and selected-item detail visible together |
| 03 | Charcoal canvas, cyan playhead, distinct selection range; compact squared controls and monospaced time | Keep preview, properties and timeline simultaneously visible |
| 04 | Soft light background, indigo active step; numbered headings and roomy instructions | Only the current trim/text/export step exposes its controls |
| 05 | Near-black canvas, restrained coral selection; minimal framing and contextual labels | Object selection summons tools around the canvas; floating dock |
| 06 | Neutral gray surround, amber selection outlines; tight thumbnail rhythm and small metadata | Move between existing items from a filmstrip, one item edited at a time |
| 07 | White preview, blue-gray list, blue current selection; clear row separators | Inspect in a large right preview while the left item list remains visible |
| 08 | Deep navy surround, mint playhead, purple text intervals; readable time hierarchy | Timeline occupies at least 40% of editor height; source time is the primary navigation |
| 09 | Warm white space, blue primary action; large headings, fewer visible controls | One task at a time, with an explicit side sheet instead of an object-floating dock |
| 10 | Graphite/ivory utility surfaces, lime active command; compact tables, shortcut badges | Existing actions exposed as command buttons and shortcuts, not a promised new global command-search engine |
| 11 | Paper background, ink text, terracotta actions; editorial captions and soft dividers | Plain-language instructions embedded beside the current work |
| 12 | Slate compact panel, turquoise confirmation; compact but legible groups | Narrow utility surface focused on a recent item, not a full task-board window |

All proposals must show the same temporary capture confirmation/cancellation rule. New captures enter the library only after confirmation. Filmstrip navigation does not imply simultaneous editing, and compact panels do not promise a new detachable-window subsystem. These are alternative interface proposals; the owner selected direction 02 for the gallery and direction 03 for the editor. Unselected concepts are not shipped capabilities.

## Selection and verification

Deliver twelve gallery/editor pairs, a readable interactive comparison, and contact sheets. Demonstrations must be labeled prototypes and must not save files or change the native app. Verify today-group toggling, item selection, screen switching and the demonstrated editing flow. Inspect all twelve rendered variants for clipping, missing controls and structurally duplicate layouts.

The strongest initial recommendation is 02 for everyday capture/library use, 03 for the supplied video-editor reference, or 01 when immediate capture/copy speed dominates. This is design judgment from the owner's stated tasks, not measured usability research. A selected combination may use the same brand system with different appropriate layouts for library and editing.
