## Accepted behavior and design

- One resident-ready notification per normal process startup, after shell/hotkey setup; configured shortcut and real assembly version. Diagnostic and duplicate launches do not produce it.
- Retake closes only the current owned still-image editor after busy/recording/save guards allow it. Persisted original, unrelated windows and an active recording remain protected.
- Virtualized, date-grouped library selection uses visible order for inclusive Shift ranges and actual tile rows for arrow navigation. Date selection covers the displayed date group. External drag is Copy only, staging both PNG and MP4 with unique names away from managed originals.
- Batch deletion publishes the updated queue before physical cleanup, protects active eviction leases, restores records if publication fails and reports unfinished cleanup. Clear-all confirmation takes a snapshot of the whole queue, including pinned/video records; captures added afterwards remain.
- Export settings are explicit and cancelable. MP4 percentage is measured against a fresh standard encode of the same edited interval; image percentage is measured against a fresh rendered PNG. Actual bytes and an unmet target are reported. GIF limits remain 20 seconds, 200 frames and 960 pixels on the long edge, with existing quality/speed settings.
- Editor hierarchy follows the existing Focus Portal tokens. Workflow references: [Clipchamp timeline](https://support.microsoft.com/en-us/clipchamp/how-to-work-with-the-timeline-in-clipchamp), [Clipchamp export](https://support.microsoft.com/en-US/Clipchamp/exporting-and-saving-a-video-in-clipchamp), [Camtasia animation controls](https://www.techsmith.com/learn/tutorials/camtasia/animations-in-depth/), and [Premiere export settings](https://helpx.adobe.com/premiere/desktop/render-and-export/export-files/overview-of-export-settings.html). Selected [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) are pinned to `1035d6e8663d9e92e71d6fc96dc361c1f766c153` with the full MIT notice shipped.
