# MyCapture 2.4.0

내보내기와 편집기, 설정 이관을 중심으로 9개 항목을 개선했습니다.

**GIF 내보내기 자동 계산·자동 자르기** — GIF 내보내기 대화상자를 열면 계산 버튼을 누르기 전에 예상 크기와 미리보기를 자동으로 계산합니다. GIF 최대 길이(20초)를 넘는 구간은 잘리는 부분을 미리 알려 주고, 편집기 타임라인의 트리밍 끝점을 20초 안으로 당기는 자동 자르기를 제공합니다.

**모자이크·자르기 도구** — 주석 편집기 도구 모음에 픽셀화(모자이크) 도구와 자르기 도구가 추가됐습니다. 모자이크는 드래그한 영역 아래를 픽셀 단위로 흐려 개인정보를 가립니다. 자르기는 유지할 영역을 드래그하고 Enter로 확정하며, 되돌리기 한 번으로 복원됩니다.

**설정 내보내기·가져오기** — 설정창 하단의 내보내기 버튼으로 모든 설정을 JSON 파일 하나로 저장하고, 가져오기로 다른 PC나 재설치 후 그대로 복원합니다. 가져온 값은 기존 범위 검사를 통과한 뒤 적용되며, 적용 버튼을 눌렀을 때만 반영됩니다.

**F9 토큰 기반 업로드** — 설정의 GitHub 섹션에 개인 접근 토큰(PAT) 필드가 생겼습니다. 토큰을 넣어 두면 F9(GitHub 이미지 주소 복사)가 브라우저를 열지 않고 REST API로 바로 업로드해 주소를 클립보드에 담습니다. 창이 열리지 않고 포커스도 빼앗기지 않으며, 토큰이 만료되거나 API 오류가 나면 기존 브라우저 방식으로 자동 전환됩니다. 토큰은 이 PC의 설정 파일에만 저장되고 api.github.com으로만 전송됩니다.

**녹화 고정 크기 프리셋** — 설정에서 녹화 영역의 너비와 높이를 지정할 수 있습니다. 값을 넣으면 영역 선택 오버레이가 드래그로 위치만 정하고 크기는 프리셋에 고정되어, 같은 크기의 녹화를 반복할 때 매번 맞추지 않아도 됩니다. 비워 두면 기존처럼 자유 드래그입니다.

**OCR 텍스트 저장** — OCR 결과 창에서 Ctrl+S(또는 텍스트 저장 버튼)로 인식된 텍스트를 UTF-8 .txt 파일로 저장합니다.

**시각 회귀 베이스라인** — UX 자가 검사에 `--compare-baseline` 모드가 생겼습니다. 여섯 테마의 갤러리 렌더링을 저장해 둔 기준 이미지와 픽셀 단위로 비교하고, 달라진 지점을 첫 픽셀 좌표까지 보고합니다. 픽스처 시각을 고정 클록으로 바꿔 실행마다 같은 결과를 내도록 했습니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.

알려진 제한: OCR 정밀 모드의 DirectML GPU 가속은 RapidOcrNet의 ONNX Runtime 1.29 의존성 문제로 이번 릴리스에 포함되지 않았습니다. 정밀 모드는 CPU 추론으로 동작합니다.
