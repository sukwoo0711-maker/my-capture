# MyCapture 4.2.1

4.2.1은 포인트 색을 앱 아이콘의 빨강에 맞추고, 단축키 설정의 사용법 버튼을 간결하게 바꾼 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.2.1.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 포인트 색

- 기본 포인트 색을 **레드**로 바꿨습니다. 앱 아이콘의 압정과 같은 빨강(`#E0453C`)을 주 버튼에 사용하며, 버튼 글자는 대비 4.5:1 이상을 지키는 어두운 색으로 표시합니다.
- 선택한 탐색 항목, 체크 표시, 진행 막대, 포커스 테두리는 테마별 배경과 대비 3:1 이상을 지키도록 맞춘 빨강을 사용합니다. 고대비 테마에서는 시스템 색을 따릅니다.
- **바이올렛**은 설정 → 일반 → **포인트 색**에서 계속 선택할 수 있으며, 4.2.0과 같은 색으로 표시합니다. 이미 바이올렛을 저장한 설정은 그대로 유지합니다. **기본값으로 재설정**을 누르면 레드로 돌아갑니다.

## 사용법 보기

- 설정의 **단축키** 화면과 단축키 도움말 창에서 기능마다 표시하던 **사용법 보기** 버튼을 기능 이름 옆의 작은 재생 아이콘 버튼으로 바꿨습니다. 마우스를 올리면 “{기능} 사용법 보기”를 표시하고, 누르면 이전과 같이 해당 기능의 사용법 창을 엽니다.

## 녹화 편집기

- 영상을 여는 데 5초 넘게 걸려 녹화 편집기가 먼저 열린 경우에도 전체 범위로 인코딩된 MP4(가져온 휴대폰 영상 등)를 원래 색으로 표시합니다. 이전에는 이 경우 어두운 부분과 밝은 부분이 과하게 대비되어 보일 수 있었습니다.

## 데이터

- 라이브러리와 설정 파일 형식은 4.2.0과 같습니다. 4.2.0으로 되돌려도 그대로 열리며, 포인트 색을 저장하지 않은 설정은 4.2.0에서 바이올렛으로 표시됩니다.

4.2.0의 라이브러리·편집기 확장, 새 앱 아이콘과 실기 피드백 수정은 [4.2.0](4.2.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
