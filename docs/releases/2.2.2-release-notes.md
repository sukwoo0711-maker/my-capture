# MyCapture 2.2.2

2.2.1의 라이브러리 편집·폴더 찾아보기·F9 GitHub URL·회전·텍스트 개선을 포함하면서, 회전 후 클릭 영역과 텍스트 한 줄 입력을 바로잡았습니다.

- 이미지를 90도 이상 돌리거나 되돌린 뒤 선택 핸들과 클릭 위치가 그림과 어긋나던 문제를 수정했습니다. 회전 캔버스는 만들어진 비트맵 크기를 따르고, 편집 좌표는 항상 선택 이미지의 (0,0)을 사용합니다.
- 텍스트 상자가 짧은 기본 폭에서 바로 줄바꿈되던 문제를 수정했습니다. 클릭한 위치에서 캔버스 오른쪽까지 한 줄을 유지하고, 주석과 같은 글꼴·크기로 입력한 뒤 확정 시 글자 크기에 맞춥니다.
- 라이브러리에서 편집이 열리지 않던 WPF 부모 연결 오류, 설정/내보내기 찾아보기 오류, GitHub URL 단축키 기본값 F9, 사내 GitHub HTTPS 이슈 주소, 상자·화살표 도구 유지, 글자 크기 슬라이더는 2.2.1과 같습니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
