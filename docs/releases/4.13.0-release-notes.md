# MyCapture 4.13.0

4.13.0은 그림 핀의 번역을 원래 그림 위 같은 자리에 덧씌우도록 바꾼 업데이트입니다. 4.12.2의 변경은 [4.12.2 릴리스 노트](4.12.2-release-notes.md)에서 확인할 수 있습니다.

- 그림 핀에서 `번역`을 누르면 번역문이 원래 그림 위 같은 자리에 덧씌워집니다. 원래 글자 자리를 둘레 배경색으로 지우고, 원래 글자의 색과 크기에 맞춰 번역문을 그립니다. `번역`을 다시 누르면 원본 그림으로 돌아갑니다.
- 핀의 오른쪽 클릭 메뉴에서 `번역문 문서로 보기`와 `번역 그림으로 보기`를 골라 두 보기를 오갑니다. 글자가 2° 넘게 기울었거나 글자 위치를 쓸 수 없는 그림은 번역문 문서로 보여 줍니다.
- 번역을 덧씌운 상태에서 Ctrl+C를 누르면 덧씌운 그림과 번역문 텍스트를 함께 복사합니다. Ctrl+더블클릭과 저장은 원본 그림을 씁니다.
- 번역이 빨라지고 메모리를 덜 씁니다. 위키백과·MDN 화면 두 장 기준으로 처음 번역은 2.3초에서 2.0초로, 두 번째 번역은 1.5초에서 0.9초로 줄었습니다.
- 한국어 화면 문구가 낱말 중간에서 줄을 바꾸지 않고, 마지막 줄에 한 음절만 남기지 않습니다.
- 화면 글자 크기를 여섯 단계로 맞췄습니다. 동영상 타임라인의 글자가 조금 커졌습니다.
- 라이브러리에서 연 문자 인식 결과의 텍스트를 고친 뒤 표 탭을 고르면 교체를 묻고 빈 표로 굳던 문제를 고쳤습니다.
