# MyCapture 5.3.1

5.3.1은 다시 띄운 그림 핀과 복사한 그림으로 만든 핀에서 그림 복사와 저장이 실패하던 문제를 고친 업데이트입니다.

5.3.0의 변경은 [5.3.0 릴리스 노트](5.3.0-release-notes.md)에서 확인할 수 있습니다.

## 핀

- 다음 그림 핀에서 그림 복사(`Ctrl+C`)와 빠른 저장(`Ctrl+S`)이 실패하던 문제를 고쳤습니다. 앱을 다시 시작할 때 복원된 핀, 닫았다 다시 연 핀, 클립보드의 PNG 그림을 `F3`으로 띄운 핀, 인코딩된 그림으로 연 글자 인식 창에서 띄운 핀이 해당합니다.
- 닫았다 다시 연 핀이 열려 있는 동안 열린 핀 저장이 실패하던 문제를 고쳤습니다. 이때는 다음 실행에서 마지막으로 저장된 상태의 핀이 복원됐습니다.
- 복원된 핀을 닫으면 닫은 핀 목록에 남지 않던 문제를 고쳤습니다.
- 텍스트·표 핀의 원문 복사와, 캡처해서 바로 띄운 핀은 이 문제와 무관했습니다.

## 원인과 확인

- 이 핀들의 그림은 PNG를 한 스레드에서 디코딩한 것입니다. 복사와 저장은 다른 스레드에서 인코딩하는데, 그때 예외가 났습니다. 디코딩한 스레드에 우연히 다시 걸릴 때만 성공했고, 핀을 띄우고 30초가 지난 뒤에는 12번 가운데 12번 실패했습니다.
- 디코딩한 스레드에서 그림의 메타데이터를 한 번 읽어 두어 어느 스레드에서든 인코딩되게 했습니다. 인코딩 결과는 이전과 바이트까지 같습니다.
- 새 시험 9개 가운데 8개가 5.3.0의 코드에서 실패했고, 수정한 뒤에는 모두 통과했습니다.
