# MyCapture 4.1.3

4.1.3은 캡처 영역을 고르는 화면의 반응 속도를 개선한 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.1.3.0`입니다. GitHub 릴리스의 포터블 zip은 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오.

## 캡처 선택 화면

- 선택 화면에서 마우스 포인터와 십자 안내선이 지연 없이 따라옵니다. 이전 버전은 선택 화면 전체(모든 모니터를 합친 크기)를 감싸는 키보드 포커스 테두리를 화면이 바뀔 때마다 다시 그렸습니다. 이 때문에 큰 모니터나 여러 모니터에서 포인터가 끈적이게 움직였습니다.
- 십자 안내선을 미리 만들어 둔 이미지로 그려 포인터를 움직일 때마다 선을 다시 계산하지 않습니다.
- 화면을 복사한 결과를 한 번에 받아 선택 화면이 뜨기 전 단계를 줄였습니다.
- 앱을 시작한 뒤 컴퓨터가 한가할 때 선택 화면을 미리 준비합니다. 첫 캡처도 늦게 뜨지 않습니다.
- 선택 화면이 뜬 직후 화면 전체를 한 번 더 그리던 동작을 없앴습니다.

측정한 PC(3440×1440 120Hz 주 모니터와 세로 보조 모니터)에서 4.1.2와 비교한 결과입니다.

| 항목 | 4.1.2 | 4.1.3 |
|---|---|---|
| 마우스를 움직인 뒤 화면에 반영되기까지(중앙값) | 약 106ms | 약 6ms |
| 선택 화면 갱신 간격 | 약 25ms(초당 40회) | 약 8.3ms(초당 120회, 모니터 주사율) |
| 화면 그리기 부담(1초당 사용 시간) | 약 990ms | 약 443ms |
| 단축키부터 선택 화면 첫 표시까지 | 약 106ms | 약 84ms |
| 앱 실행 직후 첫 캡처 | 약 221ms | 약 175ms |
