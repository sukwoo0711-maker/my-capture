# MyCapture 1.8.0

> 출시 준비 중입니다. 아래는 통합된 기능의 배포용 설명이며, 최종 전체 테스트·패키지·설치 검증 완료를 뜻하지 않습니다. 게시 전 검증 기록과 실제 배포 파일 정보를 확정합니다.

MyCapture 1.8.0은 영상 레이어 편집, 영어 UI, 녹화 중 캡처, 앱 내 업데이트를 추가하고 라이브러리 저장 작업의 UI 응답성을 개선합니다.

## 영상에 텍스트·도형·이미지 추가

- 녹화 영상에 텍스트, 사각형, 원과 이미지 레이어를 추가할 수 있습니다. 미리보기에서 레이어를 선택해 드래그로 옮기고 모서리로 크기를 조절합니다.
- 아래 타임라인에서 레이어 막대를 옮기거나 양 끝을 조절해 표시 구간을 바꿉니다. 키보드 선택·이동·크기 조절과 실행 취소도 지원합니다.
- 레이어 위치, 크기와 표시 시간을 편집 문서에 저장합니다. 미리보기와 MP4·GIF 내보내기에 같은 합성 경로를 사용합니다.
- 작은 편집 창에서도 레이어 추가 도구와 선택한 레이어의 시간 막대를 볼 수 있도록 배치를 조정했습니다. 창을 크게 하면 미리보기 공간이 늘어납니다.
- 이미지 크기와 전체 레이어 데이터에 제한을 두어 과도한 메모리 사용을 막습니다. 손상되거나 너무 큰 입력은 이유를 안내하며 거부합니다.

## 한국어·영어 표시 언어

- 설정에서 Windows 언어 따르기, 한국어, 영어를 선택할 수 있습니다. 표시 언어는 저장되며 다음 앱 시작부터 모든 창과 메뉴에 적용됩니다.
- 메뉴, 설정, 편집 도구, 상태 메시지와 접근성 이름을 포함한 724개 UI 리소스에 영어를 제공합니다.
- 사용자가 입력한 텍스트, 캡처 제목, 파일 경로와 저장 데이터는 번역하지 않습니다.

## 녹화와 작업 흐름

- 인코더 준비가 끝난 뒤 녹화 시간을 시작하고, 캡처·출력·중복·누락 프레임을 구분해 기록합니다.
- 녹화 세션의 캡처 자원을 재사용하고 파일 마무리와 라이브러리 등록을 비동기로 처리합니다.
- 녹화·캡처 창을 영상에서 안전하게 제외할 수 있는 상태에서는 녹화 중에도 스크린샷을 캡처할 수 있습니다. 녹화 종료 처리 중에도 제외 정책을 유지합니다.
- 선택적으로 녹화 시계를 표시하고, 드래그와 마우스 휠로 위치와 크기를 조절할 수 있습니다.
- 영상 재생과 위치 이동 작업이 끝나면 불필요한 미리보기 주기 작업을 멈춥니다. 디코딩한 레이어 이미지를 재사용하고 잘못된 이미지의 반복 디코딩을 줄입니다.
- 화면 고정 창을 닫은 뒤 늦게 도착한 피드백이 타이머를 다시 켜지 않도록 했습니다. 닫힌 창에서 불필요한 주기 작업이 CPU를 사용하는 것을 막습니다.

## 라이브러리 게시 작업의 응답성

- UI가 소유한 상태를 변경 불가능한 스냅샷으로 전달하고, 저장 결과를 순서대로 게시하도록 정리했습니다. 파일 저장 작업과 UI 상태 갱신의 경계를 명확히 유지합니다.
- 합성 라이브러리의 OCR 색인 결과 게시 과정에서 UI 스레드가 실제 작업에 사용한 시간의 중앙값은 다음과 같습니다. 디스크 쓰기 대기 시간은 제외한 값이며, 전체 게시 지연이나 OCR 작업의 소요 시간이 줄었다는 뜻은 아닙니다.

| 라이브러리 항목 수 | 이전 UI 스레드 작업 시간 중앙값 | 변경 후 UI 스레드 작업 시간 중앙값 |
|---:|---:|---:|
| 32 | 13.320 ms | 0.232 ms |
| 300 | 15.039 ms | 0.940 ms |
| 1,000 | 17.770 ms | 1.121 ms |

이 수치는 다른 작업을 줄인 측정 구간에서 얻은 합성 워크로드 결과입니다. 전체 처리 시간은 개선되지 않았으며, 실제 응답성과 녹화 속도는 장치·해상도·동시 작업에 따라 달라집니다. 원본 이미지 게시 측정은 이전 측정과 구간 범위가 달라 직접적인 배율 비교를 하지 않습니다.

## 앱 내 업데이트

- 공식 저장소에서 업데이트를 확인하고 설치 파일을 다운로드한 뒤 SHA-256을 검증합니다.
- 기존 설치의 소유 정보와 설치 위치를 확인해 업데이트합니다. 포터블 앱을 설치 버전으로 전환하는 작업은 별도로 안내합니다.
- 설치 완료 응답을 확인하고, 설치된 파일의 해시와 버전을 검증한 뒤 다시 시작한 프로세스의 실행 상태를 확인합니다.
- 안전하지 않은 임시 경로나 연결된 디렉터리를 거부합니다. 정리할 때는 해당 업데이트 세션이 소유한 파일만 삭제합니다.

## 설치 및 호환성

- Windows 11 21H2(build 22000) 이상, x64를 지원합니다. ARM64에서는 Windows x64 에뮬레이션으로 실행합니다.
- 오프라인 self-contained 설치 파일과 portable ZIP으로 배포합니다. 별도의 .NET 설치는 필요하지 않습니다.
- 캡처와 OCR 처리는 로컬에서 수행합니다. MIT 라이선스와 Authenticode 미서명 배포 정책을 유지합니다.
