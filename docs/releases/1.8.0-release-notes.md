# MyCapture 1.8.0 — release draft

This draft records accepted implementation changes. It is not a release announcement or a statement that the remaining release gates have passed.

## Video editing

- Add text, rectangles, circles, and images to a recording. Select layers in the preview, drag them to move, and drag their corners to resize.
- Move or trim a layer's display interval in the lower timeline. Keyboard movement, resizing, selection, and undo remain available.
- Save layer position, size, and timing in the editing document. Preview, MP4, and GIF output use the shared layer composition path.
- Keep layer tools and the selected layer's timing bar visible in the minimum-size editor. Larger windows give more space to the preview.
- Bound image dimensions and aggregate layer data before decoding or exporting. Invalid or oversized documents are rejected with an explanation.

## Recording and responsiveness

- Start the recording timebase after the encoder is ready, and track captured, emitted, duplicated, and dropped frames separately.
- Reuse native capture resources during a recording session. Finalize recordings asynchronously while preserving dispatcher ownership for UI and library publication.
- Capture still images during recording when the recording and capture windows can be safely excluded. Keep the exclusion policy active through recording shutdown.
- Add an optional recording clock that can be moved and resized.
- Stop idle video preview polling when playback and seek work are finished. Reuse decoded layer images and avoid repeatedly decoding known-invalid image data.

These changes do not imply a particular FPS, CPU reduction, or input-latency improvement. Hardware measurements and their limitations belong in the final validation record.

## Updates

- Check the official repository, download a bounded installer payload, and verify its SHA-256 before installation.
- Preserve the identity and destination of an owned installation. Portable-to-installed conversion is explicitly labeled.
- Wait for an authenticated installer receipt, verify the installed manifest and binary hashes and versions, and confirm that the restarted process remains running.
- Reject unsafe staging paths and linked ancestors. Cleanup removes only the exact files owned by the update session.

## Compatibility

- Windows 11 21H2 (build 22000) or later, x64. ARM64 uses Windows x64 emulation.
- Self-contained offline setup and portable ZIP; no separate .NET installation is required.
- Capture and OCR processing remain local. The MIT license and unsigned Authenticode distribution policy remain unchanged.
