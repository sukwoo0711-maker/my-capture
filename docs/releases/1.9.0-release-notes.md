# MyCapture 1.9.0

라이브러리에서 여러 항목을 선택해 정리하고, 영상 편집기에서 GIF 변환과 용량 절감 내보내기를 쉽게 찾을 수 있도록 개선했습니다.

- 앱이 트레이에서 사용할 준비를 마치면 현재 캡처 단축키를 한 번 안내합니다. 창 제목과 설정에서 `MyCapture-1.9.0` 버전을 확인할 수 있습니다.
- 이전 영역 캡처의 편집기가 열려 있을 때 `Ctrl+Shift+C`를 다시 누르면 해당 편집기를 닫고 새 캡처를 시작합니다. 저장된 원본은 유지하며 녹화나 저장 등 진행 중인 작업의 보호 조건도 적용합니다.
- 라이브러리를 날짜로 구분하고 카드 위에 촬영 시각을 표시합니다. Ctrl로 개별 선택을 추가하고, Shift로 두 카드 사이를 선택하며, 날짜 버튼으로 해당 날짜의 표시된 항목을 선택할 수 있습니다.
- 여러 이미지·동영상을 선택해 삭제하거나 외부 폴더로 복사 드래그할 수 있습니다. 동명 동영상도 서로 다른 내보내기 이름으로 준비하며 관리 중인 원본 파일을 이동하지 않습니다.
- 항목 수·용량 버튼을 누르면 전체 보관함 비우기 확인이 표시됩니다. 고정 항목과 동영상 포함 여부를 명확히 안내하고, 사용 중인 항목이나 파일 정리가 끝나지 않은 항목은 결과에 구분해 표시합니다.
- 영상 편집기의 미리보기, 재생 제어, 레이어 타임라인, 편집 저장과 내보내기 버튼을 정돈했습니다. Microsoft Fluent System Icons의 MIT 라이선스 아이콘을 사용하며 출처와 라이선스를 패키지에 포함합니다.
- 내보내기 화면에서 MP4 또는 GIF를 선택합니다. GIF는 최대 20초 구간과 기존 표준·작게·최소 용량 품질 옵션을 유지합니다.
- 이미지와 MP4의 용량 절감 목표를 선택한 뒤 **결과 계산**으로 실제 파일 크기를 확인할 수 있습니다. MP4 기준 크기는 현재 편집 구간을 표준 설정으로 인코딩한 결과이며, 이미지 기준 크기는 현재 이미지의 PNG 결과입니다. 목표 비율에 도달하지 못하면 실제 결과와 함께 안내합니다. 슬라이더를 움직일 때마다 인코딩하지 않습니다.
- 계산 취소, 설정 변경, 창 닫기와 다른 이름으로 저장 시 임시 결과와 원본 파일의 수명을 보호합니다.

한국어와 영어를 지원하며 설정에서 변경한 언어는 다음 앱 시작부터 적용됩니다. 첫 캡처와 성능 검증의 조건, 실제 실행한 검사와 한계는 [1.9.0 검증 기록](https://github.com/sukwoo0711-maker/my-capture/blob/main/docs/releases/1.9.0-validation.md)에 기록합니다.

Windows 11 x64 설치판은 `MyCapture-1.9.0-win-x64-setup.exe`, 포터블은 `MyCapture-1.9.0-win-x64-portable.zip`을 사용하세요. 설치형과 포터블은 동일한 앱·런타임을 포함합니다. 현재 실행 중인 이전 버전에는 이 변경이 자동으로 반영되지 않으며 새 버전을 설치하거나 앱 내 업데이트를 완료해야 합니다.
