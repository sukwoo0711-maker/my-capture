# MyCapture 2.5.0

캡처 반응성과 녹화·편집·OCR의 사용성을 개선했습니다.

**캡처 반응성 개선** — 영역 캡처가 이전 세션의 잔상을 방지하려고 매번 100ms를 기다리던 것을, 직전 세션이나 트레이 메뉴가 방금 닫혔을 때만 기다리도록 바꿨습니다. 일반적인 캡처(단축키 → 선택 화면)에서 불필요한 대기가 사라졌습니다.

**핀 Alt+Tab 정리** — 화면에 띄운 핀 개수만큼 Alt+Tab 목록에 동일한 항목이 나타나던 문제를 고쳤습니다. 핀 창은 이제 Alt+Tab 전환 목록에서 제외되고, 전환은 실제 작업 창 사이에서만 일어납니다.

**텍스트 상자 비례 확대** — 주석 편집기에서 텍스트 상자의 모서리를 끌어 크기를 바꾸면 글자 크기가 상자 높이에 비례해 함께 커지고 작아집니다(가장자리 핸들로는 상자만 조절). 한 번의 드래그가 한 번의 실행취소로 되돌아갑니다.

**녹화 중 커서 강조** — 영역 녹화에 커서 주위로 강조 링이 함께 기록됩니다. 평상시에는 호박색 링, 왼쪽 버튼을 누르고 있는 동안에는 붉은 링으로 바뀌어 클릭 동작이 영상에서 바로 읽힙니다. 설정의 녹화 섹션에서 끌 수 있습니다.

**OCR 속도** — 영수증처럼 인식할 줄이 많은 이미지에서 텍스트 인식 단계를 코어 수만큼 병렬로 실행하도록 바꿨습니다. 직렬 실행이 기본값이어서 남던 다중 코어를 활용합니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
