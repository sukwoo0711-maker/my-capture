# MyCapture 2.3.1

영수증 OCR과 테마 글자 시인성을 보강했습니다.

- 느림(기본) OCR은 RapidAI PP-OCRv5 한국어 인식 모델을 `%LOCALAPPDATA%\MyCapture\ocr-models`에 받아 사용합니다. 모델이 없거나 실패한 경우에는 기존 Windows OCR로 넘어갑니다.
- 글래스·글래스 라이트 패널을 더 불투명하게 하고, 모든 테마의 본문·보조·흐린 글자 대비를 올렸습니다. Windows 밝은/어두운 Mica 위에서도 글자가 읽히도록 맞춰 두었습니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
