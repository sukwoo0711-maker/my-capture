# MyCapture 1.5.0

MyCapture 1.5.0은 자주 사용하는 캡처 작업의 단축키 체계를 하나로 정리하고, 앱 아이콘부터 라이브러리와 영상 편집기까지 일관된 시각 언어를 적용한 디자인·사용성 릴리스입니다. 소리를 녹음하거나 재생하지 않는 기존 원칙은 그대로 유지합니다.

## 주요 변경 사항

- 핵심 작업 키를 `Ctrl+Shift+C/X/Z` 패밀리로 통일했습니다. 영역 캡처는 `Ctrl+Shift+C`, 화면 영역 녹화 시작·중지는 `Ctrl+Shift+X`, 라이브러리 열기는 `Ctrl+Shift+Z`입니다.
- 이전 기본 녹화 키 `Ctrl+X`를 사용하던 설정은 `Ctrl+Shift+X`로 자동 마이그레이션합니다. 사용자가 직접 지정한 단축키는 보존합니다.
- 겹친 캡처 프레임을 모티프로 한 MyCapture 전용 **Focus Portal** 브랜드 마크를 추가했습니다.
- 앱과 트레이 아이콘을 16·20·24·32·40·48·64·128·256px 해상도로 다시 제작했습니다. 트레이 아이콘은 유휴, 캡처, 작업 중, 오류 상태를 색으로 구분합니다.
- 전체 UI를 Graphite 배경과 Focus Blue 강조색으로 정비했습니다. Windows 네이티브 제목 표시줄도 앱 테마와 일치하며 고대비 모드에서는 시스템 색상을 존중합니다.
- 라이브러리의 이미지·동영상 식별 배지, 검색, 재생 버튼과 상태 표현을 다듬어 미디어 종류와 가능한 작업을 더 빠르게 파악할 수 있습니다.
- 영상 편집기의 문자형 재생 기호를 벡터 아이콘으로 교체했습니다. 자르기 삭제 영역, 재생 헤드, 텍스트 레이어와 프레임 레이어는 각각 구별되는 의미 색상을 사용합니다.
- 좁은 영상 편집 창에서 재생 컨트롤이 넘치던 문제를 수정하고, 설정 화면에 `Ctrl+Shift+C/X/Z` 빠른 작업 안내를 추가했습니다.
- 트레이 오류 상태 아이콘과 다중 해상도 아이콘 구성은 자동 테스트와 패키지 검증 대상에 포함됩니다.

## 설치 및 호환성

- 지원 운영체제: Windows 11 21H2(build 22000) 이상, x64
- Windows 11 ARM64: x64 에뮬레이션으로 실행 가능
- 배포 형태: 오프라인 self-contained 설치 파일과 portable ZIP
- 사전 설치 .NET/SDK: 필요 없음
- 라이선스: MIT
- 서명: Authenticode 미서명이며 Windows에서 알 수 없는 게시자 경고가 나타날 수 있습니다.

설치 파일 실행이 조직의 AppLocker/WDAC 정책으로 차단되면 portable ZIP을 사용할 수 있습니다. 다운로드한 파일은 함께 제공되는 `SHA256SUMS.txt`로 무결성을 확인하십시오.
