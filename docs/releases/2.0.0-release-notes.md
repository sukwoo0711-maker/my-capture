# MyCapture 2.0.0

2.0.0은 기존 MyCapture 앱의 품질·워크플로 버전입니다.

- 더 조용한 계층과 선택 가능한 테마(미드나잇 / 데이라이트 / 고대비)
- 떠 있는 창: 휠 확대 중에는 캐시된 텍스처를 스케일하고, 멈춘 뒤 선명하게 다시 그립니다. 새 창은 겹치지 않게 계단식으로 배치됩니다.
- F4: 클립보드 이미지를 설정한 GitHub 이슈 Write 칸에 붙여 넣고 `user-attachments` URL을 복사합니다. F3과 Ctrl+V로 그 URL을 사용합니다.
- 라이브러리 카드에 띄우기 / 복사 / 편집 버튼을 표시합니다.
- 영상 편집: In/Out 핸들을 항상 잡고, 레이어 목록과 미리보기 더블클릭 텍스트 편집을 복구합니다.
- 기본 저장 경로를 설정에 미리 채우고, 이미지 보관 시간(기본 7일)을 바꾸며, 편집 화면에 남은 시간을 표시합니다.

Windows 11 x64 설치판: `MyCapture-2.0.0-win-x64-setup.exe`

포터블: `MyCapture-2.0.0-win-x64-portable.zip`
