# MyCapture 4.9.0

4.9.0은 캡처를 처음 시작하는 안내부터 라이브러리에서 다시 찾고 편집하는 과정까지 다듬은 업데이트입니다.

- 처음 사용 안내에서 직접 캡처하고, 다른 창 위에 핀을 띄우고, 라이브러리에서 다시 찾는 과정을 차례로 익힐 수 있습니다. 안내는 트레이 메뉴와 설정에서 다시 볼 수 있습니다.
- 첫 화면의 `영역 캡처`와 표·코드를 다른 창 위에 띄우는 설명을 알기 쉽게 다듬었습니다. 라이브러리와 설정 아래에서 앱 버전을 확인할 수 있습니다.
- 라이브러리의 폴더 행을 간결하게 정리하고 캡처 카드를 3열로 배치했습니다. 상세 정보는 필요할 때 열어 볼 수 있으며, 선택한 항목과 고정된 선택 작업 막대를 쉽게 확인할 수 있습니다.
- 편집기 오른쪽 위에 `파일로 저장`과 `복사하고 닫기`를 배치했습니다. 글자를 입력할 때 커서도 더 잘 보이도록 개선했습니다.
- 편집 중에도 영역 캡처 단축키로 새 화면을 캡처할 수 있습니다. 현재 편집 내용은 유지하며, 새 캡처는 라이브러리에 저장하고 클립보드에 복사합니다.
- `다른 이름으로 저장`은 마지막으로 저장한 폴더를 기억합니다. 빠른 저장은 설정에서 지정한 폴더를 계속 사용합니다.
- 클릭 허용 상태인 핀의 오른쪽 위 손잡이를 누르면 클릭 허용을 바로 끌 수 있습니다. 처음 세 번은 사용 안내를 표시합니다.
- 빠른 작업 카드의 동작 단추에 이름을 표시하고, 글자 인식 결과의 번역 탭에는 `번역 복사`를 표시합니다. 설정 안내 문장의 한국어 줄바꿈도 다듬었습니다.
- 앱 시작이 늦어질 때 `시작 중`을 표시하며, 처음 열린 창이 앞에 나타나도록 개선했습니다.
- 캡처 카드와 캡처 전환 효과를 닫은 뒤 쓰던 메모리를 더 빨리 돌려주고, 단축키를 누른 뒤 선택 화면이 뜨는 시간을 줄였습니다.

이전 업데이트 내용은 [4.8.5 릴리스 노트](4.8.5-release-notes.md)에서 확인할 수 있습니다.
