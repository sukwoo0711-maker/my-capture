# MyCapture 2.3.7

테마별로 흐리게 보이던 글자를 손봤습니다. 자정·주간·고대비·작업 공간·글래스·글래스 라이트 여섯 테마에서 보조 텍스트와 흐린 텍스트를 밝혀, 타이틀 표시줄 배경·본문·사이드바·컨트롤 위에서 모두 읽기 기준(대비 4.5:1)을 넘게 만들었습니다. 가장 낮은 조합도 8.6:1에서 10.4:1로 올라갔습니다.

테마의 성격은 그대로입니다. 색 톤·표면·테두리·액센트는 그대로 두고 글자 단계만 조정했으며, 시작 대화상자·OCR·영수증 인식 동작은 바뀌지 않았습니다.

설정 자가 검사에 테마별 가독성 검사가 추가됐습니다. 여섯 테마 모두 표면 위에서 AA 대비를 유지하고, 테마를 바꾸면 열린 창도 즉시 따라 오는지 확인합니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
