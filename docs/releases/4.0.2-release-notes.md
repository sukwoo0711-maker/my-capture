# MyCapture 4.0.2

캡처 후 열리는 화면을 선택할 수 있고, 이미지 자르기는 적용 전에 틀을 조정할 수 있습니다. 주요 편집 버튼에는 단축키를 함께 표시합니다.

- 일반 설정에 **캡처 후 동작**을 추가했습니다. 기본값은 **편집기 열기**이며, **빠른 작업 카드** 또는 **클립보드에만 복사**를 선택할 수 있습니다. 편집기와 카드가 동시에 열리지 않습니다. 기존 클립보드 자동 복사 동작은 유지됩니다. 클립보드 모드의 알림은 실제 복사·저장 결과를 안내하며 누르면 라이브러리를 엽니다.
- 이전 버전의 빠른 작업 카드 설정은 값에 관계없이 **편집기 열기**로 이행합니다. 이미 새 버전에서 선택한 캡처 후 동작은 유지합니다.
- 선택형 빠른 작업 카드는 280px 가로형으로 줄이고 캡처 영역 가까이에 배치합니다. 화면 경계에서는 위치를 보정합니다. 썸네일을 드래그해 파일을 전달할 수 있으며, 포인터가 카드 위에 있거나 **Alt+Q**로 진입하면 **C 복사 · E 편집 · P 화면 고정 · S 저장 · Esc 닫기**를 사용할 수 있습니다. 약 6초 후 닫히며 포인터를 올리거나 유지 버튼을 선택하면 시간을 멈춥니다.
- 자르기 도구 **X**를 선택하면 이미지 전체에 자르기 틀이 나타납니다. 틀 이동, 여덟 방향 크기 조절, 바깥 영역에서 새 틀 그리기, 드래그 중 3분할 안내선과 픽셀 크기 표시를 제공합니다.
- 자르기 비율은 자유·원본·1:1·4:3·16:9·9:16을 지원하며 너비와 높이를 직접 입력할 수 있습니다. **Enter** 또는 틀 안 더블클릭으로 적용하고 **Esc**로 취소합니다. **Shift** 드래그는 비율을 유지하고, 방향키는 1px, **Shift+방향키**는 10px씩 이동합니다. 적용한 자르기는 실행 취소·다시 실행할 수 있습니다.
- 주석 편집기 도구는 작은 창에서도 모두 보이는 두 열로 배치했습니다. 상단 명령은 공간에 맞춰 줄을 바꿉니다. 동영상 편집기, 빠른 작업 카드, OCR 결과의 관련 버튼에도 단축키를 표시합니다. 일반 설정의 **버튼에 단축키 표시**에서 끌 수 있습니다.
- 한국어 안내 문구를 정리하고, 여섯 테마에서 작은 단축키가 읽히도록 표시 색상을 맞췄습니다.

Windows 11 x64 설치형과 포터블은 .NET 런타임을 포함합니다.
