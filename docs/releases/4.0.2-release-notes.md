# MyCapture 4.0.2

캡처 후 열리는 화면을 선택할 수 있고, 이미지 자르기는 적용 전에 틀을 조정할 수 있습니다. 주요 편집 버튼에는 단축키를 함께 표시합니다.

- 일반 설정에 **캡처 후 동작**을 추가했습니다. 기본값은 **편집기 열기**이며, **빠른 작업 카드** 또는 **클립보드에만 복사**를 선택할 수 있습니다. 편집기와 카드가 동시에 열리지 않습니다. 영역·창·전체 화면·마지막 영역 반복·지연·스크롤 캡처는 세 모드 모두에서 클립보드 복사와 라이브러리 저장을 병렬로 시작합니다. **클립보드에만 복사**는 편집기와 카드 없이 짧은 알림만 표시하는 모드입니다. 클립보드 모드의 알림은 실제 복사·저장 결과를 안내하며 누르면 라이브러리를 엽니다.
- 이전 버전의 빠른 작업 카드 설정은 값에 관계없이 **편집기 열기**로 이행합니다. 이미 새 버전에서 선택한 캡처 후 동작은 유지합니다.
- 선택형 빠른 작업 카드는 280px 가로형으로 줄이고 캡처 영역 가까이에 배치합니다. 화면 경계에서는 위치를 보정합니다. 썸네일을 드래그해 파일을 전달할 수 있으며, 카드 배경(버튼이 아닌 영역)을 클릭하거나 **Alt+Q**로 진입해 키보드 포커스를 준 뒤 **C 복사 · E 편집 · P 화면 고정 · S 저장 · Esc 닫기**를 사용할 수 있습니다. 약 6초 후 닫히며 포인터를 올리거나 유지 버튼을 선택하면 시간을 멈춥니다. **Alt+Q**는 자동 닫힘이 활성화된 카드에만 등록하며, 유지 중인 카드는 배경 클릭으로 진입합니다. 동작 버튼·썸네일 클릭과 드래그는 다른 앱의 포커스를 유지합니다. 복사 버튼 클릭 뒤 원래 앱에 바로 붙여 넣을 수 있으며, 키보드로 진입하지 않은 카드는 포인터가 벗어나면 자동 닫힘 시간이 다시 진행됩니다. 다른 앱에 입력하는 C·E·P·S·Esc는 카드 위에 포인터가 있어도 그대로 전달됩니다.
- 자르기 도구 **X**를 선택하면 이미지 전체에 자르기 틀이 나타납니다. 틀 이동, 여덟 방향 크기 조절, 바깥 영역에서 새 틀 그리기, 드래그 중 3분할 안내선과 픽셀 크기 표시를 제공합니다.
- 자르기 비율은 자유·원본·1:1·4:3·16:9·9:16을 지원하며 너비·높이 입력에서 **Enter**를 누르거나 포커스를 옮기면 값만 확정하며 자르기 틀은 유지합니다. 빈 값·문자·소수 등 잘못된 입력에는 오류를 표시하고 입력한 내용을 보존합니다. 값을 고칠 때까지 적용·완료·복사·저장을 막습니다. 크기 입력란 밖에서 **Enter**, **적용** 버튼 또는 틀 안 더블클릭으로 적용하고 **Esc**로 취소합니다. **Shift** 드래그는 비율을 유지하고, 방향키는 1px, **Shift+방향키**는 10px씩 이동합니다. 완료·복사·저장을 실행하면 변경한 틀을 먼저 적용합니다. 이미지 전체 그대로인 틀은 적용하지 않습니다. 적용한 자르기는 실행 취소·다시 실행할 수 있습니다. 자르기는 마지막 사용 도구로 저장하지 않습니다.
- 주석 편집기 도구는 작은 창에서도 모두 보이는 두 열로 배치했습니다. 상단 취소·복사·완료는 오른쪽에 배치하고 좁은 창에서 줄을 바꿉니다. 동영상 편집기, 빠른 작업 카드, OCR 결과의 관련 버튼에도 단축키를 표시합니다. 일반 설정의 **버튼에 단축키 표시**에서 끌 수 있습니다.
- 이번에 수정한 주석·동영상 편집기와 일반 설정의 한국어 안내 문구를 정리하고, 여섯 테마에서 작은 단축키가 읽히도록 표시 색상을 맞췄습니다.
- 상단 단축키는 11px, 도구 레일은 10px로 표시하며 비활성 명령은 중립 색으로 구분하고 단축키 대비를 유지합니다. 도구·상단 버튼·색 견본·사용자 색 적용을 마우스로 누른 뒤에도 한 글자 단축키와 Esc가 동작하며, Tab으로 버튼을 탐색하고 Space·Enter로 실행할 수 있습니다. 자르기 틀 밖은 어둡게 표시하고 Windows 고대비를 전환하면 시스템 색상 갱신을 기다린 뒤 열린 자르기 화면에도 반영합니다. 앱의 고대비 테마만 선택한 경우에는 반투명 어두운 마스크를 유지합니다. **카드 유지**는 열린 자물쇠와 닫힌 자물쇠로 상태를 구분하며, 카드 작업 버튼에는 짧은 지연의 툴팁을 제공하고, 접근성 이름과 단축키를 구분해 전달합니다.

Windows 11 x64 설치형과 포터블은 .NET 런타임을 포함합니다.
