# MyCapture 2.3.5

정밀(Careful) 품질이 이미지 보정 뒤에 Real-ESRGAN 4배 초해상도를 실행하도록 바뀌었습니다. 모델은 처음 정밀을 쓸 때 약 67MB를 내려받아 `%LOCALAPPDATA%\MyCapture\ocr-models`에 저장하며, 이후에는 다시 받지 않습니다. 내려받기가 실패하면 기존 방식(최근접 이웃 확대)으로 계속 인식합니다. 느림·보통·빠름은 2.3.4와 동일합니다.

Real-ESRGAN은 BSD-3 라이선스이며, 출처는 `THIRD-PARTY-NOTICES.md`에 기록했습니다.

2.3.3의 기본 빠름과 2.3.2의 시작 대화상자 수정은 그대로입니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
