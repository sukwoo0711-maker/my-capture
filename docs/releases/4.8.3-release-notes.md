# MyCapture 4.8.3

4.8.3은 텍스트 인식(OCR)을 사용한 뒤 남는 메모리와 OCR 준비 과정의 처리 부담을 줄인 업데이트입니다.

- OCR 결과 창을 닫으면 원본 이미지, 인식한 글자, 표, 번역 결과와 관련 참조를 해제합니다. 창을 화면에서 숨긴 뒤에도 이미지와 결과가 메모리에 남던 문제를 고쳤습니다.
- 일반 화면 캡처처럼 투명하지 않은 이미지의 Windows 기본 OCR 준비 과정을 단축했습니다. PNG로 변환했다가 다시 읽는 과정을 줄여 처리 시간과 임시 메모리 할당을 줄입니다.
- OCR을 취소하거나 결과 창을 닫고 다시 열 때, 이전 작업의 늦은 완료가 새 결과나 창 상태를 덮어쓰지 않도록 고쳤습니다.

GitHub 릴리스에는 x64와 x86의 사용자별 설치 파일(`setup.exe`)과 포터블 ZIP을 제공합니다. 64비트 Windows에서는 x64판을 사용하십시오. x86판은 Windows 10 22H2의 32비트 PC용이며 Windows 기본 OCR을 사용합니다.

다운로드한 파일은 x64의 `SHA256SUMS.txt`, x86의 `SHA256SUMS-win-x86.txt`로 확인할 수 있습니다.

이전 변경은 [4.8.2 릴리스 노트](4.8.2-release-notes.md)에서 확인할 수 있습니다.
