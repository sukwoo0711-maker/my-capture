# MyCapture 4.5.0

4.5.0은 코딩하는 동안 엑셀 사양 표와 자주 쓰는 코드를 핀으로 띄워 두고, 원문 그대로 다시 붙여 넣는 흐름을 다듬은 업데이트입니다. 엑셀이나 에디터에서 복사한 뒤 F3을 누르면 핀이 뜨고, 핀에서 Ctrl+C를 누르면 원문이 복사됩니다.

Microsoft Store 배포용 패키지 버전은 `4.5.0.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 핀

- 새로 설치하면 F3이 클립보드 내용을 핀으로 띄우고, Shift+F3이 핀을 모두 숨기거나 다시 보입니다. 이미 쓰던 단축키 설정은 그대로이며, 설정의 단축키에서 '기본값'으로 되돌릴 수 있습니다. 다른 프로그램이 F3을 쓰고 있으면 시작할 때 알려 드립니다.
- 텍스트·표·코드 핀에서 Ctrl+C(마우스 막대와 메뉴의 '복사' 포함)를 누르면 원문 텍스트와 이미지를 함께 복사합니다. 에디터에는 원문이, 이미지 편집기에는 그림이 붙습니다. 이미지 핀은 지금처럼 이미지를 복사합니다.
- F3이나 트레이 메뉴로 띄운 핀은 키보드 포커스를 가져가지 않습니다. 핀을 띄운 뒤 에디터에서 그대로 이어서 입력합니다. 핀을 클릭하면 핀이 선택되어 Esc와 Ctrl+C가 동작합니다.
- 새로 설치하면 더블클릭해도 핀이 닫히지 않습니다. Esc나 닫기 버튼으로 닫습니다. 이미 쓰던 설정은 그대로입니다.
- 설정 → 편집 → 핀의 '다음 실행 때 열린 핀 다시 띄우기'를 켜면 앱이나 PC를 다시 시작해도 열려 있던 핀이 같은 자리에 다시 뜹니다. 핀 이미지와 원문은 이 PC의 앱 데이터 폴더에만 저장하고, 끄면 저장한 핀을 바로 지웁니다. 새로 설치하면 켜져 있고, 이미 쓰던 사용자는 꺼져 있습니다.
- 단축키 도움말(F1)의 핀 항목에 원문 텍스트 복사(Ctrl+C, Ctrl+더블클릭)를 넣었습니다.

## 핵심 단축키

- 처음 실행할 때 Ctrl+Shift+C(영역 캡처), Ctrl+Shift+X(영역 녹화), Ctrl+Shift+Z(라이브러리), F3(클립보드를 핀으로)을 MyCapture 단축키로 쓸지 한 번 묻습니다. 덮어쓰기를 고르면 네 키를 지정하고, 다른 프로그램이 먼저 등록한 키도 MyCapture가 먼저 처리합니다. 이미 쓰던 사용자는 업데이트 뒤 첫 실행에서 한 번 묻습니다.
- 설정 → 단축키에 'Ctrl+Shift+C·X·Z와 F3을 다른 프로그램보다 먼저 처리'가 생겼습니다. 켜 두면 MyCapture가 실행 중인 동안 다른 프로그램의 같은 단축키(예: 파일 탐색기의 F3 검색)는 동작하지 않습니다.

## 동영상 편집기

- 짧은 클립의 GIF 내보내기 창에서 미리보기 프레임 수와 요약의 프레임 수가 다르게 보이던 문제를 고쳤습니다. 요약과 공유 권장 판단은 실제로 저장되는 GIF 이미지 수를 씁니다.

## 데이터

- 설정에 새 항목(열린 핀 다시 띄우기, 핵심 단축키 질문 여부와 먼저 처리)이 생겼습니다. 4.4.0으로 되돌리면 새 항목은 무시되고, 앱 데이터 폴더의 `pins` 폴더도 쓰지 않습니다. 캡처, 라이브러리, 색인 형식은 4.4.0과 같습니다.

캡처 카드와 시각 체계 정리 같은 이전 변경은 [4.4.0](4.4.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
