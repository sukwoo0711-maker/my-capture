# MyCapture 2.3.10

라이브러리 동영상 재생과 F9 GitHub 이미지 주소 흐름을 개선했습니다.

부동 영상 플레이어 — 오른쪽 사이드바에 있던 인라인 재생 패널을 없애고, 별도의 항상 위 부동 플레이어 창으로 바꿨습니다. 기존에는 카드와 사이드바 양쪽에 재생 수단이 있어 기능이 중복됐고, 재생 패널이 사이드바의 영상 편집 버튼 위에 겹쳐 눌렸습니다. 이제 재생은 카드 더블클릭(또는 Enter) 하나로만 시작되고, 플레이어 창은 화면 오른쪽 위에 떠서 라이브러리와 겹치지 않습니다. 닫기·재생/일시정지·구간 이동을 플레이어 안에서 모두 할 수 있습니다.

F9 포커스 복구 — GitHub 이미지 주소 복사(F9)는 브라우저를 열어 댓글 창에 붙여넣는 방식이라 어쩔 수 없이 포커스를 가져옵니다. 이제 흐름이 끝나면 시작 전 활성 창으로 포커스를 되돌려, 업로드가 진행되는 동안 사용자의 다른 작업이 덜 방해받도록 했습니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
