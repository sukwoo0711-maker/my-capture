# MyCapture 1.9.1

1.9.0의 기능을 유지하는 긴급 유지보수 버전입니다.

- `PinViewState_InitialSizeMatchesImageAtFit`이 화면 배율을 무시하고 64 DIP를 기대하던 문제를 수정했습니다. 150% 배율에서는 64픽셀이 약 42.67 DIP이며, 검사는 배율을 적용한 실제 픽셀 크기를 확인합니다.
- 검사 실패 시에도 생성된 핀 창을 닫도록 정리 경로를 보완했습니다.
- 앱의 정상적인 1:1 픽셀 표시 계산은 유지합니다. 이번 변경은 캡처 성능이나 메모리 사용량에 대한 추가 수정은 포함하지 않습니다.

사용자의 긴급 배포 요청에 따라 로컬 테스트와 패키지 실행 테스트는 실행하지 않았습니다. GitHub main 보호 규칙에서 요구하는 자동 CI는 유지합니다. 소스 변경은 독립 검토하며 Release 빌드와 패키지 생성을 수행합니다.

Windows 11 x64 설치판: `MyCapture-1.9.1-win-x64-setup.exe`

포터블: `MyCapture-1.9.1-win-x64-portable.zip`
