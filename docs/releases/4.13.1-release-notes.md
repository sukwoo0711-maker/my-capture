# MyCapture 4.13.1

4.13.1은 그림 핀 번역이 그림 위에 덧씌워지지 않고 번역문 문서로 열리던 문제를 고친 업데이트입니다. 4.13.0의 변경은 [4.13.0 릴리스 노트](4.13.0-release-notes.md)에서 확인할 수 있습니다.

- 설정의 인식 품질을 `정확`으로 두면 그림 핀의 `번역`이 원래 그림 위에 덧씌워지지 않고 번역문 문서로 열리던 문제를 고쳤습니다. 똑바른 화면 캡처도 글자가 2° 넘게 기운 것으로 잘못 잰 것이 원인이었습니다.
- 그림 핀을 번역할 때는 인식 품질 설정과 상관없이 덧씌움에 맞춘 방식으로 글자를 읽습니다. 문자 인식 창은 설정한 품질을 그대로 씁니다.
