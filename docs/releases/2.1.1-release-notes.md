# MyCapture 2.1.1

라이브러리 편집 버튼의 글자 잘림과 프레임 레이어의 표시 구간 편집을 수정하고, F4의 GitHub 이미지 URL 가져오기를 보완했습니다.

- 라이브러리 카드의 이미지·영상 편집 버튼은 글자 없이 연필 아이콘만 표시합니다. 툴팁과 접근성 이름은 유지합니다.
- 영상 편집에서 프레임·이미지·도형 레이어도 속성 편집으로 시작·끝 시간을 입력할 수 있습니다. 기존 이미지와 위치 정보, 실행 취소 동작을 유지합니다.
- 짧은 프레임 막대의 조절 영역을 넓히고, 영상 끝의 오른쪽 핸들이 화면 밖으로 나가지 않도록 수정했습니다. 핸들을 잡을 때 시간이 갑자기 이동하는 문제도 보완했습니다.
- F4는 설정한 GitHub 이슈의 실제 주소와 댓글·설명 입력란을 확인한 뒤 이미지를 붙여넣고, 새로 생성된 첨부 이미지의 HTTPS 주소만 클립보드에 복사합니다. 댓글을 게시하지 않습니다.
- 기존 업로드가 진행 중이거나 사용자가 클립보드를 변경한 경우 잘못된 URL을 복사하거나 새 클립보드를 덮어쓰지 않도록 검사합니다.

F4 사용 시 브라우저에서 GitHub에 로그인되어 있어야 하며, 업로드 중 해당 탭과 클립보드를 유지해야 합니다. 실제 로그인된 브라우저의 업로드부터 URL 복사까지 이어지는 검증은 아직 완료하지 않았습니다. 브라우저의 접근성 지원 상태에 따라 동작 확인이 필요합니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
