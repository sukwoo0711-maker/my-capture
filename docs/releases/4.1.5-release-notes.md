# MyCapture 4.1.5

4.1.5는 Microsoft Store 제출용 패키지 검사를 바로잡은 업데이트입니다. 앱의 화면과 동작은 4.1.4와 같습니다.

Microsoft Store 배포용 패키지 버전은 `4.1.5.0`입니다. GitHub 릴리스의 포터블 zip은 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오.

## 패키지 검사

- 오류 대화상자를 닫는 자체 검사가 4.1.2에서 추가된 **문제 신고** 버튼 때문에 버튼을 고르지 못하고 실패하던 문제를 수정했습니다. 검사는 이제 표준 **닫기** 버튼을 눌러 대화상자가 닫히는지 확인합니다.
- 이 검사가 실패하면 멈추지 않고 5초 안에 실패로 끝납니다.

4.1.3과 4.1.4의 캡처 선택 화면 개선은 [4.1.3](4.1.3-release-notes.md), [4.1.4](4.1.4-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
