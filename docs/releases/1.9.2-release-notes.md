# MyCapture 1.9.2

이미지 열기와 연속 캡처의 안정성을 개선하고, 트레이와 편집 옵션을 정리하는 유지보수 버전입니다.

- 갤러리에서 이미지를 열거나 용량 절감 내보내기를 준비할 때, 자신의 편집 잠금을 다른 작업으로 오인해 표시하던 “이미지가 로딩 중 변경되었습니다” 오류를 수정합니다.
- 재캡처 시 이전 편집 창을 닫고 화면이 정리된 뒤 새 캡처를 시작합니다. 준비 중인 중복 요청은 겹쳐 실행하지 않습니다.
- 영역을 선택한 것만으로 라이브러리에 등록하지 않습니다. 확인 등 명시적인 완료 동작 전 취소하거나 다시 캡처한 이미지는 라이브러리에 남지 않습니다.
- 트레이 알림과 단축키 안내에 앱의 기존 테마를 적용합니다. 트레이 세부 메뉴에서 Language를 통해 한국어와 영어를 선택할 수 있습니다.
- 마지막으로 사용한 편집 도구와 도형 옵션을 기억합니다.

긴급 배포 요청에 따라 로컬 테스트와 패키지 실행 테스트는 생략합니다. Release 빌드, 독립 코드 검토 및 GitHub 보호 규칙에서 요구하는 자동 CI는 유지합니다. 이번 버전에 대해 별도의 RAM 절감률이나 실제 화면 반응 시간 측정치는 제시하지 않습니다.

Windows 11 x64 설치판: `MyCapture-1.9.2-win-x64-setup.exe`

포터블: `MyCapture-1.9.2-win-x64-portable.zip`
