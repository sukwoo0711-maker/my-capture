# MyCapture 1.6.0

MyCapture 1.6.0은 캡처 직후의 불필요한 화면 고정을 없애고, 클립보드의 텍스트와 Excel 표를 읽기 쉬운 플로팅 참조 카드로 확장한 워크플로 릴리스입니다.

## 주요 변경 사항

- 영역 캡처를 완료하면 원본을 클립보드에 복사하고 편집기를 열되, 동일 이미지를 별도의 플로팅 창으로 자동 생성하지 않습니다. 화면 고정은 사용자가 `F3`을 누를 때만 수행합니다.
- 이미지 편집기의 기본 주석 도구를 자유 그리기에서 도형(사각형)으로 변경했습니다.
- `F3` 화면 붙여넣기가 이미지뿐 아니라 일반 텍스트와 Excel의 탭 구분 셀 범위를 지원합니다.
- 일반 텍스트는 고대비 카드로, Excel 셀 범위는 행과 열 및 빈 셀을 보존한 격자 이미지로 렌더링합니다.
- Excel이 셀 텍스트와 미리보기 이미지를 함께 제공하면 편집 가능한 셀 구조를 유지하기 위해 표 텍스트를 우선합니다. 일반적인 이미지와 설명 텍스트 조합은 기존처럼 이미지를 우선합니다.
- 텍스트와 표 핀에서 `Ctrl+C`는 보이는 이미지를 복사하고, `Ctrl+더블클릭`은 핀 생성 당시 보존한 전체 Unicode 원문을 복사합니다. 이미지 핀의 `Ctrl+더블클릭` OCR 동작은 유지됩니다.
- 원문 복사 기능을 우클릭 메뉴, 툴팁 및 접근성 도움말에 노출했습니다.
- 대용량 텍스트와 표는 화면 미리보기 크기를 제한하되, 원문 복사에는 잘리지 않은 전체 문자열을 사용합니다.
- 96 DPI로 렌더링한 텍스트·표 카드가 고배율 모니터에서 지나치게 작게 열리지 않도록 초기 배치를 보정했습니다.

## 설치 및 호환성

- 지원 운영체제: Windows 11 21H2(build 22000) 이상, x64
- Windows 11 ARM64: x64 에뮬레이션으로 실행 가능
- 배포 형태: 오프라인 self-contained 설치 파일과 portable ZIP
- 사전 설치 .NET/SDK: 필요 없음
- 라이선스: MIT
- 서명: Authenticode 미서명이며 Windows에서 알 수 없는 게시자 경고가 나타날 수 있습니다.

Excel 표의 원문 복사는 Unicode 탭/줄바꿈 셀 값입니다. 행과 열은 다시 붙여넣을 수 있지만 셀 스타일, 병합, 수식 자체, 행 높이와 열 너비는 포함하지 않습니다.
