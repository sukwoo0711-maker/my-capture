# MyCapture 4.4.0

4.4.0은 매일 쓰는 흐름과 화면을 다시 정리한 업데이트입니다. 캡처 직후 편집기 대신 작은 카드가 뜨고, 버튼마다 붙어 있던 단축키 글자와 테두리를 걷어 내 중요한 것이 먼저 보이게 했습니다. 설정은 바꾸는 즉시 저장되고, 앱 안에서 바로 문의할 수 있습니다.

Microsoft Store 배포용 패키지 버전은 `4.4.0.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 캡처 직후

- 새로 설치하면 캡처 직후 편집기 대신 화면 모서리에 작은 카드가 뜹니다. 카드에서 E를 누르면 편집기가 열립니다. 이미 쓰던 설정은 그대로 유지됩니다.
- 카드의 미리보기를 카드 폭만큼 키웠습니다. 결과('복사됨')를 먼저 보여 주고, 편집만 글자 버튼으로, 핀·저장·텍스트 복사·복사는 아이콘으로 둡니다.
- '유지' 버튼은 '자동으로 닫지 않음' 아이콘으로 바뀌었습니다.
- 카드를 클릭하거나 Alt+Q를 누르면 키보드로 카드를 조작할 수 있습니다.

## 처음 실행

- 첫 실행 안내를 '한 번 캡처해 보십시오' 한 화면으로 줄였습니다.
- 핀으로 띄우는 방법과 핀을 모두 숨기는 방법은 첫 캡처와 첫 핀 직후에 한 줄씩 한 번만 알려 드립니다.

## 화면

- 글자 크기와 글자색을 몇 단계로 정리하고, 입력 칸을 뺀 카드·패널·버튼의 테두리를 걷어 냈습니다. 고대비 테마는 모든 테두리를 그대로 유지합니다.
- 빨강은 화면마다 주 버튼 하나와 녹화 상태에만 씁니다. 선택과 키보드 포커스는 흰(밝은 테마에서는 검은) 테두리로, 배지는 회색으로 표시합니다.
- 버튼 아래 단축키 글자는 새로 설치하면 숨겨져 있습니다. Alt를 누르고 있는 동안 나타나며, 도움말 풍선과 F1 단축키 표에는 늘 표시됩니다.
- 테마는 시스템 따르기·밝게·어둡게·고대비 네 가지입니다. 새로 설치하면 Windows 앱 모드를 따릅니다. 예전 테마를 쓰던 사용자는 가장 가까운 테마로 바뀌고, 포인트 색은 빨강으로 통일했습니다.

## 캡처·녹화 막대

- 영역 선택 막대를 아이콘 중심으로 줄이고, 창·스크롤·지연 캡처를 막대에 바로 두었습니다. 이름과 키는 도움말 풍선에 있습니다.
- 녹화 막대는 빨간 점·경과 시간·일시 정지·중지만 남긴 작은 막대가 되었습니다. 일시 정지하면 '일시 정지됨'으로 바뀝니다.

## 편집기

- 이미지 편집기 오른쪽 속성 패널을 캔버스 위 한 줄 속성 막대로 옮겨 캔버스를 창 폭만큼 씁니다. 사용자 지정 색은 색 점 끝의 '+'로 엽니다.
- 단계 번호가 지금 고른 색을 따릅니다.
- 동영상 편집기 기본 화면을 미리보기, 자르기 손잡이가 있는 시간축, 텍스트, 내보내기, 저장으로 줄였습니다. 프레임 단위 이동, 시작·끝 입력, 레이어 목록은 '자세히'를 열면 오른쪽 열에 나타납니다. 기존 단축키는 모두 그대로 동작합니다.

## 라이브러리

- 이미지가 타일을 채우고, 촬영 시각은 이미지 위에 작게 겹쳐 표시합니다. 동작 아이콘은 마우스를 올리거나 선택했을 때만 나타나고, 종류 배지는 동영상에만 붙습니다.
- 새로 설치하면 라이브러리 이미지를 기간 제한 없이 보관합니다. 대신 5GB 또는 1,000개를 넘으면 오래된 캡처부터 정리합니다. 7일 자동 삭제를 쓰던 사용자의 설정은 그대로이며 설정의 저장 공간에서 바꿀 수 있습니다.

## 설정과 문의

- 설정은 바꾸는 즉시 저장되고 '저장됨'으로 알려 드립니다. '적용' 버튼은 없어졌습니다.
- 설정 창 위쪽에서 설정을 검색할 수 있습니다.
- '기본값으로 재설정'은 정보 탭으로 옮겼습니다.
- 트레이 메뉴와 설정의 정보 탭에 '문의하기'가 생겼습니다. 버전, Windows, 화면 배율 같은 진단 정보를 채워 주고, 진단 정보 복사, GitHub 이슈, Microsoft Store 리뷰 중에서 고를 수 있습니다. 캡처나 파일 경로 같은 개인 정보는 담지 않습니다.

## 데이터

- 설정에 새 항목(첫 사용 안내 표시 여부, 시스템 테마)이 생겼습니다. 4.3.1로 되돌리면 새 항목은 무시되고, '시스템 따르기'를 고른 설정은 4.3.1에서 어두운 '자정' 테마로 열립니다. 캡처, 라이브러리, 색인 형식은 4.3.1과 같습니다.

편집 중 캡처 안내와 표시 결함 수정 같은 이전 변경은 [4.3.1](4.3.1-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
