# MyCapture 4.0.1

4.0.0의 캡처 후 작업과 단축키 입력에서 발견된 문제를 수정했습니다.

- Quick Access 카드가 자동으로 표시되거나 마우스로 조작될 때 편집기 포커스를 유지합니다. 편집기에서 Alt+Q를 누르면 카드의 키보드 조작으로 전환합니다. 네 가지 작업 버튼은 두 줄로 배치해 한국어·영어 레이블이 잘리지 않도록 했습니다.
- 다음 캡처 전에 카드와 도움말을 닫고 화면에서 사라질 시간을 반영합니다. 영역·창·전체 캡처에 이전 카드가 포함되지 않도록 수정했습니다.
- 전역 단축키에서 보조키 없는 문자·숫자·이동 키를 거부합니다. F1–F24와 PrintScreen은 단독 지정할 수 있습니다. Backspace/Delete는 입력 지우기, Tab은 다음 컨트롤 이동으로 동작합니다. IME 키 처리와 OEM 키 저장·복원을 보강했습니다.
- 카드의 복사·화면 고정·저장·드래그가 현재 편집 결과를 공통으로 사용합니다. 편집기가 닫힌 뒤에는 라이브러리에 저장된 최신 결과를 사용합니다.
- 첫 실행 안내를 닫으면 완료 상태를 저장합니다.
- 동영상 레이어 한도, 잘못된 이미지와 디스플레이 변경의 구체적인 안내를 유지합니다. 소유자 없는 오류 대화상자는 작업 표시줄에 표시하며, 테마 대화상자를 만들 수 없는 예외 경로에는 시스템 대화상자를 제공합니다.
- 캡처 오버레이에서는 F1/? 도움말을 열지 않고, 암호 입력의 물음표를 가로채지 않습니다.
- 라이브러리 관련 조사·안내 문구와 README의 이전 릴리스 링크를 정리했습니다.

- 빠른 작업 카드는 화면 공유와 다른 캡처 도구의 결과에도 표시되지 않습니다.
- 4.0.0에서 저장한 수정키 없는 문자·숫자·이동 단축키와 Shift만 조합한 해당 단축키는 해제됩니다. 캡처 단축키가 해당하는 경우 기본값 Ctrl+Shift+C로 복원되며 첫 실행 시 변경 알림이 표시됩니다. F1–F24와 PrintScreen의 단독·Shift 조합은 유지됩니다.

Windows 11 x64 설치형과 포터블은 .NET 런타임을 포함합니다.
