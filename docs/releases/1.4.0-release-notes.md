# MyCapture 1.4.0

MyCapture 1.4.0은 캡처부터 고정, 편집, 라이브러리 확인까지의 흐름을 더 짧게 만들고 영상 편집을 비파괴 레이어 기반으로 확장한 기능 릴리스입니다. 소리는 녹음하거나 재생하지 않는 기존 원칙을 유지합니다.

## 주요 변경 사항

- `Ctrl+Shift+C` 영역 캡처는 캡처 직후 원본을 클립보드에 복사하고 화면에 고정한 다음 편집기를 엽니다. 편집을 완료하거나 저장하면 편집 결과도 클립보드에 갱신됩니다.
- 라이브러리는 `Ctrl+Shift+Z`로 열며 이미지와 동영상을 배지로 명확하게 구분합니다. MP4는 외부 플레이어 없이 라이브러리 창 안에서 음소거 상태로 재생하고 탐색할 수 있습니다.
- 영역 녹화 단축키를 `Ctrl+X`로 단순화했습니다. 기존 설정은 스키마 마이그레이션으로 새 기본값에 안전하게 맞춥니다.
- 녹화 영역 선택 테두리를 더 굵게 만들고 잘리던 안내 문구를 제거했습니다.
- 영상 편집기의 시간 텍스트와 프레임 편집 결과를 각각 독립적인 비파괴 레이어로 저장합니다. 음악 편집 도구와 유사한 두 개의 트랙에서 레이어 위치와 구간을 한눈에 확인할 수 있습니다.
- 하나의 `자르기` 모드에서 시작·끝 삭제 핸들을 드래그해 제거 범위를 정합니다. 삭제 영역은 별도 색과 패턴으로 표시되며 재생 헤드는 유지 구간 안에서만 움직입니다.
- GIF 내보내기 배속을 `0.5x`, `1x`, `1.5x`, `2x`, `3x`, `4x` 중 선택할 수 있습니다. 짧은 프레임·텍스트 레이어 경계도 스케줄에 포함합니다.
- 편집 미리보기, MP4 내보내기, GIF 내보내기가 동일한 텍스트·프레임 레이어 합성 파이프라인을 사용합니다.

## 설치 및 호환성

- 지원 운영체제: Windows 11 21H2(build 22000) 이상, x64
- Windows 11 ARM64: x64 에뮬레이션으로 실행 가능
- 배포 형태: 오프라인 self-contained 설치 파일과 portable ZIP
- 사전 설치 .NET/SDK: 필요 없음
- 라이선스: MIT
- 서명: Authenticode 미서명이며 Windows에서 알 수 없는 게시자 경고가 나타날 수 있습니다.

설치 파일 실행이 조직의 AppLocker/WDAC 정책으로 차단되면 portable ZIP을 사용할 수 있습니다. 다운로드한 파일은 함께 제공되는 `SHA256SUMS.txt`로 무결성을 확인하십시오.
