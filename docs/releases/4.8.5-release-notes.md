# MyCapture 4.8.5

4.8.5는 라이브러리에서 이미지를 살펴볼 때 안내와 출처 정보가 미리보기를 가리지 않도록 개선한 업데이트입니다.

- 이미지 카드에 포인터를 올릴 때마다 나타나던 끌기 안내를 없앴습니다. 필요한 경우 카드 메뉴의 `끌기 안내`에서 확인할 수 있습니다.
- 출처를 이미지 아래의 작은 아이콘으로 표시합니다. 아이콘에 포인터를 올리거나 키보드 초점을 두면 상세 정보를 확인할 수 있으며, 클릭하면 기존처럼 출처를 엽니다.
- 긴 제목은 제목 영역에 포인터를 올리거나 키보드로 카드를 선택할 때 펼쳐집니다. 이미지 위를 지나가거나 클릭할 때에는 제목 팝업이 열리지 않습니다.
- 열린 설명은 Esc로 닫을 수 있습니다. 좁은 카드와 큰 글자 설정에서 출처·상태·동영상 배지가 겹치지 않도록 배치를 조정했습니다.
- 기존 외부 앱으로 끌기, 폴더 이동, 핀, 보관, 복사, 편집 기능은 유지합니다.

이전 OCR 메모리·응답 개선은 [4.8.3 릴리스 노트](4.8.3-release-notes.md)에서 확인할 수 있습니다.
