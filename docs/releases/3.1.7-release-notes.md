# MyCapture 3.1.7

동영상 내보내기를 빠르게 하고, 이미지 편집기의 회전 오작동을 고쳤습니다. GIF 길이 제한을 없애고, 녹화 저장을 더 빠르게 체감하도록 개선했습니다.

- **내보내기 속도**: 편집하지 않은 구간 저장(트리밍)이 최대 3.4배 빨라졌습니다(1080p 30fps 10초 기준 13.9초 → 4.1초). 프레임마다 반복되던 화면 조판과 복사를 건너뛰고 디코딩한 프레임을 인코더로 곧바로 넘깁니다. 텍스트를 넣은 내보내기도 18% 빨라지고 메모리 할당은 절반으로 줄어 긴 영상에서도 안정적입니다.
- **회전 오작동 수정**: 이미지 편집기에서 90도 회전 뒤 모자이크·자르기·이미지 삽입·검열 처리가 잘못된 위치를 읽던 문제를 고쳤습니다. 회전과 자르기를 섞어 쓴 뒤 되돌리기 해도 캔버스와 주석이 올바른 위치에 복원됩니다.
- **동영상 프레임 편집**: 동영상에서 추출한 프레임을 이미지로 편집해 회전하면 결과가 동영상에 올바르게 반영됩니다(회전한 화면은 검은 여백과 함께 표시). 자르기만 한 편집은 원래 위치에 정확히 얹힙니다.
- **GIF 길이 제거**: GIF 내보내기의 20초 제한을 없앴습니다. 20초를 넘기면 파일이 커지고 계산에 오래 걸릴 수 있음을 미리 알려줍니다.
- **녹화 저장 체감**: 녹화를 중지하면 인코더 마무리가 끝나는 즉시 화면이 돌아오고, 갤러리 등록은 뒤에서 진행됩니다. 등록이 끝나기 전 핫키를 누르면 트레이 알림으로 안내합니다. 저장 중 표시 문구도 실제 동작에 맞게 바꿨습니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
