# MyCapture 4.8.0

4.8.0은 텍스트 인식(OCR) 결과 창에 번역 보기를 더하고, 캡처와 복사, 삭제처럼 결과가 손에 남아야 하는 순간의 반응을 다듬은 업데이트입니다. 4.7.0 검수에서 나온 편집기 Ctrl+C, 핀, 녹화 편집기, 설정 창의 문제도 고쳤습니다.

Microsoft Store 배포용 패키지 버전은 `4.8.0.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 번역

- 텍스트 인식 결과 창에 '번역' 보기가 생겼습니다. 인식한 영어 문단과 표 칸을 이 PC 안에서 한국어로 옮깁니다. 원본 그림에는 번호 윤곽을 그리고, 오른쪽에는 원문 아래에 번역을 번호순으로 나열합니다. 원본 그림의 번호 블록을 누르면 목록의 그 항목으로 이동합니다.
- 복사 버튼은 번역문을 복사하고, 원문과 함께 복사하는 선택지도 있습니다. 진행 표시와 취소, 다시 시도를 제공합니다.
- 식별자, 숫자, `rw`만 있는 칸과 영어가 아닌 글자는 번역하지 않습니다. 대소문자나 µ/μ 같은 작은 차이로 바뀐 숫자와 식별자는 원문과 대조해 되돌립니다. 되돌리지 못한 값은 블록 아래에 '번역에 없는 원문 값'과 '원문에 없는 값'으로 표시합니다.
- 번역은 기본으로 꺼져 있습니다. 번역 보기의 '번역 켜기 (247 MB)'를 누를 때 모델을 내려받습니다. 모델은 설치 파일이나 MSIX에 들어 있지 않아, 번역 기능을 넣은 뒤 설치 파일은 232 KiB(0.19%)만 커졌습니다.
- 모델을 메모리에 올리면 작업 집합이 약 400 MB이고 번역 중 최대 약 840 MB까지 오릅니다(개발 PC에서 잰 값). 1분 동안 쓰지 않으면 모델을 메모리에서 내립니다. 설정 > 일반 > 번역에서 모델 크기를 확인하고 삭제할 수 있습니다.
- 영어를 한국어로 옮기는 OPUS-MT 모델을 ONNX로 변환하고 int8로 양자화해 씁니다. 저작자 표시(CC BY 4.0)와 변경 사실(ONNX 변환, int8 양자화, 가중치 중복 제거)은 `THIRD-PARTY-NOTICES`에 적었습니다.
- 캡처 위에 번역을 겹쳐 그리는 기능은 이번 버전에 없습니다.

## 캡처와 빠른 작업 카드

- 영역을 놓으면 찍은 영역이 그 자리에서 떠오르고, 빠른 작업 카드가 뜨면 250ms 동안 카드 썸네일 자리로 날아가 앉습니다. 저장·복사와 다음 캡처는 이 움직임을 기다리지 않습니다. 움직임이 꺼진 경우(Windows 애니메이션 효과 설정을 따릅니다), 원격 세션, 스크롤 캡처, 배율이 다른 화면을 지나는 경우, 4K 한 장보다 큰 경우에는 날지 않습니다.
- 카드가 뜰 때는 불투명도와 함께 8 DIP 내려앉고, 닫힐 때는 83ms 동안 흐려지며 내려갑니다.
- 카드에서 다시 복사하면 상태 줄 체크가 다시 그려지고, 누른 단추 아이콘이 1.2초 동안 체크로 바뀝니다.
- 자동 닫힘 남은 시간 막대가 0.1초마다 한 칸씩 줄지 않고 매끄럽게 줄어듭니다.
- '캡처 완료 소리'(기본 꺼짐)를 켠 경우, 저장이 끝난 뒤 Windows 알림음 대신 영역을 놓는 순간 앱의 짧은 셔터 소리가 납니다. 복사, 카운트다운, 녹화에는 소리를 넣지 않았습니다.
- 저장이 실패한 뒤 늦게 끝난 복사 성공이 실패 표시를 지우고 카드가 이유 없이 닫힐 수 있던 문제를 고쳤습니다. 실패가 남아 있는 동안 다른 작업의 진행과 성공은 실패 문구를 덮지 않고 화면 낭독으로만 알리며, 자동 닫힘 막대는 숨깁니다. 같은 작업의 재시도가 성공하거나 카드를 닫을 때만 그 실패 표시가 풀립니다.
- 한국어 입력기(IME)가 켜진 상태에서도 카드의 P·E·T 단축키가 동작합니다.

## 캡처 선택

- 창 감지 강조가 창 사이를 83ms 동안 미끄러집니다. 클릭하면 포인터 아래 창을 바로 캡처하는 동작은 그대로입니다.
- 지연 캡처 카운트다운에서 새 숫자가 1.22배에서 내려앉고, 이전 숫자는 줄며 흐려지고, 숫자 둘레의 고리가 1초마다 줄어듭니다. 0이 되면 창이 줄며 사라지고, 창이 닫힌 뒤 캡처합니다. 화면 공유에서 카운트다운이 보이도록 캡처 제외는 이전처럼 녹화 중에만 겁니다.

## 라이브러리

- 썸네일을 읽으면 150ms 동안 서서히 나타납니다. 캐시에서 바로 보이는 경우(스크롤 복귀)는 효과가 없습니다.
- 삭제하면 카드가 120ms 동안 줄어들며 사라지고, 나머지 카드가 200ms 동안 미끄러져 빈자리를 채웁니다. 휴지통 이동과 되돌리기 기록은 이 움직임을 기다리지 않습니다.
- 복사 단추 안에 '복사됨' 체크가 1.2초 뜹니다. 단추가 없는 Ctrl+C와 메뉴 복사는 상태 줄에 '이미지 복사됨'을 보여 줍니다.
- 출처 배지를 평소에는 가볍게 보여 줍니다. 높이 22 DIP, 최대 폭 130 DIP, 보조 글자색, 테두리 없음이며, 마우스를 올리거나 선택하거나 키보드 포커스가 오면 기존 모양으로 돌아옵니다. 영상 길이 배지와 한 행의 두 열로 나눠 좁은 폭에서도 겹치지 않습니다.
- 타일 작업 단추가 83ms 동안 나타납니다.

## 핀

- 원문이 있는 코드·글·표 핀에서 선택 없이 Ctrl+C를 반복할 때 PNG를 다시 만들지 않습니다. 핀의 이미지는 바뀌지 않으므로 같은 이미지와 같은 출처 주소의 PNG를 재사용합니다. 클립보드 쓰기를 뺀 측정에서 큰 표 그림(2400×4000)의 반복 복사가 99ms에서 1.9ms로 줄었습니다. 핀을 다시 그리거나(배율 변경) 닫으면 보관한 PNG를 버립니다. 핀마다 처음 복사는 이전과 같습니다(큰 표 약 0.1초).
- 글자 선택 모드에서 수식키 없는 휠은 스크롤 끝에 닿아도 핀 배율을 바꾸지 않습니다. Ctrl+휠(투명도)과 확대 키(+, -, 0)는 그대로입니다. 정밀 터치패드의 작은 휠 값은 누적해 120마다 한 칸씩 움직입니다.
- '복사 중…' 같은 진행 문구는 200ms가 지난 뒤에만 보입니다. 그 전에 결과가 오면 결과만 보입니다.
- 글자 선택 진입 안내는 앱을 켠 뒤 처음 한 번만 6초, 다음부터는 2초 동안 보입니다.

## 편집기

- Ctrl+C와 [복사]가 4.5.2처럼 클립보드에 복사하고 라이브러리에 저장한 뒤 편집기를 닫습니다(완료와 같음). 4.6.0부터 4.7.0까지는 복사만 하고 편집기가 열려 있었습니다. 텍스트 상자에 글자를 입력하는 중의 Ctrl+C는 선택한 글자만 복사하고 편집기를 닫지 않습니다. 동영상 프레임을 정지 화면으로 편집할 때도 [복사]하면 저장합니다.
- 편집기에서 빠른 저장을 하면 '저장됨 · 파일 이름 · 폴더 열기' 카드가 뜹니다. 이미 있던 '빠른 저장 뒤 알림' 설정을 설정 화면에서 켜고 끌 수 있게 했습니다. 기본은 켬입니다.

## 녹화와 녹화 편집기

- 녹화를 멈추면 편집기가 뜰 때까지 녹화 막대에 '저장됨'이 보입니다.
- 동영상을 불러올 때 실제 진행과 관계없이 오르던 '불러오는 중… N%'를 없애고 '동영상을 불러오는 중…'만 보여 줍니다.
- Tab 같은 키보드로 포커스를 옮긴 단추·토글·체크는 Space로 자기 동작을 합니다. 마우스로 누른 단추와 토글은 지금처럼 Space가 재생과 정지입니다.
- 시작·끝 입력에 잘못된 값을 넣어도 이전 값으로 되돌리지 않습니다. 초안은 칸에 남고, 유효한 한 쌍이 될 때만 구간에 적용합니다. 범위 밖이거나 형식이 틀린 값은 그 칸에, 순서가 맞지 않는 한 쌍은 두 칸에 오류를 표시합니다. Esc와 손잡이 끌기는 실제 구간 값으로 칸을 맞춥니다.
- 눈금 '0:00.5'가 '시작 0:00.000' 태그에 가려지던 문제를 고쳤습니다. 태그와 겹치는 눈금 글자만 숨기고 눈금선은 모두 남깁니다.
- 영상을 끝까지 재생한 뒤 첫 정지 탐색이 요청 위치를 3~74ms 지나쳐 멈추던 문제를 고쳤습니다. 화면 프레임은 맞았고 어긋난 것은 미리 보기가 보고하는 위치로, 그 위치를 기준으로 하는 범위 검증 샘플과 재생 시작에 영향이 있었습니다. 이제 위치가 멈출 때까지 지켜보고, 읽은 위치가 요청과 다르면 다시 탐색합니다. 끝 상태가 다시 오면 클립을 다시 엽니다.
- 재생 헤드가 프레임 경계 0.3~0.9ms 앞에 서 있으면 '다음 프레임'이 화면을 바꾸지 못하고 프레임 번호만 올라가던 문제를 고쳤습니다. 개요 줄을 누르거나 재생을 멈추면 이렇게 설 수 있었습니다. 미리 보기 위치를 플레이어의 약 1ms 탐색 분해능에 맞춰 고릅니다.

## 화면

- 보조 버튼이 표면에서 살짝 뜬 모양으로 바뀌었습니다. 테두리는 1 DIP 세로 그라데이션이고, 라이트 테마의 보조 버튼은 흰색 채움입니다. 보조·명령·고스트 버튼의 글자는 보통 굵기로 바뀌고, 빨강 주요 버튼과 위험 버튼은 굵은 글자를 유지합니다. 클릭 영역, 높이, 글자 크기, 모서리는 그대로입니다. 고대비 테마는 바뀌지 않습니다.
- 버튼의 평소 테두리는 이전보다 옅어집니다. 마우스를 올리거나 누르거나 키보드 포커스가 올 때의 테두리 강조는 그대로입니다.
- 글자가 보통 굵기가 되어, 창이 좁아질 때 영어 명령 막대의 명령 이름이 몇 DIP 더 오래 남습니다. 한국어는 같습니다.
- 버튼을 누를 때 줄어드는 정도를 0.985배에서 0.97배로 키웠습니다.
- 핀을 닫으면 120ms 동안 0.97배로 줄며 사라지고, 알림 카드는 오른쪽으로 밀리며 사라집니다. 닫은 핀 기록과 세션 저장은 닫기 시작 시점에 끝납니다.

## 설정, 첫 화면, 문구

- 1920×1080 해상도 200% 배율에서 설정 창이 작업 영역(약 960×516 DIP)을 넘던 문제를 고쳤습니다. 포인터가 있는 모니터의 작업 영역에 크기·최소 크기·위치를 맞추고, 내용은 스크롤로 끝까지 볼 수 있습니다. 100%와 1440p 150%는 지금 크기(940×700) 그대로이고, 1080p 150%는 높이가 700에서 688 DIP로 줄어듭니다.
- 첫 화면의 '한 번 캡처해 보십시오' 아래에 '복사한 표와 코드는 F3 키로 핀에 띄웁니다.' 한 줄을 더했습니다. 실제로 지정된 핀 키를 보여 주고, 지정이 없으면 숨깁니다. 첫 화면은 작업 영역 높이를 넘으면 스크롤합니다.
- '원본 열기'를 '출처 열기'로, '원본 앱을 찾을 수 없습니다.'와 '원본 앱을 열 수 없습니다.'를 '출처 앱을 찾을 수 없습니다.'와 '출처 앱을 열 수 없습니다.'로, '출처 URL 포함'을 '출처 주소 포함'으로 바꿨습니다. 이미지 내보내기의 '원본 크기·원본 품질'처럼 편집 전 이미지를 뜻하는 '원본'은 그대로입니다.
- 라이브러리 정리 안내를 '제목과 태그를 붙여도 자동 삭제는 막지 못합니다. 중요한 캡처는 보관함에 넣으십시오.'로 고쳤습니다. 제목·태그 편집 창의 안내문은 단어 단위로 줄을 바꿉니다.

## 사용법 영상

- 이미지 복사 사용법 영상(한국어·영어)을 새 동작에 맞게 다시 만들었습니다. 복사를 누르면 '저장 중…' 뒤 편집기가 닫히고 메모 앱에 붙여 넣습니다.

## 개인정보와 네트워크

- 번역은 기본으로 꺼져 있고, 번역 보기에서 '번역 켜기 (247 MB)'를 누를 때만 모델을 내려받습니다. 내려받는 곳은 이 저장소의 GitHub 릴리스 `translation-models-1`(사전 릴리스)입니다. 파일 9개, 합계 246,256,561바이트이며, 앱이 파일마다 크기와 SHA-256을 고정해 두고 다른 파일은 받지 않습니다.
- 내려받는 동안 진행 표시와 취소를 지원하고, 60초 정지 감지와 여유 공간 확인을 하며, 받은 파일은 해시를 확인한 뒤 옮깁니다.
- 번역할 글자와 이미지는 보내지 않습니다. 번역은 이 PC 안에서 실행합니다.
- 설정 > 정보 탭의 개인정보 안내와 설치 문서에 번역 모델 내려받기를 반영했습니다.

## 데이터

- 번역을 켜면 모델을 데이터 폴더의 `translation-models`(`%LOCALAPPDATA%\MyCapture\translation-models`, Store 설치본은 패키지의 `LocalCache\translation-models`)에 저장합니다. 설정 > 일반 > 번역에서 삭제합니다.
- 설정 파일에 새 항목을 더하지 않았고, 이전 버전의 설정, 캡처, 라이브러리, 색인, 열린 핀 저장 형식을 바꾸지 않았습니다.

이전 변경은 [4.7.0](4.7.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
