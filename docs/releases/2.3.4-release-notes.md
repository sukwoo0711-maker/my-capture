# MyCapture 2.3.4

인식 품질에 정밀(Careful)을 추가했습니다. 느림과 같은 PP-OCRv5를 쓰되, 그 앞에 로컬 조명 평탄화·대비·선명 보정을 합니다. 빛 번짐이나 흐린 가장자리 때문에 느림으로도 잘 안 읽히던 영수증을 위한 단계이며, 업스케일 모델은 받지 않습니다. 기본값은 빠름 그대로입니다.

2.3.3의 기본 빠름과 2.3.2의 시작 대화상자 수정은 그대로입니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
