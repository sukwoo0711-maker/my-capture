# MyCapture 4.3.1

4.3.1은 편집 중에 캡처 단축키가 아무 반응 없이 실패하던 문제를 고치고, 핀 테두리가 포인트 색을 따르도록 바꾼 업데이트입니다. UX 점검에서 찾은 화면 표시 결함 네 가지도 함께 고쳤습니다.

Microsoft Store 배포용 패키지 버전은 `4.3.1.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 편집 중 캡처

- 저장하지 않은 편집이 있을 때 영역 캡처 단축키를 누르면 저장 확인 창이 다른 앱 뒤에 열려, 아무 반응이 없는 것처럼 보였습니다. 이 문제를 고쳤습니다. 이제 편집기와 확인 창이 맨 앞에 나타나고, 최소화된 편집기는 복원됩니다.
- 확인 창이 열린 동안 단축키를 다시 누르면 확인 창을 앞으로 가져옵니다. 편집기 상태 줄에는 새 캡처를 시작하지 않은 이유를 표시합니다.
- 확인 창에서 '저장하고 닫기'를 고르면 저장이 끝난 뒤 새 캡처가 바로 시작됩니다. 저장에 실패하면 그 이유를 표시합니다.
- 다른 작업 때문에 시작할 수 없는 캡처는 해당 창을 앞으로 가져오거나 이유를 알립니다. 전체 화면·창·이전 영역 반복 캡처, 지연 캡처, 스크롤 캡처, 영역 녹화가 해당됩니다.
- 캡처나 녹화를 시작하지 못했을 때의 오류 알림이 편집·녹화 중에도 표시됩니다.

## 포인트 색 테두리

- 핀 테두리가 평소에도 포인트 색을 따릅니다. 평소에는 옅게, 마우스를 올리거나 핀을 선택했을 때는 또렷하게 표시합니다.
- 설정에서 테마나 포인트 색을 바꾸면 열려 있는 핀에도 바로 반영됩니다.
- 영상 편집기에서 선택한 레이어의 테두리와 모서리 핸들이 포인트 색을 따릅니다.
- 고대비 테마의 핀 테두리는 이전과 같은 시스템 색을 사용합니다.

## 화면 표시

- 영상 편집기의 '레이어' 머리글이 좁은 패널에서 잘리던 문제를 고쳤습니다. 편집·삭제 버튼은 목록 아래로 옮겼습니다.
- 150%·200% 배율에서 캡처 선택 화면 돋보기의 색상값과 좌표가 겹치던 문제를 고쳤습니다.
- 녹화 막대 상태 칸에는 상태만 짧게 표시하고, 재개·중지 안내는 도움말 풍선으로 옮겼습니다. 이제 문구가 잘리지 않습니다.
- 클릭 허용이 켜진 핀이 있으면 트레이 메뉴에 '모든 핀 클릭 허용 해제'가 나타납니다.

## 사용법 영상

- 사용법 영상 76개를 현재 화면과 포인트 색으로 다시 만들었습니다. 핀 영상 12개는 새 테두리를 넣어 다시 만들었습니다.

## 데이터

- 설정, 라이브러리 기록, 색인, 메타데이터 형식은 4.3.0과 같습니다. 4.3.0으로 되돌려도 캡처, 설정, 라이브러리가 그대로 열립니다.

Windows 10 22H2 지원과 PowerShell 없는 설치 파일 같은 이전 변경은 [4.3.0](4.3.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
