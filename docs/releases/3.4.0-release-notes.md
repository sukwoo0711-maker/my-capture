# MyCapture 3.4.0

앱 전체의 색·버튼 위계·도구 배치를 정리하고, 이전 버전에서 남겨 둔 두 가지 빈틈을 채웠습니다.

- **Iris 브랜드 색**: 시안블루 액센트를 일렉트릭 아이리스(`#7C6CFF`)로 바꿨습니다. 6개 테마(Midnight · Daylight · HighContrast · Workspace · Glass · GlassLight) 모두에 같은 규칙으로 적용하며, 액센트 채움 위에는 항상 어두운 잉크를 써서 밝은 테마와 어두운 테마 모두에서 대비를 유지합니다. HighContrast는 시스템 색을 그대로 두고, 레이어 식별색(텍스트=아이리스, 프레임=아쿠아)과 재생헤드도 함께 정리했습니다.
- **동영상 편집기 버튼 재배치**: 재생 줄을 이동·프레임 이동·보기 세 묶음으로 나누고, 채워진 버튼은 재생 하나만 남겼습니다. `프레임 편집`을 재생 아이콘 무리에서 빼내 `내보내기` 옆의 주요 동작으로 올리고, 상단에 실행취소·재실행을 노출했습니다.
- **`구간 적용` 제거**: In/Out을 적고 별도로 적용 버튼을 누르던 단계를 없앴습니다. 타임라인 핸들로 직접 조정하거나 값을 입력하면 즉시 반영되고, 되돌리기로 복원합니다.
- **이미지 편집기 정리**: 도구 레일을 변형·주석·삽입·프라이버시 네 묶음으로 나눴습니다. 상단 종료 동작은 `취소 · 복사 · 완료`로 줄이고 `완료`를 유일한 주 버튼으로 두었습니다(저장은 완료·Ctrl+S·오버플로 메뉴에서 유지).
- **갤러리 주 행동**: 헤더에서 `영역 캡처`를 유일한 채움 버튼으로 올리고, 항목 개수는 행동처럼 보이던 버튼에서 낮춰 정보로 표시했습니다.
- **핀 원본 주소 유지**: 붙여넣기 화면(F3)으로 만든 핀을 복사하거나 빠른 저장·다른 이름으로 저장할 때도 원본 웹페이지 주소를 PNG에 함께 담습니다. 이전 버전에서 주소가 빠지던 경로입니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
