# MyCapture 1.8.2

> 이 문서는 변경 범위를 설명합니다. 실제 배포 커밋·파일·검증 결과는 [GitHub 릴리스](https://github.com/sukwoo0711-maker/my-capture/releases)를 확인하세요.

1.8.2는 영역 캡처 선택 화면을 이미지 획득보다 먼저 띄우고, GitHub 최신 릴리스가 필수 산출물 없이 게시되지 않도록 검사합니다.

- 영역 캡처 단축키는 가상 데스크톱 픽셀을 다 읽기 전에 선택 화면을 띄웁니다. 선택 창이 캡처에서 제외되면 그 위에 고정 이미지를 붙입니다. 제외할 수 없으면 이전처럼 이미지를 먼저 읽고 화면을 엽니다.
- 확정한 영역은 고정 이미지에서 자르며, 선택 화면이 덮고 있는 데스크톱을 다시 찍지 않습니다.
- GitHub 릴리스는 setup.exe, portable ZIP, `installer-manifest.json`, `release-manifest.json`, `SHA256SUMS.txt`, `README-OFFLINE.txt` 여섯 파일이 있어야 통과합니다. `build/publish-github-release.ps1`은 로컬에 여섯 파일이 없으면 게시하지 않습니다.

Windows 지원 범위와 오프라인 설치·포터블 배포는 1.8.1과 같습니다.

## English overview

The region selector can appear before the full virtual-desktop frame is acquired when the overlay is excluded from capture. Confirmed crops still come from that frozen frame. Published GitHub releases must include the six required assets; the publish script refuses to create a latest release without them.
