# MyCapture 5.5.0

5.5.0은 캡처 방식을 선택 화면에서 고르게 하고, 색을 스포이드로 집고, 띄워 둔 핀을 다시 켤 때까지 지키며, 편집기에 지우개를 더합니다. 캡처 결과 카드는 작업 표시줄 위 오른쪽 아래로 옮겼습니다.

5.4.1 이후의 변경을 담았습니다. 5.4.1의 변경은 [5.4.1 릴리스 노트](5.4.1-release-notes.md)에서 확인할 수 있습니다.

## 캡처 선택 화면

- `스크롤 캡처`가 선택 화면의 캡처 방식이 되었습니다. 고르면 포인터 아래 창의 스크롤 영역이 강조되고 포인터가 세로 스크롤 모양으로 바뀌며, 누른 창을 스크롤 캡처합니다. 키는 `S`입니다. 전에는 단추를 누르면 선택 화면이 닫히고 포인터 아래 창을 다시 찾느라 아무것도 캡처하지 못했습니다.
- `지연 캡처`가 걸어 두는 상태가 되었습니다. `지연 없음`·`3초`·`5초`·`10초` 가운데 고르면 단추에 초가 표시되고, 영역이나 창을 확정한 뒤 카운트다운이 끝나면 그 시점의 화면에서 같은 영역을 캡처합니다. 키는 `D`입니다.
- 전역 단축키와 트레이 메뉴의 `지연 캡처`, `스크롤 캡처`도 그 방식이 골라진 선택 화면을 엽니다. 전에는 카운트다운이 먼저 끝난 뒤 선택 화면이 열렸습니다.
- `색상 복사`가 스포이드 방식이 되었습니다. 고르면 포인터가 스포이드로 바뀌고 돋보기가 늘 보이며, 클릭하거나 `Enter`를 눌러야 색이 복사됩니다. 화살표 키로 한 픽셀씩(`Ctrl`과 함께 열 픽셀씩) 옮길 수 있습니다. 전에는 `C`를 누른 자리의 색이 바로 복사되고 화면이 닫혔습니다.
- 돋보기와 복사 알림에 색 이름을 함께 보여 줍니다. CSS 표준 색 이름 148개에서 가장 가까운 이름을 찾고, 값이 정확히 같지 않으면 앞에 `≈`를 붙입니다. 한국어 화면에서는 `마젠타 (Magenta)`처럼 한글 표기와 영문 이름을 함께 보입니다.
- 영역을 끌기 시작할 때의 멈칫함을 줄였습니다.

## 캡처 결과 카드

- 캡처한 뒤 나오는 카드가 캡처한 영역 옆이 아니라 작업 표시줄 위 오른쪽 아래, 앱 알림과 같은 자리에 뜹니다. 방금 캡처한 자리를 가리지 않습니다.
- 알림은 카드 위에 쌓이고, 작업 영역이 낮으면 카드 왼쪽에 놓입니다. 작업 표시줄을 옮기거나 화면 구성이 바뀌면 열린 카드가 모서리로 돌아갑니다.
- 캡처한 그림이 카드로 날아가는 움직임은 카드 가까이에서만 나타납니다.

## 핀

- 띄워 둔 핀이 프로그램을 다시 켤 때 마지막 상태 그대로 돌아옵니다. 자리와 크기, 확대 배율, 투명도, 접힘, 클릭 통과, 앞뒤 순서를 지킵니다. 직접 닫은 핀은 돌아오지 않습니다. 전에는 이 기능이 새로 설치한 경우에만 켜져 있어, 이전 판부터 쓰던 설정에서는 꺼져 있었습니다. 설정 `핀` → `열린 핀 다시 열기`로 끌 수 있습니다.
- 핀에 마우스를 올리면 나오는 막대의 단추 순서와 크기, 아이콘 위치를 모든 핀 종류에서 같게 맞췄습니다. 순서는 `복사`·`텍스트 복사`·`저장` 다음에 `번역`과 `출처`, 마지막이 `닫기`입니다.
- 막대에 `텍스트 복사`를 더했습니다. 글자·Markdown·코드·표 핀은 원문을, 그림 핀은 인식한 글자를 복사합니다.
- 막대에서 `투명도`를 뺐습니다. 투명도는 `O` 키와 `Ctrl`+휠, 오른쪽 클릭 메뉴에서 그대로 바꿀 수 있습니다.
- 번역이 실패하면 어느 단계에서 멈췄는지 알려 줍니다. 글자 읽기, 모델 확인, 모델 설치, 모델 열기, 번역, 표시를 구분해 문구를 보이고 진단 로그에 남깁니다.
- 번역 모델이 설치되어 있는데 열리지 않으면 `번역 재시도`로 모델을 다시 설치합니다. 전에는 같은 실패가 되풀이됐습니다.
- 번역문이 모두 수치·기호 확인에서 걸려 원문이 그대로 남은 경우를 실패와 구분해 알려 줍니다.

## 편집기

- `지우개`를 더했습니다. 누르면 닿은 주석 하나를, 누른 채 끌면 지나간 주석을 모두 지웁니다. 끌기 한 번은 실행 취소 한 번으로 되돌아옵니다. 원본 캡처는 지우지 않습니다. 키는 `Shift+E`입니다.
- 도구 포인터를 Windows 기본 포인터에 맞는 크기로 줄였습니다.
- 펜·형광펜·도형·글상자·단계 번호의 포인터가 지금 고른 색으로 그려지고, 색을 바꾸면 바로 바뀝니다.
- 펜·형광펜·단계 번호 도구에서 포인터를 움직일 때 그림 전체를 다시 그리지 않습니다.
- `이미지 넣기`가 라이브러리의 캡처를 고르는 창을 엽니다. 여러 장을 한 번에 넣을 수 있고, `파일에서 찾아보기…`로 전처럼 파일을 고를 수도 있습니다.

## 라이브러리와 내보내기

- 오른쪽 `선택한 항목` 판이 접기 단추로 접지 않는 한 늘 보입니다. 선택이 없으면 `선택된 항목이 없습니다.`를 보이고, 고른 항목에 따라 격자의 열 수가 바뀌지 않습니다. 접은 상태는 다음 실행에도 유지됩니다.
- 라이브러리가 차지하는 용량 때문에 캡처를 지우지 않습니다. 설정의 `최대 크기` 칸을 없앴고, 자동 정리는 이미지 보관 기간과 최대 항목 수로만 합니다. 쓰고 있던 보관 기간과 항목 수는 그대로입니다.
- `PDF로 만들기`에서 순서 목록의 이미지를 고르면 그 이미지가 들어가는 쪽을 미리 보기에 보여 주고, 그 자리를 표시합니다.
- 순서를 끌어서 바꿀 때 행이 들리고 다른 행이 비켜나며, `Esc`로 처음 순서로 되돌릴 수 있습니다.
- GIF를 공유 목표 크기로 내보내면 결과 파일이 그 크기보다 반드시 작습니다. 내보낸 뒤 실제 크기를 확인하고, 넘으면 해상도를 줄여 다시 만듭니다. 크기 표기도 올림이 아니라 내림으로 바뀌어, 10MB 목표의 결과가 `10.0MB`로 보이지 않습니다.
- 라이브러리 창의 최소 너비가 1032로 커졌습니다. 가장 좁은 크기에서도 도구 줄의 글자가 잘리지 않습니다.

## 그 밖의 수정

- 설정 파일이 손상되어 읽을 수 없을 때 캡처 자동 삭제가 켜지던 문제를 고쳤습니다. 라이브러리 보관 한도는 새로 설치했을 때와 같은 값으로 시작합니다.
- 라이브러리 가져오기, PDF 저장, 폴더 작업, 저장한 검색이 실패하면 저장 공간, 사용 중, 권한 같은 원인을 문구에 함께 보이고 진단 로그에 남깁니다.
- 녹화 편집기와 내보내기에서 프로그램 오류 문장이 그대로 보이던 것을 고쳤습니다.
- 영어 화면에서도 한국어로 보이던 Markdown·Mermaid 핀 안내와 시작 중 창의 문구를 고쳤습니다.
- 소수 배율 화면에서 화살표 키로 핀을 옮길 때마다 핀이 한 픽셀씩 커지던 문제를 고쳤습니다.
- 확대한 문서 핀의 번역 전환 첫 장면이 원문과 어긋나던 문제를 고쳤습니다.
- 길이를 읽지 못한 동영상을 손상으로 보고 기록하지 않던 문제를 고쳤습니다.
- 사용법 영상을 바뀐 선택 화면, 결과 카드, 핀 막대, 편집기, 라이브러리에 맞춰 다시 만들었습니다.
