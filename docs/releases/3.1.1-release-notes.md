# MyCapture 3.1.1

캡처 이미지에 문서·창 제목을 표시하는 옵션과 테마 미리보기를 추가했습니다.

- **이미지 우측 상단에 창 제목 표시**: 설정에서 제목 표시를 켜고 끌 수 있습니다. 켜면 캡처한 앱이 제공하는 창 제목을 이미지 우측 상단에 표시합니다. 편집 미리보기와 복사·저장 결과에 같은 표시를 사용하며, 긴 제목은 이미지 안에 맞춰 줄입니다. 기본값은 끔이며 파일명 패턴과 별도로 설정합니다.
- **테마 선택 즉시 미리보기**: 설정에서 테마를 선택하면 적용 버튼을 누르기 전에 앱의 색상이 바뀝니다. 적용하면 선택을 저장하고, 취소·Esc·창 닫기는 저장된 테마로 되돌립니다. 기본값 복원과 설정 가져오기도 미리보기에 반영합니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
