# MyCapture 2.4.1

GitHub 업로드의 보안과 GitHub Enterprise 호환성을 강화했습니다.

**토큰 암호화 저장** — F9 토큰 업로드에 쓰는 GitHub 개인 액세스 토큰을 이제 Windows DPAPI(현재 사용자 범위)로 암호화해 settings.json에 저장합니다. 파일을 열어도 토큰을 읽을 수 없고, 같은 PC의 다른 사용자 계정에서도 복호화되지 않습니다. 2.4.0에서 평문으로 저장된 토큰은 첫 실행 시 자동으로 암호화해 다시 저장합니다.

**설정 내보내기에서 토큰 제외** — 설정 내보내기 파일에는 더 이상 토큰이 포함되지 않습니다. 내보낸 파일을 공유해도 토큰이 나가지 않으며, 가져오기는 이 PC의 기존 토큰을 그대로 유지합니다.

**GitHub Enterprise 이슈 URL 지원** — 토큰 업로드가 github.com 주소에 고정되지 않고 설정된 이슈 URL의 호스트를 따라갑니다. github.com은 api.github.com을, 사내 GitHub Enterprise Server는 자체 /api/v3를 사용합니다. 엔터프라이즈 서버는 이미지 첨부 API를 아직 제공하지 않기 때문에(GitHub CLI도 동일하게 제한) 토큰 모드가 실패하면 기존 브라우저 방식으로 자동 전환되며, 브라우저 방식은 엔터프라이즈 서버에서 그대로 동작합니다.

**토큰 업로드 버그 수정** — 업로드 정책이 발급한 서명 URL로 이미지를 보내는 단계에서 빈 Authorization 헤더를 넣어 항상 실패하던 문제를 고쳤습니다. 이제 토큰 모드가 실제로 동작합니다.

**OCR 사전 파일 무결성** — 한국어 인식 사전 파일에도 다른 모델 파일과 같은 SHA256 핀 검사를 적용해, 손상되거나 변조된 파일이 자동으로 다시 내려받아지도록 했습니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
