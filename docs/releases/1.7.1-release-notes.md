# MyCapture 1.7.1

MyCapture 1.7.1은 플로팅 드래그, 연속 캡처, 자동 OCR 색인, 녹화 프레임 경로의 성능과 안정성을 다룬 유지보수 릴리스입니다. 1.7.0 사용성 기능은 그대로 유지합니다.

## 성능과 안정성

- 플로팅 창을 드래그하는 동안 모니터 목록을 매번 다시 읽지 않습니다. 커서가 같은 픽셀에 머무르면 창을 다시 놓지 않고, 이동은 크기·Z순서·활성화를 건드리지 않습니다.
- 편집기나 영역 선택이 이미 열려 있으면 전체 화면·창·이전 영역 반복 캡처가 화면을 다시 찍지 않습니다.
- 새 캡처의 `rendered.png`는 같은 픽셀을 두 번 PNG로 인코딩하지 않고 `original.png`를 복사합니다.
- 자동 OCR 색인은 회전 후보를 돌리지 않습니다. 사용자가 직접 요청한 인식은 기존처럼 약한 직립 결과에서 90/180/270°를 추가로 검사합니다.
- 녹화 중 스크린샷 단축키는 안내 후 무시합니다. 캡처가 끝나도 녹화가 계속되면 트레이 아이콘을 대기 상태로 되돌리지 않습니다.
- 녹화 프레임은 `WriteableBitmap`을 매 프레임 만들지 않고 재사용 버퍼에 직접 담습니다. 인코더의 세로 뒤집기도 행 단위 P/Invoke 대신 메모리 복사로 처리합니다.
- 스크롤 캡처와 영상 편집기 작업의 취소 토큰이 종료와 완료 시점에 두 번 해제되지 않도록 정리했습니다.

## 설치 및 호환성

- Windows 11 21H2(build 22000) 이상, x64를 지원합니다. ARM64에서는 x64 에뮬레이션으로 실행합니다.
- 오프라인 self-contained 설치 파일과 portable ZIP으로 배포합니다. 별도의 .NET 설치는 필요하지 않습니다.
- 기존 설정, 주석 파일과 라이브러리 경로를 유지합니다.
- 캡처와 OCR은 로컬에서 처리합니다.
- MIT 라이선스이며 Authenticode 미서명 배포 계약을 유지합니다.
