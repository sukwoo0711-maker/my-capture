# MyCapture 1.6.0 검증 기록

검증 기준일: 2026-09-04 (Asia/Seoul)

대상: Windows 11 21H2(build 22000) 이상, x64

배포 계약: self-contained, offline, unsigned, MIT

## 릴리스 경계

- 영역 캡처는 원본을 클립보드에 복사하고 편집기를 열며, 자동 플로팅 창을 함께 만들지 않습니다.
- 편집기의 기본 도구는 도형(사각형)입니다.
- `F3`은 이미지, 일반 텍스트, Excel 탭 구분 표를 화면에 고정합니다.
- 텍스트·표 핀의 `Ctrl+더블클릭`은 렌더링 이미지가 아닌 보존된 전체 원문을 복사합니다.
- 이미지 핀의 기존 OCR, 저장, 확대·축소, 투명도 및 클릭 통과 동작은 유지합니다.

## 패키지 무결성 및 출처

`build/package.ps1 -Version 1.6.0`은 다음을 검증합니다.

- `win-x64` CoreCLR/WPF를 포함한 완전한 self-contained publish
- 설치 payload와 portable ZIP의 경로·크기·SHA-256 inventory
- ZIP traversal, 중복 경로, reparse point 및 symlink 방어
- 설치·업데이트 실패 시 rollback과 사용자 데이터 보존
- 패키지 시작과 종료 때 동일한 정확한 Git 커밋인지 재검증
- `release-manifest.json`의 source commit과 clean-tree 상태
- 게시 파일의 `SHA256SUMS.txt`

## 알려진 제한

- Authenticode 서명이 없어 Windows가 알 수 없는 게시자 경고를 표시할 수 있습니다.
- Windows 10은 지원하지 않습니다.
- Excel 표의 원문은 셀 값의 Unicode TSV이며 수식, 스타일, 병합 및 크기 정보는 보존하지 않습니다.
- 이번 변경의 Excel 상호 운용성은 클립보드 형식 및 제스처 자동화로 검증했으며 실제 Excel GUI를 조작하는 수동 QA는 포함하지 않았습니다.
