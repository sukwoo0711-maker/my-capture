# MyCapture 2.3.0

Windows 11 네이티브 글래스 테마와 선택 가능한 팔레트, 로그인 시 자동 시작 기본값, OCR 품질 단계를 추가했습니다.

- 글래스(기본)와 글래스 라이트는 Windows 11 Mica와 반투명 패널을 사용합니다. 작업실, 데이라이트, 미드나잇, 고대비도 설정 > 일반에서 고를 수 있습니다. 캡션 색과 둥근 모서리는 선택한 테마를 따릅니다.
- 앱·트레이 아이콘은 같은 두 칸 마크를 Windows 11 글래스 플레이트 위에 다시 그렸습니다.
- 설정 > 일반 > 로그인 시 자동 시작은 새 설치에서 켜져 있습니다. 이미 저장된 설정 파일의 값은 그대로 둡니다.
- OCR 품질은 빠름(1×, 회전 탐색 없음), 보통(2×, 균형), 느림(4×, 회전 탐색과 명암 보정, 영수증·작은 글자) 세 단계입니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
