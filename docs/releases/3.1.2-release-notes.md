# MyCapture 3.1.2

캡처 저장 재시도·복구와 설정 가져오기 흐름을 보완했습니다.

- **복구 후에도 캡처 제목 유지**: 초기 저장이 중단되어 앱을 다시 실행해 복구할 때 이미지와 썸네일의 제목 표시를 보존합니다. 파생 이미지가 없거나 손상된 경우에도 캡처 당시 제목 표시 설정으로 다시 생성하고, 원본 이미지는 유지합니다.
- **저장 재시도 시 파일명 유지**: 최초 라이브러리 저장이 실패한 뒤 다른 이름으로 저장하거나 축소 내보내기를 해도 제안 파일명에 원래 문서·창 제목과 캡처 시각을 사용합니다.
- **가져온 설정 보호**: 가져온 설정을 적용하기 전에는 미저장 변경으로 취급하여 업데이트 재시작으로 초안이 사라지지 않도록 했습니다. 적용하면 저장하고 취소하면 기존 설정과 테마로 돌아갑니다.
- **설정 가져오기·내보내기 안내 개선**: 성공·실패 안내를 모든 설정 탭에서 볼 수 있게 했으며, 가져오기 후 적용을 눌러야 저장된다는 안내를 표시합니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
