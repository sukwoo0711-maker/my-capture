# MyCapture 4.6.0

4.6.0은 편집기와 라이브러리의 화면을 정리하고, 핀이 화면에 꽂히는 순간을 다시 만든 업데이트입니다. 자주 쓰는 프로그래밍용 무료 글꼴도 함께 넣었습니다.

Microsoft Store 배포용 패키지 버전은 `4.6.0.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 핀

- 새 핀이 열릴 때 압정이 꽂히듯 내려앉습니다. 압정이 닿는 순간 아주 잠깐 멈췄다가 고리가 퍼지고, 그림자가 내려앉고, 테두리가 한 번 빛납니다. 효과는 약 0.6초 뒤에 끝납니다.
- 핀 내용은 83ms 안에 제자리에서 선명하게 나타나고 움직이지 않으므로, 코드와 표 글자가 흐려지지 않습니다.
- 효과는 마우스가 통과하고 캡처에 찍히지 않는 별도 장식으로 그립니다. 핀을 바로 끌거나 복사할 수 있습니다.
- 시작할 때 복원하는 핀, Shift+F3으로 다시 보이는 핀, 1초 안에 연달아 연 네 번째 핀부터는 효과를 생략합니다. 원격 데스크톱과 Windows 애니메이션 효과를 끈 환경에서는 테두리 색만 잠깐 바뀝니다.

## 편집기와 명령 버튼

- 버튼 아래 단축키 줄을 평소에는 숨기고, Alt를 누르는 동안만 보여 줍니다. 이름이 위로 비키고 아래에 단축키가 나타나며, 버튼 위치는 바뀌지 않습니다. 툴팁에는 단축키가 그대로 있습니다.
- 늘 보고 싶으면 설정 → 편집의 '단축키 항상 표시'를 켜십시오. 이전 버전에서 단축키 줄을 보던 설치도 4.6.0에서는 이 설정이 꺼진 상태로 시작합니다.
- 창이 좁아지면 버튼이 두 줄로 넘어가지 않고 덜 중요한 이름부터 아이콘으로 접습니다. 완료 버튼의 이름은 끝까지 남습니다.
- '복사'(Ctrl+C)는 편집한 이미지를 클립보드에 복사하고 편집기를 열어 둡니다. 저장하고 닫으려면 '완료'(Ctrl+Enter)를 누르십시오. 지금까지는 두 버튼이 같은 동작이었습니다.

## 라이브러리

- 캡처 시각을 썸네일 위 배지 대신 제목 아래에 표시합니다. 동영상 길이와 헷갈리지 않습니다.
- 카드의 빈 공간을 줄여 한 화면에 더 많이 보입니다.
- 빈 곳이나 날짜 머리글을 오른쪽 클릭하면 새 폴더, 정렬 기준, 모두 선택, 가져오기 메뉴가 나옵니다.
- 캡처 이름을 바꿀 수 있습니다. 캡처 메뉴의 '이름 바꾸기'나 F2를 누르고, Enter로 저장하거나 Esc로 취소합니다. 이름을 비우면 자동 이름으로 돌아갑니다.
- '새 폴더' 버튼은 ⋯ 메뉴와 폴더 구역의 [+]로 옮겼습니다. Ctrl+Shift+N은 그대로입니다.
- '검색 저장'은 검색어가 있을 때만 작은 [+]로 보입니다.

## 글꼴

- 설정과 편집기 텍스트 도구의 글꼴 목록을 추천 글꼴로 줄였습니다. 순서는 맑은 고딕, Pretendard, D2Coding, Maple Mono, JetBrains Mono, Cascadia Mono, Consolas, Segoe UI입니다. Fira Code, Cascadia Code, Source Code Pro, 나눔고딕코딩, Noto Sans KR은 설치된 경우에만 보입니다.
- 목록 끝의 '설치된 다른 글꼴…'에서 전체 글꼴을 고를 수 있습니다.
- Maple Mono, JetBrains Mono, D2Coding, Pretendard를 앱에 함께 넣었습니다(SIL OFL 1.1). 따로 설치하지 않아도 편집과 내보내기에서 같은 글꼴로 보입니다. Maple Mono와 JetBrains Mono의 한글은 D2Coding으로 보입니다. 이 때문에 설치 파일과 zip이 약 6.6MB 커졌습니다.
- 설정 검색 상자에 '설정 찾기' 안내를 넣었습니다.

## 사용법 영상

- 앱 안 사용법 영상을 새 편집기·라이브러리 화면과 핀 꽂힘 효과로 다시 만들었습니다.

## 데이터

- 설정 파일에 `AlwaysShowShortcutHints`를 더했습니다. 이전 버전의 설정, 캡처, 라이브러리, 색인, 열린 핀 저장 형식은 그대로 읽습니다.

이전 변경은 [4.5.2](4.5.2-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
