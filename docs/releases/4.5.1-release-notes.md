# MyCapture 4.5.1

4.5.1은 이미지 편집 중 프로그램이 '응답 없음'으로 멈추던 문제를 고치고, 핀에서 필요한 부분만 골라 복사할 수 있게 한 업데이트입니다. 캡처를 마친 뒤 창이 사라지는 속도와 앱 시작 속도도 빨라졌습니다.

Microsoft Store 배포용 패키지 버전은 `4.5.1.0`입니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## 이미지 편집기

- 편집을 시작하고 잠시 뒤 프로그램이 '응답 없음'으로 멈추던 문제를 고쳤습니다. 첫 자동 저장과 화면 그리기가 서로를 기다리던 교착이 원인이었으며, 4.1.2부터 있던 문제입니다.
- 주석이 많은 이미지에서 펜으로 그리기, 끌기, 실행 취소가 두세 배 빨라졌습니다. 큰 이미지의 저장과 모자이크도 덜 멈춥니다.
- 그림을 넣는 중에 저장하거나 닫으면 그림이 들어간 뒤 저장하거나 닫습니다.

## 속도

- 캡처를 마치면 클립보드에 복사되는 즉시 편집기가 사라집니다. 저장은 뒤에서 이어집니다.
- 편집기를 처음 열 때와 캡처가 많은 라이브러리에서 앱을 시작할 때가 빨라졌습니다.
- 라이브러리는 저장·글자 인식 뒤 바뀐 줄만 다시 그립니다.

## 핀

- 텍스트·코드·표 핀에서 F2(또는 오른쪽 클릭 메뉴의 '글자 선택')를 누르면 글자나 셀을 골라 그 부분만 복사합니다. 표는 셀이나 사각 범위를 고르고, 엑셀에 붙여 넣을 수 있는 형식으로 복사합니다. Esc를 누르면 선택을 끝냅니다.
- 텍스트·표·코드 핀을 모니터 배율에 맞춰 그려 고배율 화면에서도 선명합니다. 배율이 다른 모니터로 옮기면 다시 그립니다.
- 트레이 메뉴의 '열린 핀'에서 열려 있는 핀을 골라 앞으로 가져옵니다.
- '다음 실행 때 열린 핀 다시 띄우기'로 저장하는 핀은 이 PC의 현재 Windows 사용자만 읽을 수 있도록 암호화합니다. 4.5.0에서 저장한 핀은 다음 저장 때 암호화된 형식으로 바뀝니다.

## 글자 인식과 라이브러리

- 코드 글자 인식이 `#include`, `#define`, `#ifdef` 같은 C/C++ 전처리 줄을 C/C++로 알아봅니다.
- 라이브러리에서 P를 누르면 고른 캡처를 핀으로 띄우고, 보관 전환은 K로 옮겼습니다.

## 처음 실행

- 환영 화면에 F3으로 복사하거나 캡처한 내용을 핀으로 띄우는 방법을 한 줄로 알려 드립니다.

## 데이터

- 열린 핀 저장 파일이 암호화된 형식으로 바뀌어, 4.5.0으로 되돌리면 저장해 둔 열린 핀은 다시 뜨지 않습니다. 캡처, 라이브러리, 색인, 설정 형식은 4.5.0과 같습니다.

코딩 옆 핀(F3, 원문 복사, 포커스 유지) 같은 이전 변경은 [4.5.0](4.5.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
