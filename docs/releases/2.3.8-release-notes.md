# MyCapture 2.3.8

라이브러리 왼쪽 필터의 라디오박스(모두 보기 · 이미지 · 동영상 · 보관한 항목)를 테마 토큰으로 그리도록 바꿨습니다. 이전에는 WPF 기본 모양을 써서 어두운 테마에서 테마에 어울리지 않았습니다. 이제 체크박스와 같은 규칙을 따릅니다. 미선택은 표면 채움과 테두리 강색, 선택은 액센트 채움과 액센트 위 잉크 점, 마우스올림·키보드 포커스는 포커스 링입니다. 여섯 테마 모두 자동으로 적용됩니다.

2.3.7의 README 기능 소개와 사용법 가이드(docs/guides/README.md)도 함께 포함됩니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
