# MyCapture 3.1.5

캡처 준비 화면의 보조선 갱신과 항목이 많은 라이브러리의 검색·선택 처리를 최적화했습니다.

- **보조선 렌더링**: 드래그 전 커서를 따라 움직이는 가로·세로 보조선을 재사용하고 필요한 위치만 갱신하도록 개선했습니다. 주황색 선의 모양과 표시 설정은 유지합니다.
- **반복 갱신 감소**: 커서와 표시 상태가 같을 때 포인터·확대경을 불필요하게 다시 그리는 작업을 줄였습니다.
- **라이브러리 검색**: 검색이나 필터로 숨겨진 항목의 캐시를 확인할 때 전체 목록을 반복 탐색하던 작업을 줄였습니다. 필터를 해제하면 기존 썸네일 캐시를 계속 사용합니다.
- **전체·그룹 선택**: 항목이 많은 라이브러리에서 선택 대상 확인을 빠르게 처리합니다. 표시 순서와 Ctrl·Shift 선택 동작은 유지합니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
