# MyCapture 1.7.0

MyCapture 1.7.0은 캡처 편집, 녹화 상태, F3 플로팅과 라이브러리 관리의 사용성 개선 릴리스입니다. 아래 내용은 릴리스 후보의 변경 범위이며, 실제 검증과 배포 상태는 [검증 기록](1.7.0-validation.md)을 따릅니다.

## 캡처와 녹화 편집

- 사각형 외곽선 종류와 내부 채우기 투명도를 조절합니다. 기본 투명도는 100%로 외곽선만 표시하며, 50%로 바꾸면 선과 같은 색을 반투명하게 채웁니다.
- 녹화 중인 영역을 외곽선으로 표시합니다. 안내 UI를 녹화 영상에서 제외하는 기존 캡처 제외 정책을 사용합니다.
- 녹화 종료 후 파일 변환과 라이브러리 등록이 끝날 때까지 처리 상태와 진행 표시를 유지합니다.
- GIF 품질을 표준(긴 변 960px, 10fps), 작게(640px, 10fps), 최소 용량(480px, 5fps) 중에서 선택합니다. 원본이 작은 경우 확대하지 않습니다. 실제 크기는 영상 내용과 길이에 따라 달라집니다.
- 동영상의 하단 텍스트 타임라인에서 막대 양 끝을 드래그해 표시 시작과 끝을 조절합니다. 키보드로도 레이어를 선택하고 시작·끝 시간을 조절할 수 있습니다.

## F3 플로팅

- 지원하는 VS Code HTML을 코드로 판별하여 들여쓰기, 고정폭 글꼴과 지원하는 글자·배경 색상을 유지합니다. 들여쓰기를 위한 탭 때문에 코드가 Excel 표로 표시되는 문제를 줄였습니다.
- 실제 HTML 표와 일관된 TSV 셀 범위는 표로 표시합니다. 원문 Unicode 텍스트는 미리보기와 별도로 보존합니다.
- 다중 모니터 이동은 물리 화면 좌표를 기준으로 처리하여 음수 좌표 및 서로 다른 배율의 모니터 경계를 지원합니다.
- 플로팅 창을 선택한 뒤 `Ctrl+C`는 이미지를 복사합니다. `Ctrl+더블클릭`은 보존된 원문을 복사하고, 원문이 없는 이미지에서는 로컬 OCR로 인식한 텍스트를 복사합니다. 별도의 OCR 결과 편집 창은 열지 않습니다.

상용 제품 검토와 구현 선택은 [클립보드 비교 조사](../market/clipboard-code-benchmark.md)에 기록했습니다. HTML 전체나 임의 CSS를 완전히 재현하는 기능은 아닙니다. 지원하지 않거나 안전하게 해석할 수 없는 형식은 일반 텍스트로 표시합니다.

## 라이브러리와 화면 구성

- graphite/cyan 색상에 맞는 스크롤바와 네이티브 어두운 제목 표시줄로 라이브러리와 설정 화면의 색상을 통일합니다.
- 버튼, 글자 크기, 정렬, 줄바꿈과 키보드 조작의 화면 검토를 릴리스 검증 범위에 포함합니다. 검토 결과는 [UI 검토 기록](../design/1.7.0-ui-review.md)에 별도로 남깁니다.
- 라이브러리의 관리 이미지는 전용 캡처 폴더에 저장합니다. 생성 후 7일이 지난 이미지는 오래된 순서대로 정리하며, 핀 고정하거나 편집 중인 이미지는 보관합니다. 동영상에는 7일 만료를 적용하지 않습니다. 별도로 내보내거나 저장한 파일은 정리하지 않습니다.
- 새 캡처와 편집 결과를 자동으로 로컬 OCR 색인에 등록합니다. 시작 시 미색인 이미지도 처리합니다. 수동 색인과 자동 색인은 중복 실행되지 않도록 순차 처리합니다.
- 라이브러리의 편집 버튼 다음 동작을 복사, 휴지통, 더보기 순으로 배치하고 핀 고정은 더보기에서 제공합니다.

## 설치 및 호환성

- Windows 11 21H2(build 22000) 이상, x64를 지원합니다. ARM64에서는 x64 에뮬레이션으로 실행합니다.
- 오프라인 self-contained 설치 파일과 portable ZIP으로 배포합니다. 별도의 .NET 설치는 필요하지 않습니다.
- 기존 설정, 주석 파일과 라이브러리 경로를 유지합니다. 새 라이브러리를 만드는 위치는 기존 전용 경로와 같습니다.
- 캡처와 OCR은 로컬에서 처리합니다. OCR에는 Windows 언어 팩이 필요하며, 사용할 수 없으면 다른 캡처 기능은 계속 사용할 수 있습니다.
- MIT 라이선스이며 Authenticode 미서명 배포 계약을 유지합니다.
