# MyCapture 4.1.1

4.1.1은 캡처 영역 선택, 이미지 자르기, 라이브러리 선택에 필요한 처리 비용을 줄인 업데이트입니다.

Microsoft Store로 배포하며, Store 패키지 버전은 `4.1.1.0`입니다.

## 변경 사항

- 캡처 영역을 선택할 때 화면을 중복해서 그리는 작업을 줄였습니다.
- 큰 이미지에서 일부 영역을 자르거나 다시 실행할 때 메모리 사용량을 줄였습니다.
- 라이브러리에서 전체 선택할 때 목록을 다시 구성하는 작업을 줄였습니다.
- 라이브러리의 선택 상태를 확인할 때 임시 목록을 만드는 작업을 줄였습니다.
