# MyCapture 4.1.0

4.1.0은 캡처를 정리하는 폴더, 이미지 가장자리에서 시작하는 자르기, 테마에 맞는 캡처 가이드, 표·코드·텍스트 추출을 제공합니다.

Microsoft Store로 배포하며, Store 패키지 버전은 `4.1.0.0`입니다.

## 라이브러리 폴더

- 날짜 아래에 폴더와 하위 폴더를 만들고, 캡처를 드래그하거나 선택하여 이동할 수 있습니다.
- 선택한 폴더를 새 캡처의 저장 위치로 지정할 수 있습니다. 폴더에 넣은 캡처는 보관 기간에 따른 자동 정리에서 제외됩니다.
- 폴더에서 꺼낸 캡처는 꺼낸 시점부터 보관 기간을 다시 계산합니다. 폴더 항목은 일반 캡처의 개수·용량 한도에서 제외되며 보관 용량을 별도로 표시합니다.
- 폴더와 날짜 묶음을 탐색기로 드래그하거나 폴더·ZIP으로 내보낼 수 있습니다. 이미지의 현재 편집 결과와 동영상이 폴더 구조대로 복사됩니다.
- 폴더나 날짜 묶음을 삭제하면 하위 폴더와 캡처도 함께 삭제됩니다. 확인 창에서 삭제할 항목 수를 확인하거나 취소할 수 있습니다.

## 자르기와 캡처 가이드

- 주석 편집기의 선택 도구에서 주석이나 크기 조절 핸들이 없는 이미지 가장자리·모서리를 끌어 자르기를 시작할 수 있습니다. 그리기 도구는 가장자리에서도 그대로 동작합니다. 상단의 자르기 버튼과 여백 자동 제거도 사용할 수 있습니다.
- 기존 비율·숫자 입력, Enter 적용, Esc 취소를 유지합니다.
- 캡처 테두리·안내선·크기 표시·확대경이 테마 색을 따릅니다. 설정에서 캡처 가이드 색을 직접 지정할 수 있습니다.

## 텍스트 고급 추출

- 표·코드·텍스트 탭에서 인식 결과를 목적에 맞게 정리합니다.
- 표를 CSV·Markdown·탭 구분 형식으로 복사하거나 기본 스프레드시트 앱으로 열 수 있습니다.
- 코드 들여쓰기와 언어 표시, 텍스트 줄 합치기, 원본의 영역 선택을 지원합니다.
- 한국어와 영어 인식은 기기의 Windows OCR로 처리합니다.

## 화면 다듬기

- 첫 실행 안내와 단축키 모음에 키캡을 표시하고 검색을 정리했습니다. 두 안내 창은 크기가 고정된 창으로 열립니다.
- 빠른 작업 카드는 제목 표시줄 없이 표시되며 닫기 버튼을 제공합니다. 버튼·썸네일 클릭과 카드 바탕 드래그 시 다른 앱의 포커스를 유지합니다.
- 창 제목에서 버전 표기를 제거하고 오류 대화상자의 중복 제목을 정리했습니다.

## 알려진 제약과 확인 범위

- 탐색기로 폴더를 직접 드래그하여 복사하는 동작은 실제 탐색기에서 확인하지 못했습니다. 폴더 내보내기와 ZIP 생성·해제는 확인했습니다.
- Windows OCR은 한국어 표 머리글을 일부 잘못 인식할 수 있습니다. 내보내기 전에 인식 결과를 확인하십시오.
- `.xlsx` 파일 생성은 확인했습니다. 검증 PC에 연결된 스프레드시트 앱이 없어 기본 앱으로 여는 동작은 확인하지 못했습니다.
