# MyCapture 4.12.0

4.12.0은 쓰다가 막히던 곳을 손본 편의성 업데이트입니다. 함께 확인하기 위한 테스트판이며, 기존 사용자에게는 업데이트 알림이 가지 않습니다.

- 편집기가 캡처를 실제 크기(100 %)로 보여 줍니다. 창에 맞춰 늘이거나 줄이지 않아 글자와 1 px 선이 흐려지지 않고, 자른 뒤에도 배율이 그대로입니다. 자르기 손잡이가 캔버스 가장자리에서 잘리지 않습니다.
- 편집기에서 펜·형광펜·단계 번호는 그리기 전부터 실제 두께와 시작점을 보여 줍니다. 손잡이와 선 끝 위에서는 방향에 맞는 크기 커서가 나옵니다.
- 모자이크와 흐림을 `가리기` 도구 하나로 합쳤습니다. M은 모자이크, B는 흐림입니다. `도장`은 `워터마크`로 이름을 바꿨습니다.
- 단계 번호는 네 모서리를 끌어 크기를 바꾸고, 속성 막대에서 다음 번호와 크기를 고칩니다.
- Esc를 누르면 한 번에 한 겹씩 닫히고, 맨 바깥에서는 편집기가 닫힙니다. 저장하지 않은 변경이 있으면 먼저 묻습니다.
- 여러 글상자의 크기·굵기·배경·글꼴을 한 번에 바꿉니다. 글자를 입력하는 중에 Ctrl+S를 누르면 입력을 마치고 저장합니다.
- 동영상 플레이어와 영상 편집기에서 지금 장면을 이미지로 저장합니다(Shift+S). 원본 해상도 그대로 라이브러리에 들어갑니다.
- 화면을 녹화할 때 글자나 이미지 워터마크를 넣을 수 있습니다. 기본값은 꺼짐입니다.
- 라이브러리에서 고른 이미지로 PDF를 만듭니다. 카드의 출처 아이콘을 누르면 원본 페이지·파일·앱이 바로 열리고, 오른쪽 클릭 메뉴는 탐색기와 같은 순서(속성은 맨 끝)입니다. 카드의 `편집됨` 표시는 뺐습니다.
- 문자 인식 창에서 바로 정확도를 바꿔 다시 인식하고, 고른 부분만 복사합니다.
- 설정을 아홉 범주로 다시 나눴습니다. 효과가 애매한 설정 옆의 `변화 보기`를 누르면 바꾸기 전과 후를 그림으로 비교합니다.
- 처음 사용 연습을 한 단계에 한 행동씩, 15단계로 다시 만들었습니다. 단계마다 짧은 영상이 나오고, 마치면 다음에 할 일을 알려 줍니다. 핀은 `연습 그림 복사`로 시작해 크기, 투명도, 닫기, 다시 열기까지 연습합니다.

알려진 점: 실제 고배율 모니터, 한글 입력기, 화면 녹화 파일의 워터마크는 이 테스트판으로 함께 확인합니다.
