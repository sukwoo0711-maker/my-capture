# MyCapture 4.10.0

4.10.0은 라이브러리를 다시 정리하고, 영역을 고를 때의 비율·고정 크기와 편집기 도장을 더한 업데이트입니다. 상주 메모리와 캡처 반응도 함께 개선했습니다.

- 라이브러리 카드에 `핀`과 `복사`를 늘 표시합니다. 선택 상자는 썸네일 왼쪽 위로 옮기고, 캡처 시각은 제목 오른쪽에 둡니다. 동작하지 않던 끌기 손잡이는 없앴습니다.
- 업데이트와 평가 알림은 카드를 가리지 않도록 상태 줄에 표시합니다. 카드 메뉴와 도구 막대는 카드와 같은 순서로 정리했습니다.
- 한글 입력 상태에서도 라이브러리의 P·K·M·T·G 키가 동작합니다. 메뉴의 삭제와 보관은 누른 카드가 선택에 들어 있으면 선택한 카드 전체에 적용합니다.
- 영역을 고를 때 R 키나 모드 막대의 비율 단추로 16:9·4:3·1:1·9:16 비율과 1280 × 720·1920 × 1080·1080 × 1080 고정 크기를 고를 수 있습니다.
- 편집기의 `도장`(S)에 로고나 이름 그림을 한 번 등록하면 다음 캡처에도 같은 자리에 찍을 수 있습니다. 오른쪽 클릭 메뉴에서 그림·불투명도를 바꿉니다.
- F1 도움말에 편집기·자르기·선택 화면·빠른 카드·라이브러리의 실제 단축키를 모두 표시합니다. 빠른 카드에서는 Ctrl+C·Ctrl+S도 사용할 수 있습니다.
- 메뉴와 알림에서 '으'의 가로획이 빠져 보이던 문제와, 이미지 가장자리에서 입력한 글상자가 입력을 마친 뒤 잘려 보이던 문제를 고쳤습니다.
- 연속 캡처에서 선택 화면이 더 빨리 나타나고, 캡처·편집기·핀을 닫은 뒤 남는 메모리를 줄였습니다.

이전 업데이트 내용은 [4.9.0 릴리스 노트](4.9.0-release-notes.md)에서 확인할 수 있습니다.
