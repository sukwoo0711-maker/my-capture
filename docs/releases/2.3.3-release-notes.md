# MyCapture 2.3.3

OCR 기본 품질을 빠름(Fast)으로 바꿨습니다. 새로 설치하거나 설정 파일이 없는 경우에는 회전 탐색 없이 1× 배율로 인식합니다. 이미 저장한 품질 값은 그대로 두고, 설정에서 보통(Balanced)이나 느림(Accurate)으로 바꿀 수 있습니다. 빠름·보통은 Windows OCR을 쓰고, 느림은 기존처럼 PP-OCRv5 한국어 모델을 사용합니다.

2.3.2의 시작 대화상자 수정과 2.3.1의 영수증 OCR·테마 시인성 개선은 그대로입니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
