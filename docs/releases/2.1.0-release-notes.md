# MyCapture 2.1.0

2.1.0은 라이브러리와 영상 편집기의 작업 구조를 정리하고, 2.0.0에서 보고된 선택·화면 표시·구간 편집 문제를 수정한 버전입니다.

## 새 작업실 디자인

- 라이브러리는 왼쪽 필터, 가운데 캡처 목록, 오른쪽 선택 항목 정보의 3단 구조로 구성합니다. 밝은 바탕과 청록 강조색으로 선택과 다음 동작을 구분합니다.
- 영상 편집기는 어두운 미리보기, 오른쪽 레이어·속성, 아래 타임라인을 중심으로 구성합니다. 시간 입력과 선택 구간을 명확하게 표시합니다.
- 기존 기본 미드나잇 설정은 새 작업실 디자인으로 한 번 전환합니다. 데이라이트·고대비 선택은 유지하며, 설정에서 미드나잇을 다시 선택하면 이후에도 유지됩니다.
- 갤러리 상세정보는 기존 썸네일을 재사용합니다. 화면 배치를 바꾸기 위해 원본 이미지를 추가로 일괄 로딩하지 않습니다.

## 수정 사항

- 라이브러리의 날짜 제목을 다시 누르면 해당 그룹의 선택이 해제됩니다. 다른 그룹의 선택은 유지합니다.
- 라이브러리의 편집 동작에 연필 아이콘과 설명을 제공합니다.
- 이미지 보관 표시는 자동 삭제까지 남은 시간임을 알 수 있도록 정리합니다. 영상의 보관 정책은 바꾸지 않습니다.
- Ctrl+Shift+X 녹화 영역 선택 전 안내창이 사라질 시간을 확보하고, 모니터 배치가 도중에 변경되면 잘못된 좌표로 진행하지 않도록 합니다.
- 테마 적용 시 반투명 캡처 배경의 투명도가 사라질 수 있는 문제를 수정합니다.
- 영상 자르기의 In/Out 시간 직접 입력, 핸들을 놓았을 때의 정확한 탐색, 드래그 단위 실행 취소를 보완합니다. 자르기 구간 밖의 원본 장면도 탐색할 수 있습니다.
- 텍스트 표시 구간은 원본 영상 시간 기준으로 명시하고, 기존 텍스트를 편집할 때 스타일을 보존합니다. 24시간이 넘는 영상의 시간 입력도 올바르게 유지합니다.
- 작은 영상 편집창에서 시간 입력·레이어 도구·상태 문구가 잘리는 문제를 수정합니다.

## 다운로드

- Windows 11 x64 설치형: `MyCapture-2.1.0-win-x64-setup.exe`
- Windows 11 x64 포터블: `MyCapture-2.1.0-win-x64-portable.zip`

두 형식 모두 .NET 런타임을 포함합니다. 파일 무결성 확인용 `SHA256SUMS.txt`와 원본 커밋을 기록한 `release-manifest.json`을 함께 제공합니다.
