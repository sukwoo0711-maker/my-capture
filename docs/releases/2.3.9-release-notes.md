# MyCapture 2.3.9

설정·라이브러리·트레이 세 곳을 손봤습니다.

**단축키 비우기 허용** — 화면 캡처 단축키를 더 이상 비워 둘 수 없다고 막지 않습니다. 단축키가 없어도 트레이 메뉴와 라이브러리 상단 버튼으로 모든 기능을 쓸 수 있기 때문입니다. 남아 있는 충돌 검사는 그대로입니다.

**라이브러리 상단 툴바** — 라이브러리 창 오른쪽 위에 영역 캡처와 화면 녹화 버튼을 추가했습니다. 단축키나 트레이 없이 마우스만으로 캡처·녹화를 시작할 수 있고, 시작 시 라이브러리 창은 자동으로 숨겨집니다.

**트레이 메뉴 트리 구조** — 캡처 관련 명령(영역·창·전체 화면·스크롤·마지막 영역 반복·지연·화면 녹화)을 하나의 "캡처" 하위 메뉴로 묶었습니다. 라이브러리·설정·종료는 최상위에 둡니다. 테마가 적용된 WPF 메뉴와 네이티브 폴백 메뉴 모두 같은 구조입니다.

**트레이 아이콘 리디자인** — 두 개의 외곽선 사각형 대신, 채워진 둥근 셔터 한 장과 가운데 검은 점(녹화 표시)으로 단순화했습니다. 배경색에 관계없이 잘 읽히고 상태 색(파랑·호박·초록·코랄)은 그대로입니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
