# MyCapture 3.2.1

3.2.0에서 웹페이지 주소가 저장되지 않던 문제를 고쳤습니다.

- **원본 페이지 주소 저장 복구**: 3.2.0은 주소를 읽는 제한 시간을 실측에 맞춰 조정했지만, 브라우저 창이 여러 개인 데스크톱에서는 목록 전체를 훑는 비용(실측 약 0.5초)이 제한을 넘어 주소가 비어 있었습니다. 제한을 실제 비용에 맞게 넓혀, 웹페이지 캡처가 페이지 주소를 PNG와 클립보드에 다시 담습니다. 영역 선택 창은 주소를 읽기 전에 표시되므로 캡처 화면이 늦게 뜨지 않습니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
