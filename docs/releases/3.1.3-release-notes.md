# MyCapture 3.1.3

캡처 영역을 맞추고, 원본 웹페이지를 다시 찾고, 긴 파일명을 확인하는 흐름을 개선했습니다.

- **캡처 영역 격자**: 영역을 선택할 때 가로·세로 3등분 안내선을 표시합니다. 기본으로 켜져 있으며 설정에서 끌 수 있습니다. 스크린샷과 녹화 영역 선택에 적용되고, 저장한 이미지나 영상에는 포함되지 않습니다.
- **원본 웹페이지 주소 보관**: 브라우저가 제공하는 실제 문서 주소를 캡처 정보에 저장합니다. 라이브러리에서 주소를 확인·복사하거나 원본 페이지를 열 수 있고, 주소로 검색할 수 있습니다. 문서 주소를 확인할 수 없거나 캡처 중 페이지·창 상태가 바뀌면 주소를 붙이지 않습니다.
- **긴 파일명 전체 보기**: 라이브러리 카드에 마우스를 올리거나 키보드로 포커스를 이동하면 전체 이름을 펼쳐 보여 줍니다. 카드 배치는 그대로 유지되며 Esc로 닫을 수 있습니다.
- **저장·복구한 이미지 갱신**: 같은 파일을 다시 저장하거나 복구했을 때 이전 이미지가 남아 보이거나 과거 크기로 판단되는 문제를 수정했습니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
