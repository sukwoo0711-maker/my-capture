# MyCapture 2.3.6

2.3.5가 시작 직후 "MyCapture를 시작할 수 없습니다" 대화상자를 띄우던 문제를 고쳤습니다. OCR 서비스 등록 방식을 2.3.2 때처럼 명시적 생성자로 바꾼 것입니다. 2.3.5의 나머지 내용(정밀 품질의 Real-ESRGAN 4배 확장)은 그대로이며, v2.3.5는 절대 덮어쓰지 않았습니다.

2.3.5의 정밀(Careful) 품질은 조명·대비·선명 보정 후 Real-ESRGAN 4배 초해상도를 실행하고, 그 결과를 PP-OCRv5로 읽습니다. 모델은 처음 정밀을 쓸 때 약 67MB를 내려받으며, 실패하면 기존 방식으로 계속 인식합니다.

Windows 11 x64 설치형과 포터블을 제공하며, 모두 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
