# MyCapture 6.0.0

6.0.0은 캡처 → 결과 카드 → 핀으로 이어지는 흐름을 짧게 다듬고, 편집기·라이브러리·설정·동영상 편집기·첫 실행 화면을 같은 색·글자·간격 기준으로 다시 맞췄습니다. 밝은 테마도 어두운 테마와 같은 기준으로 다듬었습니다.

5.5.0 이후의 변경을 담았습니다. 5.5.0의 변경은 [5.5.0 릴리스 노트](5.5.0-release-notes.md)에서 확인할 수 있습니다.

## 화면 전체

- 창 바탕, 작업 영역, 묶음, 떠 있는 카드와 메뉴를 네 가지 불투명한 면으로 나눴습니다. 어두운 테마와 밝은 테마에서 같은 순서로 구분됩니다.
- 글자 크기와 굵기, 간격, 모서리 둥글기, 단추 높이를 모든 화면에서 같은 기준으로 맞췄습니다. 본문은 보통 굵기로, 제목만 굵게 씁니다.
- 체크 상자는 고르면 채워지고, 입력 칸은 아래 선으로 구분합니다. 입력 오류 표시와 키보드 초점 표시가 함께 보입니다.
- 키보드 초점 표시는 키보드로 옮길 때만 보이고, 마우스로 누를 때는 보이지 않습니다.
- 고대비 모드에서는 Windows가 정한 시스템 색을 씁니다.

## 캡처 선택 화면

- 포인터를 다른 창으로 옮기면 강조 테두리가 크기와 거리에 상관없이 짧게 미끄러져 따라갑니다. 가까운 이동은 바로 붙고, Windows의 애니메이션 효과를 끄면 움직이지 않습니다.
- 강조 테두리를 대상 바깥에 그려 캡처될 내용을 가리지 않습니다.
- 위쪽 도구 막대를 캡처·녹화 종류, 캡처 방식(영역·창·자유형·전체 화면·스크롤·텍스트·색상), 지연·비율·메뉴의 세 묶음으로 나눴습니다. 지금 고른 방식은 강조색으로 채워 보입니다. Windows 11에서는 막대와 안내 칩의 모서리가 둥글게 그려집니다.
- 안내 칩은 키 이름을 키 모양으로 보이고, 크기와 좌표 숫자는 폭이 같은 숫자로 그려 값이 바뀌어도 흔들리지 않습니다.
- 창을 가리키면 `클릭: 창 캡처 · 드래그: 영역 캡처 · Esc: 취소` 안내가 나옵니다.
- 스크롤 캡처 방식과, 끌기 전에 창을 가리키는 동안에는 돋보기를 감춥니다.
- 스크롤 캡처가 진행되는 도중에도 `Esc`로 취소할 수 있습니다.
- 녹화 영역 선택 화면이 돋보기 설정을 따릅니다. 전에는 설정과 상관없이 늘 켜졌습니다.
- 선택 화면이 열린 뒤 키와 마우스 입력을 받기까지의 시간을 줄였습니다.

## 캡처 결과 카드

- 카드의 주 단추가 `핀`입니다. `핀`·`편집`·`복사`를 아이콘과 이름으로 나란히 두었고, `라이브러리`·`저장`·`텍스트 복사`·`연결 프로그램`은 `더보기` 메뉴로 옮겼습니다.
- 미리 보기가 캡처의 원래 비율을 지킵니다. 세로로 긴 캡처는 높이 240까지, 가로로 긴 캡처는 높이 180까지 보이고, 작은 캡처는 두 배까지만 키웁니다. 닫기 단추가 그림을 가리지 않습니다.
- 상태를 한 줄로 보입니다. 긴 문구는 줄여 보이고, 마우스를 올리면 전체를 보입니다.
- `Alt+Q`로 카드에 들어가면 `핀`에 초점이 가고, `Tab`은 핀·편집·복사·더보기·유지·닫기 순서로 옮겨 갑니다. 처음 쓰는 안내에 `Alt+Q` 키보드 조작을 더했습니다.

## 핀

- 핀이 뜰 때 내용은 처음부터 제자리에 제 크기로 보이고, 테두리 장식은 0.25초 안에 끝납니다. 전에는 장식이 약 0.6초 동안 움직였습니다.
- 마우스를 올리면 나오는 막대를 큰 핀에서도 핀 바깥 위에 둡니다. 위에 자리가 없으면 아래, 그다음 안쪽에 둡니다.
- 저장 완료 알림이 6초에서 2초로 줄었습니다.
- 핀을 직접 줄일 때 짧은 변이 40보다 작아지지 않습니다.
- 배율 알림에 실제 크기를 픽셀로 함께 보입니다.
- 첫 핀 안내에 `F2`로 글자를 고르는 방법을 더했습니다.
- `투명도`를 `불투명도`로 통일했습니다.
- 트레이 메뉴 `열린 핀`의 `그 외 {n}개` 줄을 누르면 목록에 없는 핀을 앞으로 가져옵니다.

## 편집기

- 캔버스 둘레의 테두리와 여백을 없애 원본이 더 넓게 보입니다.
- 오른쪽 위 결과 명령을 `저장` → `복사하고 닫기` → `핀` → `더보기` 순서로 두었습니다. `더보기`의 첫 항목은 `이미지 내보내기`, 마지막 항목은 `정보`입니다. `Ctrl+C`는 그대로 복사하고 닫기입니다.
- 저장 메뉴에 `다른 이름으로 저장…`을 두었습니다.
- 편집기가 열릴 때 원본은 처음부터 제자리에 보이고, 명령·도구·속성·상태 영역만 짧게 나타납니다. 키나 마우스를 누르면 바로 모두 보입니다.
- 도구를 바꿔도 속성 막대의 높이가 바뀌지 않습니다. 좁은 창에서는 속성 막대 안에서 세로로 넘겨 봅니다.
- 도형 채움을 불투명도로 보입니다. 속성 막대의 이름은 `채움`입니다. 저장된 값은 그대로입니다.
- `개인정보 가리기` 단추의 아이콘을 가려진 문서 모양으로 바꿨습니다.
- 쓸 수 없는 `텍스트 복사`와 `개인정보 가리기`에 마우스를 올리면 그 이유를 보입니다.
- 단계 번호 도구의 번호 칸 이름을 `선택한 번호`로 바꿨습니다.
- `개인정보 가리기`가 끝나 선택 도구로 바뀌어도 도구 레일이 이전 도구를 강조하던 문제를 고쳤습니다.
- 개인정보를 찾는 중 `Esc`로 취소할 수 있습니다. 전에는 안내와 달리 `Esc`가 동작하지 않았습니다.

## 라이브러리와 설정

- 라이브러리 위쪽 첫 칸에 검색을 두고, 캡처와 녹화는 오른쪽에 두었습니다.
- 아무것도 고르지 않았을 때 작업 줄에 지금 보는 범위와 정렬을 보입니다.
- 항목을 고르면 작업 줄에 `핀`·`복사`·`편집`이 나옵니다. `미리보기`·`보관`·`PDF로 만들기`는 `더보기` 메뉴에서 실행합니다.
- 선택을 풀어도 검색어, 정렬, 목록의 스크롤 위치가 그대로입니다.
- 설정 창의 큰 둥근 판을 평면으로 바꾸고, 값은 이름·값·설명 열로 맞췄습니다.
- 좁은 설정 창에서는 단축키 단추가 줄을 바꾸고, 저장 경로의 찾아보기·열기 단추가 입력 칸 아래로 갑니다.

## 동영상 편집기와 GIF

- 미리 보기 둘레의 둥근 테두리와 여백을 없애 영상이 더 넓게 보입니다.
- `자세히`를 펼치면 `프레임 이동` → `자르기`와 남는 길이 → 시작·끝·원래 길이 → `레이어` 순서로 보입니다.
- GIF 내보내기에서 미리 보기와 용량·프레임 수·길이를 먼저 보이고, 그 아래에 권장 설정과 세부 옵션을 둡니다.
- `새 캡처`를 이미지 편집기처럼 상태 줄로 옮겼습니다. `저장` 도구 설명에 저장한 뒤 창을 닫는다고 적었습니다.

## 첫 실행과 연습

- 핵심 단축키 안내 창을 내용 높이에 맞추고 제목·본문·단축키의 글자 위계를 정리했습니다.
- 안내 다음에 복사한 자료를 `F3`으로 실제 핀으로 띄워 봅니다. 복사할 자료가 없으면 `예문 복사`를 누릅니다. 안내를 열거나 읽는 동안에는 클립보드를 건드리지 않습니다.
- 핀이 실제로 뜬 뒤에 완료로 표시합니다. 안내 창을 닫아도 핀은 남습니다. `건너뛰기`로 넘어갈 수도 있습니다.
- 완료하거나 건너뛴 뒤 `전체 연습`으로 3개 주제 15단계 연습을 이어서 할 수 있습니다. 트레이·도움말·설정에서 연습을 열면 주제를 고르는 화면부터 시작합니다.
- 연습은 직접 다룰 자료와 지시문을 먼저 보이고, `예시 영상 보기`를 눌러야 영상을 재생합니다.
- 평가 단추의 이름을 카드에서는 `평가`, 설정과 지원 화면에서는 `Microsoft Store에서 평가`로 나눴습니다.

## 그 밖의 수정

- 편집기·핀·라이브러리를 쓰는 동안과 닫은 뒤의 메모리 사용량이 5.5.0보다 줄었습니다.
- 사용법 영상 `이미지 흐림`이 흐림 대신 모자이크를 보이던 장면을 고쳤습니다.
- 사용법 영상 45개 기능을 한국어·영어로 6.0 화면에 맞춰 다시 만들었습니다.
