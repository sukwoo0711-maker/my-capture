# MyCapture 4.1.4

4.1.4는 캡처 영역을 고르는 화면의 그리기 부담을 더 줄인 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.1.4.0`입니다. GitHub 릴리스의 포터블 zip은 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오.

## 캡처 선택 화면

- 영역을 드래그할 때 화면 전체를 다시 그리지 않고, 선택 영역이 바뀐 부분만 다시 그립니다.
- 돋보기 격자와 십자선을 화면 픽셀에 맞춰 그려 포인터를 움직일 때의 그리기 부담을 줄였습니다.
- 포인터를 움직일 때 메모리를 새로 할당하지 않습니다.
- 선택 화면이 뜨자마자 누른 Esc나 모드 키를 놓치지 않습니다.
- 앱을 실행한 뒤 첫 캡처에서 선택 화면이 더 빨리 키보드 입력을 받습니다.
- 화면 모양은 4.1.3과 같습니다.

측정한 PC(3440×1440 120Hz 주 모니터와 세로 보조 모니터)에서 4.1.3과 번갈아 실행해 비교한 중앙값입니다.

| 항목 | 4.1.3 | 4.1.4 |
|---|---|---|
| 포인터 이동 중 화면 그리기 부담(1초당 사용 시간) | 약 281ms | 약 199ms |
| 영역 드래그 중 화면 그리기 부담(1초당 사용 시간) | 약 487ms | 약 244ms |
| 실행 후 첫 캡처에서 키보드 입력을 받기까지 | 약 141ms | 약 93ms |
