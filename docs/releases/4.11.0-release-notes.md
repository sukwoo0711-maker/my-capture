# MyCapture 4.11.0

4.11.0은 핀을 더 쉽게 익히도록 안내를 다시 만들고, 핀에 Markdown·Mermaid 표시와 한국어·영어 번역을 더한 업데이트입니다. 창 안에서 바로 캡처하기, 파일 정보, GIF 프레임 속도도 함께 들어갔습니다.

- F3은 지금 보고 있는 그림을 핀으로 띄웁니다. 편집기에서는 편집한 그림을, 영역을 고르는 중에는 고른 영역을, 그 밖에는 지금처럼 클립보드를 띄웁니다. 편집기 명령 막대에 `핀`을 더했습니다.
- 핀 테두리를 끌어 크기를 바꿀 수 있습니다. 휠로 크기를 바꾸는 방법은 그대로입니다.
- 화살표의 머리를 끝·양쪽·없음으로 고를 수 있습니다.
- 영역을 고를 때 지금 쓸 수 있는 단축키를 화면 구석에 보여 줍니다. F1로 켜고 끕니다.
- 편집을 마치거나 캡처 카드를 닫으면, 처음 다섯 번은 저장한 곳(라이브러리)과 라이브러리를 여는 방법을 알려 줍니다.
- 처음 사용 안내를 다섯 단계 연습으로 바꿨습니다. 단축키를 직접 눌러 보며 캡처, 그리기, 핀, 크기 바꾸기, 라이브러리에서 찾기를 익힙니다. 이전 버전에서 업데이트한 경우에는 새 기능 연습을 한 번 권합니다.
- 핀이 Markdown을 문서로, Mermaid를 그림으로 표시합니다. 핀의 `번역`을 누르면 이 PC 안에서 한국어와 영어 사이를 번역합니다. 번역 모델은 처음 번역할 때 한 번 내려받습니다.
- 라이브러리와 편집기에서 바로 새 캡처를 시작할 수 있습니다. 편집 중인 화면을 캡처하거나 녹화해도 편집기는 그대로 남습니다.
- 카드 메뉴의 `정보`(Alt+Enter)로 파일 크기, 해상도, 길이, 저장 위치를 확인합니다.
- GIF로 내보낼 때 프레임 속도를 5~50fps에서 고르고 예상 크기를 미리 봅니다.

4.10.0의 라이브러리 개편, 영역 선택 비율과 고정 크기, 편집기 도장도 포함합니다. 자세한 내용은 [4.10.0 릴리스 노트](4.10.0-release-notes.md)에서 확인할 수 있습니다.
