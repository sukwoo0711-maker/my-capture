# MyCapture 4.0.3

Microsoft Store 배포를 시작하고, 한국어 안내 문구와 라이브러리 화면의 줄바꿈을 정리했습니다. 이 버전부터 MyCapture는 Microsoft Store로만 배포하며, GitHub 릴리스는 4.0.2가 마지막입니다.

- Microsoft Store에서 MyCapture를 설치할 수 있습니다. Store 설치본은 Microsoft가 서명하므로 SmartScreen과 "알 수 없는 게시자" 경고 없이 설치되며, 업데이트도 Microsoft Store가 제공합니다. 로그인 시 자동 시작은 처음에 꺼져 있고 설정에서 켤 수 있습니다. Store 설치본은 설정과 라이브러리를 앱 전용 폴더에 저장하므로 앱을 제거하면 함께 삭제됩니다.
- 앱 안내와 오류 메시지의 문장 끝을 "~하십시오"로 통일했습니다.
- 라이브러리 왼쪽 칸의 보관 안내와 항목 수가 단어 중간에서 줄이 바뀌지 않습니다.
- 라이브러리 머리말 설명이 잘리지 않도록 줄였습니다. 전체 문장은 툴팁으로 확인할 수 있습니다.
- GitHub 이미지 첨부(`F9`)의 기본 이슈 페이지를 공개 [지원 저장소](https://github.com/sukwoo0711-maker/mycapture-support)로 바꿨습니다. 이전 기본값을 쓰던 설정은 자동으로 옮기고, 직접 지정한 이슈 페이지는 그대로 둡니다.
- 사용자 지원, 문의와 [개인정보처리방침](https://github.com/sukwoo0711-maker/mycapture-support/blob/main/PRIVACY.md)은 지원 저장소에서 확인할 수 있습니다.
- README와 개인정보처리방침에 실제 네트워크 연결을 정확히 적었습니다. 앱이 자동으로 인터넷에 연결하는 경우는 PC에 없는 OCR 모델 파일을 앱 시작 시 내려받을 때뿐입니다.

Microsoft Store 패키지는 Windows 11 x64용이며 .NET 런타임을 포함합니다.
