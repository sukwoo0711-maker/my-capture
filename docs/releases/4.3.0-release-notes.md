# MyCapture 4.3.0

4.3.0은 Windows 10 22H2 지원을 다시 넣고, 설치 파일을 PowerShell 없이 동작하도록 바꾼 업데이트입니다. 영상의 밝기와 색 범위 표시, 영상 프레임 편집 저장도 함께 고쳤습니다.

Microsoft Store 배포용 패키지 버전은 `4.3.0.0`입니다. 이제 Windows 10 22H2에서도 Store에서 설치할 수 있습니다. GitHub 릴리스에는 사용자별 설치 파일(`setup.exe`)과 포터블 zip을 함께 올립니다. 두 파일 모두 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오. 설치 파일과 zip은 코드 서명이 없으므로 `SHA256SUMS.txt`의 해시로 내려받은 파일을 확인하십시오.

## Windows 10 지원

- Windows 10 버전 22H2(빌드 19045) x64에서 설치하고 사용할 수 있습니다. ARM64의 x64 에뮬레이션은 계속 Windows 11(빌드 22000) 이상이 필요합니다.
- Windows 10에서는 녹화하는 동안 화면 가장자리에 노란 테두리가 보일 수 있습니다. 이 테두리는 녹화 결과에 포함되지 않습니다.
- Windows 10에서도 녹화 중 컨트롤 창과 메뉴가 녹화 결과에 찍히지 않습니다. Windows 10에서는 투명 효과 대신 불투명 표시를 사용합니다.
- 둥근 창 모서리와 창 배경 효과처럼 Windows 11에만 있는 장식은 Windows 10에서 표시하지 않습니다.
- Print Screen 안내에서 Windows 10의 설정 경로를 안내합니다.

## 설치 파일

- 설치 파일이 PowerShell 없이 동작합니다. PowerShell 실행 정책과 관계없이 설치하고 제거할 수 있으며, 관리자 권한은 필요하지 않습니다.
- 파일 무결성 확인, 실패 시 되돌리기, 제거할 때 캡처와 설정 보존은 이전과 같습니다.
- 설치기는 Windows 10 22H2와 Windows 11에 기본으로 포함된 .NET Framework 4.8을 사용합니다. 사용할 수 없는 환경에서는 포터블 zip과 Microsoft Store 설치 방법을 안내합니다.
- 설치 폴더에 제거 프로그램 `MyCaptureUninstall.exe`가 추가됩니다. 설정 > 앱에서 제거할 수 있습니다.

## 영상 색상

- 갤러리와 편집기가 화면에 실제로 표시되는 영상을 원본과 비교해 밝기와 색 범위를 맞춥니다. 그래픽 드라이버가 영상 색을 바꾸는 PC에서는 측정한 곡선으로 보정합니다.
- 프레임 편집과 MP4·GIF 내보내기, 썸네일과 필름스트립이 전체 범위 영상의 색을 원본대로 유지합니다.

## 영상 프레임 편집

- 자막이 있는 영상 프레임을 정지 이미지로 편집하면 자막은 바탕 이미지에 한 번만 들어가고, 주석은 나중에 수정할 수 있는 레이어로 남습니다.
- 복사나 저장에 실패한 뒤 주석을 더해 다시 저장하면 추가한 주석이 갤러리에서 다시 열 때 사라지던 문제를 고쳤습니다.
- 회전만 한 프레임 편집이 편집 내용 없음으로 처리되던 문제와, 회전한 프레임에 자막이 두 번 표시되던 문제를 고쳤습니다.

## 라이브러리

- 원본을 바꾸는 중에 같은 파일을 가져오면 중복 판정이 틀릴 수 있던 문제를 고쳤습니다.
- 영문 사용법 창의 미리보기 크기를 확보했습니다.

## 알려진 제한

- Windows 기본 OCR은 설치된 OCR 언어만 사용합니다. 한국어 OCR만 설치된 PC에서는 영어 글자도 한국어 엔진으로 인식하며, 표의 숫자와 머리글 인식이 부정확할 수 있습니다. 이런 경우에는 향상 OCR을 사용하십시오.
- 거의 단색인 화면처럼 영상의 색 단계가 부족하면 색 보정을 확정하지 못합니다. 이때는 그래픽 드라이버가 표시하는 색을 그대로 보여 줍니다.

## 데이터

- 설정, 라이브러리 기록, 색인, 메타데이터 형식은 4.2.1과 같습니다. 4.2.1로 되돌려도 캡처, 설정, 라이브러리가 그대로 열립니다.
- 4.3.0이 저장 도중 비정상 종료된 직후 4.2.1로 되돌리면, 회전하거나 자른 영상 프레임 정지 이미지의 크기 정보가 이전 값으로 남을 수 있습니다. 되돌리기 전에 4.3.0을 한 번 실행해 저장 복구를 마치십시오.
- 영상 프레임 정지 이미지의 편집 복구 초안은 4.2.1에서 일반 이미지 초안으로 복구됩니다.
- 4.2.1은 Windows 10을 지원하지 않으므로, Windows 10에서는 4.2.1로 되돌릴 수 없습니다.

이전 업데이트의 포인트 색과 사용법 버튼 변경은 [4.2.1](4.2.1-release-notes.md), 라이브러리·편집기 확장과 새 앱 아이콘은 [4.2.0](4.2.0-release-notes.md) 릴리스 노트에서 확인할 수 있습니다.
