# MyCapture 5.0.1

5.0.1은 문자 인식 뒤 메모리를 계속 차지하던 문제를 고친 업데이트입니다. 5.0.0의 변경은 [5.0.0 릴리스 노트](5.0.0-release-notes.md)에서 확인할 수 있습니다.

- 설정의 인식 품질을 `정확`으로 두거나 문자 인식 창에서 `정확하게 다시 인식`을 누르면, 문자 인식을 한 번 한 뒤 앱을 끌 때까지 메모리를 1.4 GB 넘게 차지했습니다. 여러 장을 읽으면 2.7 GB까지 늘었고, 라이브러리가 새 캡처의 글자를 뒤에서 읽을 때도 같았습니다. 문자 인식 엔진이 지금까지 읽은 가장 큰 그림에 맞춰 늘린 메모리를 줄이지 않고, 앱을 끌 때까지 놓지 않은 것이 원인이었습니다.
- 이제 문자 인식 엔진은 한 번 읽는 데 필요한 만큼만 메모리를 쓰고, 마지막으로 읽고 20초가 지나면 메모리를 돌려줍니다. 1600×900 화면 한 장을 `정확`으로 읽고 30초가 지났을 때 메모리가 1,364 MB에서 162 MB로 줄었습니다. 그림 핀 번역이 영문 낱말을 고쳐 읽을 때 쓰는 같은 엔진도 이렇게 메모리를 돌려줍니다.
- 20초 넘게 쉰 뒤 다시 읽으면 엔진을 불러오는 데 0.2초 안팎이 더 걸립니다.
- 그림 핀 번역이 영문 낱말을 고쳐 읽을 때, 그림의 형식에 따라 글자를 읽지 못할 수 있던 문제도 함께 고쳤습니다.
