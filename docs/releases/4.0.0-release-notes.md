# MyCapture 4.0.0

캡처 직후 작업, 단축키 설정, 주석 편집과 오류 복구 흐름을 개선했습니다.

- **Quick Access**: 캡처 뒤 커서가 있는 모니터의 우하단에 썸네일과 복사·편집·화면 고정·저장 버튼을 표시합니다. 썸네일을 다른 앱으로 드래그해 파일로 전달하거나 라이브러리에서 열 수 있습니다. 자동 닫힘 진행 표시와 유지 버튼을 제공하며, 마우스·키보드로 조작하는 동안 닫힘을 잠시 멈춥니다. 설정에서 카드를 끄거나 알림음을 켤 수 있습니다. 카드는 기본 켬, 알림음은 기본 끔입니다.
- **라이브러리**: 화면 제목의 버전, 버튼의 접근키 원문과 탭 문자를 정리했습니다. 캡처·녹화 단축키는 실제 설정을 표시합니다. 자동 삭제 경고는 남은 시간이 24시간 미만인 이미지에만 표시하며, 라이브러리·보관·화면 고정 용어를 맞췄습니다.
- **단축키 녹화 입력**: 키 조합을 직접 누르면 키캡으로 표시합니다. 중복과 다른 앱의 등록 여부를 확인하고 지우기·기본값 복원을 제공합니다. 스크롤·지연 캡처 단축키도 지정할 수 있으며 기본값은 지정 안 됨입니다.
- **주석 도구**: 타원(E), 형광펜(H), 단계 번호(N), 사용자 지정 색상을 추가했습니다. 모자이크(M)와 자르기(X) 단축키를 연결했습니다. 단계 번호는 실행 취소·다시 실행과 편집 레이어 저장을 지원합니다.
- **테마 대화상자**: 시스템 메시지 상자를 앱 테마에 맞췄습니다. 오류 원인과 복구 안내를 본문에 표시하고, 기술 정보는 복사 가능한 접힌 상세 영역으로 옮겼습니다. 저장 위치를 바꾸는 등 가능한 해결 동작을 기본 버튼으로 제공합니다.
- **첫 실행과 도움말**: 핵심 단축키 세 가지를 단계별로 안내합니다. F1 또는 ?로 여는 단축키 모음은 캡처·주석·동영상·화면 고정 탭과 검색을 제공하며 전역 단축키 변경을 반영합니다.
- **동영상 편집기**: 레이어 추가 동작을 한 메뉴로 모아 작은 창의 공간을 확보했습니다. 구간 표시는 시작·끝으로 통일하고 타임라인 캡션 대비를 높였습니다. 3.4.0의 재생 도구 묶음과 즉시 구간 적용 방식은 유지합니다.
- **캡처 자체 진단**: 단색 판정을 모든 픽셀의 색 채널로 검사합니다. 화면 일부에만 내용이 있을 때 정상 캡처를 빈 화면으로 잘못 판정하던 문제를 수정했습니다.

창 선택기·스크롤 진행 HUD, 녹화 테두리와 일시정지·입력 시각화, 핀 미니 도구 모음과 회전·뒤집기·다시 열기는 후속 버전으로 미뤘습니다. 블러·스포트라이트도 편집 레이어 호환 검증 후 추가할 예정입니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
