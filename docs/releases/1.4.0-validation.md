# MyCapture 1.4.0 검증 기록

검증 기준일: 2026-09-02 (Asia/Seoul)

대상: Windows 11 21H2(build 22000) 이상, x64

배포 계약: self-contained, offline, unsigned, MIT

> 이 문서는 1.4.0 배포 당시의 검증 기록입니다. 후속 `main`에서는 핵심 작업 단축키를
> `Ctrl+Shift+C/X/Z`로 통일해 영역 녹화 기본값을 `Ctrl+Shift+X`로 마이그레이션합니다.

## 릴리스 경계

- 라이브러리 단축키는 `Ctrl+Shift+Z`, 영역 녹화 단축키는 `Ctrl+X`이다.
- `Ctrl+Shift+C` 영역 캡처와 편집 완료 결과는 항상 클립보드에 복사된다.
- 캡처 원본은 편집기 진입과 함께 화면에 고정된다.
- 이미지와 MP4가 통합 라이브러리에 저장되고 미디어 종류가 명확히 표시된다.
- MP4는 라이브러리 내부의 음소거 플레이어에서 재생·일시정지·탐색할 수 있다.
- 영상의 텍스트와 프레임 편집은 시간 구간을 가진 독립 비파괴 레이어로 유지된다.
- 자르기 삭제 핸들·삭제 범위 표시와 GIF 배속 선택이 미리보기 및 내보내기 계약에 반영된다.

## 패키지 무결성 및 출처

`build/package.ps1 -Version 1.4.0`은 깨끗한 Git 작업 트리에서만 실행되며 다음을 보장한다.

- `win-x64` CoreCLR/WPF를 포함한 완전한 self-contained publish
- 설치 payload와 portable ZIP의 경로·크기·SHA-256 inventory 검증
- ZIP traversal, 중복 경로, reparse point 및 symlink 방어
- 설치·업데이트 실패 시 rollback과 사용자 데이터 보존
- 패키징 시작과 종료 시 동일한 정확한 Git 커밋인지 재검증
- `release-manifest.json`에 source commit과 clean-tree 상태 기록
- 게시 파일의 SHA-256을 `SHA256SUMS.txt`에 기록

## 알려진 제한

- Authenticode 서명이 없어 Windows가 알 수 없는 게시자 경고를 표시할 수 있다.
- Windows 10은 지원하지 않는다.
- 라이브러리 내 동영상 재생은 의도적으로 음소거이며 녹음 기능을 포함하지 않는다.
- 조직 보안 정책이 IExpress 또는 PowerShell 설치 경로를 막는 경우 portable ZIP을 사용해야 한다.
