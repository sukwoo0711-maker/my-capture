# MyCapture 3.2.0

웹페이지를 캡처하면 페이지 주소가 이미지 파일과 클립보드에 함께 담겨, 나중에 파일만 열어도 어느 페이지에서 가져왔는지 알 수 있습니다.

- **원본 페이지 주소 저장**: 웹페이지 캡처의 주소를 PNG 안에 `SourceURL` 메타데이터로 기록합니다. 라이브러리 원본·표시용 파일, 편집 후 저장, 다른 이름으로 저장, 빠른 저장, 갤러리 복사, 축소 내보내기의 원본 PNG가 모두 주소를 유지합니다.
- **클립보드에 주소 유지**: 캡처를 복사하면 이미지와 함께 주소가 담기고, 다시 붙여넣은 이미지에서도 주소를 되읽습니다. 나중에 복사한 이미지에는 그 시점의 주소만 남습니다.
- **F9 업로드 문구**: F9로 GitHub에 이미지를 올리면 붙여넣는 글에 첨부 URL 다음 줄에 원본 페이지 주소를 함께 넣습니다. 주소가 없거나 안전하지 않은 형식이면 첨부 URL만 넣습니다.
- **주소 읽기 안정화**: 살아 있는 브라우저 창에서 문서 주소를 읽는 경로를 컨트롤 뷰 우선으로 바꾸고, 제한 시간을 실제 소요(약 0.2초)에 맞게 넓혔습니다. 이전 0.2초 제한은 실캡처에서 읽기를 자주 취소해 주소가 비어 있었습니다.

주소는 `http`·`https`만 허용합니다. 사용자 정보가 포함된 주소, 제어 문자, 8KB를 넘는 주소는 저장하지 않습니다. JPEG로 축소한 파일은 형식상 메타데이터를 담지 못합니다. 핀 고정 후 빠른 저장으로 내보낸 PNG에는 아직 주소가 담기지 않습니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
