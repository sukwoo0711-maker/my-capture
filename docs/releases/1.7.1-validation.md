## 통합 및 산출물 계약

원격 ruleset: 선형 이력 필수, PR 통합은 squash/rebase 허용, 필수 승인 0개, 최신 base 기준 `Release build and tests` 필수. PR의 최신 head 검증 후 squash 통합합니다.

최종 `build/package.ps1 -Version 1.7.1`은 source commit과 clean-tree 상태를 시작·종료 시 검증해야 합니다. 패키지 self-test는 독립 프로세스마다 종료 코드 0과 정확히 한 줄의 `RESULT: PASS`를 요구합니다. 최종 산출물 목록:

- `MyCapture-1.7.1-win-x64-setup.exe`
- `MyCapture-1.7.1-win-x64-portable.zip`
- `installer-manifest.json`
- `release-manifest.json`
- `SHA256SUMS.txt`
- `README-OFFLINE.txt`

소스 동결 이후의 태그 SHA, 통합 SHA, release URL, 각 asset 이름·크기·SHA-256 및 원격 실행 결과는 GitHub v1.7.1 릴리스 본문과 `artifacts/validation`의 릴리스 증거에 기록합니다. 검증된 패키지의 source SHA가 다시 바뀌지 않도록 해당 사후 결과를 이 소스 문서에 역으로 끼워 넣지 않습니다.

## 알려진 제한과 검증 범위

- 자동 OCR 색인은 회전된 텍스트를 놓칠 수 있습니다. 사용자가 직접 OCR을 요청하면 기존 회전 검색을 사용합니다.
- 녹화 중 스크린샷은 차단합니다. 오버레이를 영상에 섞지 않는 동시 캡처는 이번 범위가 아닙니다.
- 유휴 CPU의 현장 프로파일(PerfView)은 이번 소스 동결에 포함하지 않았습니다. 자동 색인의 회전 생략과 드래그 경로 축소가 해당 병목에 대한 코드 측 대응입니다.
