# MyCapture 3.1.4

캡처를 시작할 위치를 쉽게 맞출 수 있도록, 드래그 전 커서를 따라 움직이는 가로·세로 보조선을 개선했습니다.

- **시작점 보조선**: 캡처 준비 상태에서 커서 위치를 기준으로 화면 끝까지 이어지는 주황색 선을 표시합니다. 어두운 외곽선을 더해 배경과 구분되며, 안내 문구와 확대경을 가리지 않습니다.
- **드래그 전 표시**: 마우스를 눌러 영역 선택을 시작하면 긴 보조선이 사라집니다. 기존 작은 커서와 청록색 시작점 표시는 유지하며, 3.1.3의 선택 영역 내부 3분할 격자는 제거했습니다.
- **표시 설정**: 설정 → 캡처 → ‘드래그 전 커서 보조선 표시’에서 켜거나 끌 수 있습니다. 이전 버전에서 저장한 ON/OFF 선택도 유지합니다.

스크린샷과 녹화 영역 선택에 함께 적용됩니다. 보조선은 저장한 캡처 이미지에 포함되지 않습니다.

Windows 11 x64 설치형과 포터블을 제공하며 .NET 런타임을 포함합니다. `SHA256SUMS.txt`와 `release-manifest.json`에서 파일 무결성과 소스 커밋을 확인할 수 있습니다.
