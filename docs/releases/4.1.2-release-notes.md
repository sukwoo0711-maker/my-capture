# MyCapture 4.1.2

4.1.2는 캡처 속도, 작업 보호, 라이브러리 삭제·복원, 사용법 안내를 개선한 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.1.2.0`입니다. GitHub 릴리스의 포터블 zip은 앱 안 업데이트를 받지 않습니다. 업데이트를 자동으로 받으려면 Microsoft Store 설치본을 사용하십시오.

## 캡처

- 캡처 단축키를 누르면 브라우저 주소나 탐색기 폴더를 읽는 동안 기다리지 않고 바로 선택 화면을 표시합니다. 측정한 PC에서 단축키부터 선택 화면까지 약 0.25초가 약 0.06초로, 응답이 느린 브라우저 위에서는 약 0.9초가 약 0.06초로 줄었습니다. 출처 정보는 읽기가 끝나는 대로 저장한 캡처에 채웁니다.
- 창 캡처, 고정 크기 캡처, 이전 영역 캡처, 스크롤 캡처도 같은 방식으로 바꿨습니다. 응답이 느린 브라우저 위에서 편집기가 열리기까지 약 1.8초가 약 0.1초로, 6장면 스크롤 캡처가 약 11초가 약 1초로 줄었습니다.
- 보조 모니터에서 캡처하면 편집기를 그 모니터의 작업 영역 안에 엽니다. 세로 모니터에서 편집기가 화면 밖으로 나가던 문제를 수정했습니다.
- 빠른 작업 카드에 **텍스트 복사(T)**를 추가했습니다. 실패 안내는 동작별로 표시하고, 자동으로 닫지 않는 설정은 **유지** 토글로 바꿨습니다.
- 이미지 편집기 위쪽에 **텍스트 복사**를 추가해 편집한 이미지에서 바로 글자를 인식합니다. 불투명한 색은 `#EF4444`처럼 여섯 자리로 표시합니다.

## 라이브러리와 데이터 보호

- 라이브러리에서 삭제한 캡처와 폴더는 Windows 휴지통으로 이동합니다. 삭제 직후 상태 줄의 **되돌리기** 또는 `Ctrl+Z`로 방금 삭제한 항목을 한 번에 되돌릴 수 있습니다. **최근 삭제 복원** 메뉴는 미리보기와 삭제 시각을 표시합니다.
- 휴지통으로 보낼 수 없는 위치(휴지통을 끈 드라이브, 네트워크·이동식 드라이브 등)는 이유를 안내하고, 확인한 경우에만 영구 삭제합니다.
- 앱이 만든 임시 파일과 자동 정리 대상은 휴지통에 쌓지 않고 바로 정리합니다.
- 이미지 자동 삭제 기간을 설정에서 1일·7일·30일·90일·1년·삭제 안 함 중에서 고를 수 있습니다. 첫 자동 삭제 때 라이브러리에 한 번 안내합니다.
- 앱 종료와 Store 업데이트 전에 녹화와 저장하지 않은 편집을 확인합니다. 중단된 편집 초안이 있으면 다음 실행에서 한 번에 보여 주고 복구, 초안 버리기, 나중에 중에서 고를 수 있습니다. 복구한 이미지는 원래 캡처에 저장합니다.
- Store 설치본의 설정 > 정보에서 이전 버전 실행본의 이미지·동영상·주석·폴더를 가져올 수 있습니다. 원본과 현재 라이브러리는 바꾸지 않고, 이미 가져온 항목은 다시 가져오지 않습니다. 저장 공간이 부족하면 시작 전에 안내합니다.

## 녹화와 동영상 편집

- 동영상 편집기와 라이브러리 재생 창에서 녹화가 흐리게 보이던 문제를 수정했습니다. 내보낸 파일은 바뀌지 않습니다.
- 프레임 이동이 화면을 바꾸지 않던 문제와 재생을 기다리는 사이 편집기를 닫으면 앱이 종료되던 문제를 수정했습니다.
- 동영상 편집기의 시간 표기를 `0:01.500` 형식으로 통일했습니다.

## 화면과 안내

- 캡처, 텍스트·색상 복사, 이미지·동영상 편집, 라이브러리, 핀의 38개 기능을 실제 화면으로 만든 짧은 동영상으로 안내합니다. `F1` 도움말과 설정의 단축키 항목에서 열 수 있고, 단축키가 없는 기능은 바로 지정할 수 있습니다.
- 트레이 메뉴 첫 묶음에 텍스트 복사, 클립보드를 핀으로 띄우기, 핀 모두 숨기기·보이기를 두었습니다.
- 처음 실행할 때 Windows 로그인 시 MyCapture를 실행할지 고를 수 있습니다. 준비 완료 알림은 처음 실행과 캡처 단축키를 바꾼 때만 표시합니다.
- 알림은 마우스 포인터가 있는 모니터에 표시합니다. 업데이트·평가 안내는 화면 내용을 밀어내지 않는 작은 카드로 표시합니다.
- 저장 공간 부족, 다른 프로그램이 파일을 사용 중인 경우, 권한 문제를 구분해 안내하고 저장 위치 열기와 문제 신고를 바로 할 수 있습니다.
- 한국어 문장이 단어 중간에서 줄바꿈되지 않습니다.
- 설정 > 정보를 업데이트, 개인정보, 피드백, 데이터로 나누고, 텍스트 인식 모델을 처음 사용할 때 내려받는다는 사실과 크기를 안내합니다. 문제 신고는 진단 정보를 복사한 뒤 신고 페이지를 엽니다.
- 설정은 바뀐 내용이 있을 때만 **적용**을 켜고, 바뀐 내용이 없으면 **닫기**를 표시합니다.
- Windows 고대비 테마에서 라이브러리 항목에 마우스를 올렸을 때 표시가 사라지던 문제를 수정했습니다.
