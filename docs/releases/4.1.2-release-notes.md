# MyCapture 4.1.2

4.1.2는 기능별 사용법 안내, 편집 중인 작업 보호, 라이브러리 삭제·복원과 대량 텍스트·이미지 처리 개선을 담은 업데이트입니다.

Microsoft Store 배포용 패키지 버전은 `4.1.2.0`입니다.

## 변경 사항

- 캡처, 텍스트·색상 복사, 이미지·영상 편집, 라이브러리와 핀의 38개 기능을 각각 GIF로 확인할 수 있습니다. 한국어·영어 사용법을 제공하며 오프라인에서도 볼 수 있습니다.
- `F1` 단축키 도움말과 설정의 관련 단축키 항목에서 **사용법**을 열고, 기능 목록에서 다른 사용법으로 이동할 수 있습니다.
- 현재 설정한 단축키와 단계별 설명을 함께 표시합니다. 재생·일시정지·다시보기를 제공하며, Windows 애니메이션 효과를 끈 경우에는 정지 화면으로 시작합니다.
- 긴 텍스트 입력, 대량 OCR 결과 표시와 전체 선택, 많은 펜 주석 처리의 응답성을 개선했습니다.
- 항목이 많은 라이브러리의 검색 처리를 개선했습니다.
- 편집 초안을 저장하는 동안 편집 화면의 응답성을 개선했습니다.
- 앱 종료와 Store 업데이트 전에 녹화와 저장하지 않은 편집을 확인합니다. 저장하거나 변경 사항을 버릴 수 있으며, 취소하면 작업을 계속할 수 있습니다.
- 중단된 이미지·영상 편집 초안이 남아 있으면 다음 실행에서 복원 여부를 선택할 수 있습니다.
- 라이브러리에서 삭제하거나 자동 정리한 관리 파일은 Windows 휴지통으로 이동하며, 삭제 항목 복원 메뉴에서 되돌릴 수 있습니다. 처리에 실패한 항목과 편집·저장·복구 중인 항목의 보호를 보강했습니다.
- 반복해서 캡처를 사용한 뒤 평가 안내를 한 번 표시합니다. 캡처·녹화·편집 중에는 안내를 미룹니다.
- Store 설치본에서 업데이트 확인·설치 상태와 업데이트 후 완료를 안내합니다.
