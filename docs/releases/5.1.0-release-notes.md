# MyCapture 5.1.0

5.1.0의 변경은 네 갈래입니다.

- 편집기의 포인터와 굵기 조절을 다듬었습니다.
- 라이브러리와 저장, 문자 인식이 하는 일을 줄였습니다.
- Windows 10과 125% 같은 소수 배율 화면에서 생기던 문제를 고쳤습니다.
- 사용법 영상을 지금 화면으로 다시 만들었습니다.

5.0.1의 변경은 [5.0.1 릴리스 노트](5.0.1-release-notes.md)에서 확인할 수 있습니다.

## 편집기

- 도구마다 포인터가 다릅니다.
  - 사각형·타원·화살표는 회색 바탕에서도 보이는 편집기 전용 십자입니다.
  - 펜은 연필입니다.
  - 글상자에 입력하는 동안 글상자 밖은 화살표, 안은 글자 입력 포인터입니다.
  - 번호를 더 넣을 수 없으면 '사용할 수 없음' 포인터가 나옵니다.
- 펜과 형광펜은 그리기 전에 실제 굵기의 원을 획 색으로 보입니다. 연필 끝은 원 바깥에 두어 원을 가리지 않습니다.
- 펜·형광펜 도구에서 `[`와 `]`로 굵기를 1부터 64까지 14단계로 바꿉니다. `Ctrl+[`와 `Ctrl+]`는 지금처럼 그린 것의 순서를 바꿉니다.
- 형광펜 굵기를 펜·도형과 따로 기억합니다. 처음 값은 12이고, 12부터 64까지 고를 수 있습니다.
- 사용자 지정 색상 입력칸이 별도 창이 아니라 편집기 창 안에 열립니다. 입력칸 바깥을 누르면 입력칸만 닫히고 그리기는 시작하지 않습니다. 창 제목 표시줄을 누르거나 다른 창으로 옮겨도 닫힙니다.
- 소수 배율 화면에서 포인터가 픽셀 경계에 놓이면 계산 오차로 1픽셀 어긋나던 문제를 고쳤습니다. 이제 자르기와 가리기 경계가 누른 자리에 맞습니다.

## 라이브러리와 저장

- 스크롤한 라이브러리에서 카드를 고른 채 창 폭을 바꾸면 고른 카드가 화면 밖으로 밀리고 키보드 포커스를 잃었습니다. 이제 고른 카드로 돌아갑니다. 검색창으로 옮긴 포커스는 그대로 둡니다.
- 라이브러리가 화면 응답을 붙잡는 일을 줄였습니다.
  - 상세 패널은 카드를 처음 고를 때 만듭니다.
  - 여러 카드를 연달아 고르면 도구 모음 계산을 한 번만 합니다.
  - 썸네일 파일 확인은 화면 스레드 밖에서 합니다.
  - 라이브러리가 열려 있는 동안에는 편집기를 미리 준비하지 않고, 라이브러리를 닫거나 숨긴 뒤에 준비합니다.
- 캡처 정보와 라이브러리 목록을 저장할 때 CPU를 덜 씁니다. 저장 파일 형식은 그대로입니다. 시험 조건은 항목 1,000개에 항목마다 인식 글자 64 KB가 든 합성 라이브러리입니다.
  - 한 번 저장하는 데 드는 CPU 시간이 190.6 ms에서 90.6 ms로 줄었습니다.
  - 불러오는 데 드는 CPU 시간이 86.3 ms에서 68.0 ms로 줄었습니다.

## 문자 인식과 번역

- 인식 품질 `정확`이 Windows 문자 인식 결과를 합칠 때 기울어진 글자의 위치를 바르게 잡습니다. 합성 시험 그림 120장의 문자 오류율이 5.67%에서 2.48%로 줄었습니다. `빠름`과 `균형`의 결과는 같습니다.
- 문자 인식 모델을 받다가 네트워크가 멈추면 계속 기다리던 문제를 고쳤습니다. 60초 동안 받은 데이터가 없으면 실패로 알립니다.
- 번역 모델을 받을 때는 디스크에 쓰는 시간을 멈춤 판정에서 뺐습니다. 디스크가 느린 PC에서도 받기가 중간에 끊기지 않습니다.
- 모델 폴더와 그 위 폴더에 다른 위치로 이어진 링크가 있으면 모델 파일을 읽지 않도록 확인을 강화했습니다.

## Windows 10과 소수 배율 화면

- 반투명 창을 쓸 수 없는 Windows 10 환경에서 일부 창의 배경이 시간이 지나면 테마를 따르지 않거나 투명해지던 문제를 고쳤습니다. 녹화 제어창, 카운트다운, 캡처 카드, 핀 막대가 해당합니다.
- 소수 배율 화면에서 캡처 카드의 미리보기를 끌어도 끌기가 시작되지 않던 문제를 고쳤습니다.
- 125%와 175% 배율에서 동영상 편집기 타임라인의 연결선과 안내 글자가 띠 밖으로 넘치던 문제를 고쳤습니다.

## 동영상

- 컴퓨터가 바쁠 때 동영상 장면을 옮기면 `장면 저장`이 꺼지던 문제를 고쳤습니다. 라이브러리의 동영상 보기에서 생기던 문제입니다.

## 사용법 영상

- 31개 기능의 사용법 영상을 5.0.x 화면으로 다시 만들었습니다.
- 편집기·핀·빠른 작업 영상의 예시 그림을 업무용 구매 요청 표로 바꿨습니다.
