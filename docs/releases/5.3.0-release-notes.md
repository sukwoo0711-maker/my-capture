# MyCapture 5.3.0

5.3.0은 캡처 선택 화면을 더 빨리 표시하고 입력 대기 시간과 메모리 사용량을 줄이며, 여러 캡처의 삭제·되돌리기와 오류 보고를 개선하고 캡처·편집기·녹화·핀·설정·라이브러리 화면을 다듬은 업데이트입니다.

5.1.0 이후의 변경을 함께 담았습니다. 5.2.0의 변경은 [5.2.0 릴리스 노트](5.2.0-release-notes.md)에서 확인할 수 있습니다.

## 캡처 선택 화면

- 캡처 선택 화면을 전체 화면 WPF 창 대신 새 Win32 DIB 렌더러로 그립니다.
- 단축키를 누른 뒤 화면을 고정해 보여 주는 시간이 줄었습니다: {{SELECTOR_VISIBLE}}.
- 선택 화면이 키보드와 마우스 입력을 받을 때까지의 시간이 줄었습니다: {{SELECTOR_INPUT}}.
- 선택 화면을 닫은 뒤 앱이 계속 차지하는 메모리가 줄었습니다: {{SELECTOR_MEMORY}}.

## 라이브러리

- 여러 캡처를 휴지통으로 옮기거나 되돌릴 때 한 번의 작업으로 처리합니다. 지우는 카드와 개수는 누르는 즉시 화면에서 내립니다. 이 PC의 실제 휴지통에서 캡처 124개를 옮기는 시간이 42.6초에서 14.9초로, 되돌리는 시간이 396.4초에서 8.1초로 줄었습니다.
- 미리 보기와 복사할 그림을 화면 스레드 밖에서 읽습니다. 미리 보기를 눌렀을 때 화면 스레드가 쓰는 시간이 중앙값 86~122 ms에서 0.1~0.2 ms로 줄었습니다.
- 라이브러리 목록을 저장할 때 화면 스레드는 기록을 복사만 하고, 직렬화와 쓰기는 다른 스레드가 합니다.

## 캡처와 녹화

- 캡처 선택 화면에서 창 위를 훑을 때 강조 테두리가 포인터보다 늦게 따라오던 문제를 고쳤습니다.
- 스크롤 캡처가 반복 무늬가 있는 화면에서 겹침을 찾는 데 쓰는 CPU를 줄였습니다. 화면이 바뀌기 전의 중복 프레임을 고정 머리글로 잘못 판단하지 않습니다.
- 녹화 직후 일시적인 검증 실패가 나도 완성된 MP4와 복구 정보를 휴지통으로 보내지 않습니다.
- 녹화 팔레트와 시계의 도움말이 녹화 영상에 찍히지 않습니다.
- Media Foundation을 앱이 실행되는 동안 한 번만 시작합니다. 녹화를 거듭할 때 늘어나던 하드웨어 인코딩 핸들 수를 줄였습니다.

## 이미지 편집기

- 글상자에 입력하는 동안에도 확정했을 때와 같은 외곽선을 보여 줍니다. 글자가 256자를 넘으면 입력하는 동안에는 외곽선을 그리지 않습니다.
- 캐럿에 흰색과 검은색 테두리를 둘러 밝은 바탕과 어두운 바탕 모두에서 보입니다.

## 핀, 문자 인식, 번역

- VS Code에서 복사한 Markdown(`.md`) 내용을 코드 핀이 아니라 Markdown 문서 핀으로 그립니다. Mermaid 도표는 그림으로 보입니다.
- 인식 품질 `정확`의 표 탭이 두 엔진을 합친 결과로 표를 만들고, 같은 자리에 겹친 줄을 지웁니다.
- 신경망 문자 인식이 쉬는 동안 CPU를 덜 씁니다. 인식 뒤 20초 동안 쓰는 CPU 시간이 353 ms에서 45 ms로 줄었습니다.
- 번역 전처리가 같은 약어가 반복되거나 점으로 이어진 입력에서 오래 걸리던 문제와, 공백 없는 긴 입력이 256토큰에서 잘리던 문제를 고쳤습니다.

## 오류 보고

- 처리하지 못한 오류 창에 `오류 보고`를 더했습니다. 미리 채운 GitHub 이슈와 진단 묶음을 만들고, 무엇을 보낼지는 사용자가 정합니다. 서버나 자동 전송은 없습니다.
- 앱이 예기치 않게 종료되면 이 PC에만 최대 20개까지 기록하고, 다음 실행 때 알립니다.
- 문의하기 창이 내용 높이에 맞고 작업 영역을 넘지 않습니다.

## 첫 실행과 Store 평가

- 새로 설치하면 핵심 단축키 4개를 지정하고 `다른 프로그램보다 먼저 처리`를 켠 뒤, 첫 실행 때 알립니다. 설정 파일이 이미 있으면 그대로 둡니다.
- Store 설치판의 평가 초대가 빨라졌습니다. 캡처에 두 번 성공하면 바로 초대합니다. 5.1.0은 다섯 번 성공하고 설치한 지 하루가 지나야 초대했습니다. 답하지 않은 초대는 24시간 뒤 한 번 더 보이고, 그 뒤로는 보이지 않습니다. 캡처 카드에도 초대 줄이 붙습니다. GitHub 설치판에는 평가 초대가 없습니다.

## 그 밖의 수정

- 입력란을 누른 뒤 다른 곳을 누르면 그 클릭이 입력란으로 가던 문제를 앱 전체에서 고쳤습니다.
- 이미지 편집기, 캡처 흐름, 녹화 편집기, 핀과 글자 화면, 설정과 첫 실행, 라이브러리 화면을 점검해 정렬, 잘림, 색, 포커스 표시를 고쳤습니다. 녹화 편집기의 켜짐 토글이 포커스를 받으면 테두리가 채움과 같은 색이라 보이지 않던 문제, GIF 견본이 늦게 오면 견본 카드와 창 높이가 흔들리던 문제가 여기에 해당합니다.
