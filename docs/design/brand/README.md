# MyCapture 브랜드 마크

M06 ‘고정된 모서리’는 열린 캡처 프레임과 안쪽 45° 방향의 압정으로 빠른 캡처와 고정을 표현합니다. 2026-10-14 9차 시안(M06)을 바탕으로 압정의 크기와 오른쪽 아래 끝 길이를 조정합니다. SVG와 XAML 원본을 함께 보관합니다.

| 요소 | 색 |
| --- | --- |
| 흑연 타일 | `#5B6571` → `#222933` |
| 프레임 | `#FFF8F4` |
| 압정 | `#F35B4D` → `#BB252D` |
| 머리 하이라이트 | `#F87667` |
| 평면 타일 / 압정 | `#38424D` / `#E0453C` |

256 단위 캔버스에서 타일 범위는 12–236, 프레임 중심은 (124, 124)입니다. 프레임 두께는 18, 팔 길이는 54이며, 오른쪽 아래 모서리는 프레임 대신 압정이 차지합니다. 바늘은 (125.41, 125.41)에서 프레임 중심을 향합니다.

16·24 px는 전용 SVG를 사용합니다. 20 px도 전용 압정 좌표와 정수 경계의 2 px 프레임을 사용합니다. 이 세 크기에서는 오른쪽 아래 프레임 끝과 하이라이트를 생략합니다. 32·40 px는 평면판을, 48 px 이상은 그라디언트와 머리 하이라이트를 사용합니다. 각 크기를 직접 렌더링합니다.

보호 여백 x는 심벌 캔버스의 24/256입니다. 모든 락업 둘레에 x를 확보하며, 가로 락업의 심벌과 글자 간격은 40/256입니다. 화면 최소 크기는 전용 심벌 16 px, 가로 락업 너비 160 px, 세로 락업 너비 112 px, 단독 워드마크 너비 96 px입니다. 워드마크는 Segoe UI Semibold의 윤곽을 사용합니다.

밝거나 어둡거나 복잡한 배경에는 타일형을 사용합니다. 단색·반전 용도에는 제공된 전용판을 사용합니다. 프레임에는 빨강을 적용하지 않으며, 컬러 마크의 압정 색을 변경하지 않습니다. 기본 UI 포인트 색은 압정의 빨강을 바탕으로 대비를 조정한 레드이며, 바이올렛을 대안으로 제공합니다. 두 포인트 색 모두 로고 색 변경에 사용하지 않습니다. 트레이 상태 기호는 압정을 대체하되 타일과 프레임을 유지합니다.
2026-10-15에 압정을 기존 M06 대비 1.60배(기본 프로필 대비 1.536배)로 키웠습니다. 16·20·24 px 전용판은 반 픽셀 좌표와 짧은 바늘로 따로 보정했습니다.
1.00·1.20·1.40·1.60배 비교는 `pin-size-2026-10-15.png`에 있습니다. 원본 SVG를 고친 뒤에는 `build/generate-icons.ps1`로 앱·트레이 아이콘을 다시 생성합니다.
