# Codex 작업 리뷰 (2026-10-13, Claude)

대상: Codex가 오케스트레이션한 2026-10-12 ~ 13 작업. 기준은 `fix/store-update-continuity`의 2ac616b이고, `origin/main`(9a35763, Store 4.1.1)보다 176커밋 앞서 있습니다. 다섯 영역을 읽기 전용으로 나눠 리뷰했고, 주요 지적은 Claude가 코드에서 직접 다시 확인했습니다. 데이터 이관 지적 네 건은 임시 작업 공간의 시험 테스트로 재현했습니다.

## 결론

이미 Store에 나간 4.1.0·4.1.1에서는 심각한 결함이 없습니다. 고대비 테마에서 라이브러리 호버 표시가 사라지는 회귀 하나만 확인했습니다.

위험은 아직 출시하지 않은 4.1.2 후보와 QA15 변경에 몰려 있습니다. **지금의 4.1.2 후보 MSIX(236MB)는 제출하지 않아야 합니다.** 막아야 할 문제는 세 가지입니다.

- **휴지통 설계:** 앱 내부 임시 파일이 캡처할 때마다 사용자 휴지통으로 갑니다.
- **데이터 이관 결함:** 이관 기능에 사용자가 실제로 겪을 결함이 다섯 개 있습니다.
- **사용법 GIF:** 130MB 크기이고, 일부는 실제와 다른 화면을 보여 줍니다.

## 문제없음을 확인한 부분

- **출시분 코드:** 공유 테마 브러시 규칙을 지켰고, 모션은 Windows 애니메이션 끄기 설정을 따릅니다. 아이콘 렌더러와 회전 명령에 결함이 없습니다.
- **성능 개선 커밋:** 1330fac, 0a697d8, ff7e46c, caee5b8, 0519a41, 690483f, 33f6652는 기존과 같은 결과를 냅니다.
- **삭제·복원:** 트랜잭션 순서, 원본 식별, 덮어쓰기 거부, 삭제 중 편집 차단이 맞습니다. Windows 종료 보호에는 3초 상한이 있어 로그오프를 막지 않습니다.
- **데이터 이관:** 기존 Store 항목과 원본을 덮어쓰거나 지우는 경로는 없습니다. 경로 우회·접합점을 차단하고, 설정 초안은 저장 위치·토큰을 보호합니다.
- **진단 코드:** `--selftest-*` 스위치로만 실행되고, 측정 도구는 배포 패키지에 들어가지 않습니다.

## 권장 순서

1. 4.1.2 후보 MSIX를 제출하지 않습니다.
2. 휴지통 설계를 바로잡습니다. 앱 소유 파일은 실제로 삭제하고, 휴지통은 사용자가 라이브러리에서 지운 항목에만 씁니다. 0x4000을 제거하고, 휴지통으로 보낼 수 없으면 거부합니다. 테스트에는 가짜 휴지통을 주입합니다.
3. 데이터 이관 P1 다섯 개를 고칩니다. 실제 패키지(로컬 테스트 ID)에서 한 번 실행합니다.
4. 사용법은 실제 UI를 화면 밖에서 렌더한 H.264 MP4로 바꿉니다. 측정 결과 76개 전체가 약 15~25MB입니다. 원격에 올리기 전에 로컬 브랜치 이력에서 GIF를 빼야 합니다(사용자 확인 필요).
5. 자체 검사 판정을 원래 엄격도로 되돌리고, 고친 코드로 통과시킵니다.
6. 출시된 고대비 호버 회귀를 고칩니다.
7. 인계 문서를 150줄 안팎의 정본과 보관 기록으로 나누고, 디스크 정리를 사용자 확인 후 진행합니다.
