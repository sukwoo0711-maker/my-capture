# 경쟁 제품 기능 매트릭스 및 상위 기준

목표: Snipaste와 알캡처 대비 **어떤 항목에서도 열등하지 않고**, 핵심 축에서는 명확히 우위.

## 출처 신뢰도

| 제품 | 근거 | 신뢰도 |
|---|---|---|
| Snipaste | 공식 위키 `Getting Started` / `Key Bindings` (2026-01 개정) 직접 확인 | 검증됨 |
| 알캡처 | 공식 사이트는 마케팅 페이지로 기능 목록 미제공. 널리 알려진 기능 세트 기반 | 미검증(추정) |

알캡처 항목은 실물 검증 전까지 추정으로 취급한다. 최종 검증 루프에서 실제 설치 후 재확인 대상.

## 결정적 우위 5가지 (제품 정체성)

1. **300장 영속 캡처 큐** — 재시작해도 유지. 두 경쟁 제품 모두 없음.
2. **레이어 보존 재편집** — 3일 전 캡처의 화살표 위치만 수정 가능. Snipaste는 공식적으로 미구현.
3. **완성 도형 직접 재선택** — Snipaste의 Undo 반복 우회를 정면으로 해결.
4. **갤러리 창** — 격자·날짜 그룹·고정·검색. 두 제품 모두 없음.
5. **오프라인 OCR** — 한글+영어. 두 제품 모두 진짜 OCR 없음.

## 열등 위험 3가지 (반드시 방어)

1. **메모리·응답성** — 네이티브 WPF 선택 이유. 80MB / 100ms 목표를 실측으로 검증.
2. **스크롤 캡처** — 알캡처의 대표 기능. 미구현 시 즉시 열등. 13단계 필수 항목.
3. **성숙도** — 두 제품 모두 10년 이상 축적. 세부 UX(확대경, 픽셀 조정, 색상 피커)를 빠짐없이 이식.

## 검증 방법

각 항목은 최종 통합 검증 루프에서 다음으로 확인한다.

- 기능 존재: 수동 시나리오 체크리스트 통과
- 메모리: 30분 상주 후 작업 관리자 실측
- 응답성: 단축키 입력 → 오버레이 표시까지 스톱워치 로깅(내장 계측)
- 알캡처 항목: 실제 설치 후 표 재검증
