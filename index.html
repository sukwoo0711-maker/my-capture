자주 묻는 질문 English Microsoft Store

엑셀 사양 표와 자주 쓰는 코드를 에디터 위에 띄워 두는 Windows 핀 도구

엑셀이나 에디터에서 Ctrl+C, F3을 누르면 복사한 표와 코드가 핀으로 뜹니다. 보면서 코딩하다가 핀에서 Ctrl+C를 누르면 셀 값과 코드가 원문 그대로 복사됩니다. Ctrl+Shift+C로 캡처한 화면도 F3으로 띄웁니다.

Microsoft Store에서 받기

무료 · Windows 11, Windows 10 22H2(x64)

광고·계정 없이 무료이고 회사 업무에도 씁니다. 캡처와 글자 인식은 이 PC 안에서 처리합니다.

사용자가 실행하지 않았는데 앱이 인터넷에 연결하는 경우는 PC에 없는 글자 인식 모델을 내려받을 때뿐입니다. 연결하는 곳은 개인정보처리방침에 모두 적어 두었습니다. 소스 코드는 GitHub에 MIT 라이선스로 공개되어 있습니다.

엑셀 표와 코드를 원문째 띄우는 핀

엑셀에서 범위를 복사해 핀으로 띄우면 엑셀이 클립보드에 함께 넣는 그림을 그대로 보여 줍니다. 글꼴·채우기·테두리가 시트에서 보던 모양 그대로이고, 셀 값은 탭 구분 원문으로 핀에 붙어 있습니다. 색 정보를 함께 복사하는 에디터에서 복사한 코드는 에디터 색과 들여쓰기를 유지한 코드 핀이 됩니다.

복사한 뒤 F3을 누르면 핀이 뜨고, 에디터의 입력 위치는 그대로 남습니다. 핀에서 Ctrl+C나 Ctrl+더블클릭을 누르면 원문을 그대로 복사하므로 자주 쓰는 #if·#define 구문을 에디터에 바로 붙여 넣습니다.

코드를 덮지 않는 핀

핀 위에서 Ctrl+휠을 굴리면 투명도가 20–100%로 바뀝니다. 오른쪽 클릭 메뉴의 '뒤 창 클릭 허용'을 켜면 핀이 떠 있는 자리에서도 아래 에디터나 터미널을 클릭해 입력합니다.

Shift+F3으로 핀을 모두 숨기거나 다시 보이고, 앱을 다시 실행하면 열려 있던 핀이 다시 뜹니다. 최근 닫은 핀은 20개까지 위치·배율·투명도 그대로 다시 엽니다. 핀은 작업 표시줄과 Alt+Tab 목록에 나타나지 않습니다.

이미지 속 글자도 복사

데이터시트나 웹 문서를 캡처한 이미지 핀도 Ctrl+더블클릭하면 이 PC에서 한국어·영어 글자를 인식해 복사합니다. Ctrl+Shift+C로 캡처하면 캡처가 클립보드에 복사되므로, 이어서 F3을 누르면 그 캡처가 핀이 됩니다.

이미지 속 표는 CSV·Markdown·탭 구분 형식으로 복사합니다.

창 제목과 글자로 찾는 라이브러리

캡처할 때 그 창의 제목을 함께 저장하고, 이미지 속 글자는 이 PC에서 인식해 둡니다. timeout 같은 오류 메시지의 한 구절이나 CaptureService.cs 같은 파일 이름을 입력하면 해당 캡처가 나옵니다.

녹화한 MP4도 같은 라이브러리에 날짜별로 모이고, 따로 플레이어를 열지 않고 그 자리에서 재생합니다.

공유 전 주석과 개인정보 가리기

이슈에 붙일 화면에는 편집기에서 화살표·텍스트·단계 번호를 넣고, 블러나 모자이크로 일부를 가립니다. Ctrl+Shift+R을 누르면 화면 속 이메일 주소, 카드번호, IP 주소, 한국 전화번호와 주민등록번호 형태의 숫자, GitHub 토큰·AWS 액세스 키·sk-로 시작하는 API 키를 찾아 가림막을 씌웁니다.

가림막과 주석은 저장하기 전에 옮기거나 지울 수 있고, 실행 취소도 됩니다.

캡처 도구에서 옮겨 오면

Windows 캡처 도구로 하던 일은 MyCapture에서도 같은 방식으로 합니다. 여기에 코딩하는 동안 띄워 두는 핀이 더해집니다.

그대로인 것

  • 영역·창·전체 화면 캡처
  • 캡처하면 바로 클립보드에 복사
  • 이미지 속 글자 복사
  • 영역 녹화

더해지는 것

  • 엑셀 모양 그대로 띄우는 표 핀
  • 원문을 다시 복사하는 표·코드 핀
  • 반투명·뒤 창 클릭 허용 핀
  • 닫은 핀 다시 열기
  • 긴 화면을 잇는 스크롤 캡처
  • 창 제목과 이미지 속 글자로 찾는 라이브러리

기본 영역 캡처 단축키는 Ctrl+Shift+C입니다. Print Screen 키로 캡처하려면 설정에서 지정하십시오. Windows가 Print Screen 키를 캡처 도구에 연결해 두었다면 설정 화면에 끄는 방법과 Windows 설정 바로 가기가 나옵니다.

자주 묻는 질문

F3을 눌러도 핀이 뜨지 않습니다.

다른 프로그램이 F3을 먼저 쓰고 있으면 MyCapture가 실행할 때 알려 줍니다. 설정 > 단축키의 '클립보드를 핀으로 띄우기'에서 다른 키를 지정하거나, 트레이 아이콘 메뉴의 '클립보드를 핀으로 띄우기'를 쓰십시오. 이전 버전부터 쓰던 설정은 저장된 키를 그대로 유지하므로, 키가 비어 있다면 같은 곳에서 F3을 지정하십시오.

왜 무료입니까?

MyCapture는 소스 코드를 MIT 라이선스로 공개하는 프로젝트입니다. 앱이 접속하는 개발자 서버가 없어서 사용자가 늘어도 운영 비용이 늘지 않습니다. 유료 기능, 구독, 광고는 없습니다. 소스 코드는 GitHub에 있습니다.

캡처한 화면이 밖으로 나갑니까?

사용자가 보내지 않는 한 나가지 않습니다. 캡처, 편집, 녹화, 글자 인식은 이 PC에서 처리하고, 앱에는 사용 통계나 오류 보고를 보내는 기능이 없습니다. 인터넷에 연결하는 경우는 PC에 없는 글자 인식 모델을 내려받을 때와, GitHub 이미지 첨부처럼 사용자가 직접 실행한 기능에 연결이 필요할 때입니다. 전체 목록은 개인정보처리방침에 있습니다.

Windows 10에서도 쓸 수 있습니까?

4.3.0부터 Windows 10 버전 22H2(x64)를 지원합니다. 녹화하는 동안 화면 가장자리에 노란 테두리가 보일 수 있으며, 이 테두리는 녹화 결과에 들어가지 않습니다. 21H2 이하 버전과 ARM64 PC의 Windows 10은 지원하지 않습니다. Windows 11과의 차이는 지원 페이지의 표에 정리했습니다.

녹화에 소리가 들어가지 않는 이유는 무엇입니까?

MyCapture의 녹화는 버그 재현 과정이나 화면 조작을 짧게 보여 주고 GIF로 공유하는 용도에 맞췄습니다. 그래서 마이크와 시스템 소리를 녹음하지 않습니다. 소리가 필요한 녹화에는 다른 녹화 도구를 쓰십시오.

문의는 어디로 합니까?

세 가지 방법이 있습니다.

  • GitHub: 지원 저장소에 이슈를 남겨 주십시오. Windows 버전, MyCapture 버전, 재현 단계를 적어 주시면 확인이 빠릅니다.
  • Microsoft Store: MyCapture 페이지에 리뷰를 남길 수 있습니다. GitHub 계정이 없어도 됩니다.
  • 앱 안: 4.4.0부터는 앱의 '문의하기' 창이 앱 버전과 Windows 버전 같은 진단 정보를 채워 줍니다. 내용만 적어 GitHub 이슈나 Store 리뷰로 보내면 됩니다.

보안 문제는 공개 이슈 대신 비공개 보안 신고로 알려 주십시오.
